---

## 주요 기능

- 상단 안내 바: 클릭 시 상세 페이지 이동, X 버튼으로 닫기
- 프로그램 섹션: 탭으로 카테고리 필터링
- 뉴스레터: 이메일 입력 후 구독
- 통계: 숫자 카운팅 애니메이션
