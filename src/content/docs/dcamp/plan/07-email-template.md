| 비밀번호 재설정 | [dcamp] 비밀번호 재설정 안내 | 비밀번호 찾기 요청 시 |
| 프로그램 신청 확인 | [dcamp] 프로그램 신청이 접수되었습니다 | 프로그램 신청 완료 시 |
| 프로그램 선정 결과 | [dcamp] 프로그램 선정 결과 안내 | 심사 결과 발표 시 |
| 문의 접수 확인 | [dcamp] 문의가 접수되었습니다 | 문의 제출 시 |

### 주요 기능

- 반응형 이메일 템플릿 (모바일 최적화)
- 다크모드 대응
- 이메일 클라이언트 호환성 (Gmail, Outlook, Apple Mail 등)
- 추적 픽셀 (오픈율 측정)
- UTM 파라미터 (클릭 추적)

### 접근성

- alt 텍스트 제공 (이미지)
- 충분한 색상 대비
- 텍스트 기반 대체 버전
