## 1. 프로그램 관리 개요

디캠프에서 운영하는 다양한 프로그램(이벤트)을 관리합니다. 프로그램에는 지원서 접수, 지원자 관리, 심사 등의 기능이 포함됩니다.

> **참고**: 프로그램 종류는 운영 상황에 따라 변경될 수 있습니다.

### 관리자 메뉴 (프로그램 관리)

DCAMP 관리자 메뉴 → 프로그램 관리 하위에서 각 프로그램의 이벤트를 관리합니다.

| 관리자 메뉴 | 설명 | 상태 |
|------------|------|------|
| 디캠프 배치 | 배치 프로그램 이벤트 관리 | 사용 중 |
| 오피스아워 | 오피스아워 이벤트 관리 | 사용 중 |
| 그로스코칭 | 그로스코칭 이벤트 관리 | 사용 중 |
| 글로벌 | 글로벌 프로그램 이벤트 관리 | 사용 중 |
| 프로그램 전체 | 모든 프로그램 통합 관리 | Administrator 전용 |
| 비즈니스 데스크 | 비즈니스 데스크 이벤트 관리 | 숨김 |
| 리크루터 | 채용 연계 프로그램 | 숨김 |
| 스타트업 OI | → 글로벌로 이름 변경 | 숨김 |
| Residency | → space로 이름 변경 | 숨김 |
| Community | → family benefit으로 이름 변경 | 숨김 |

### 사용자 화면 (dcamp.kr)

사용자가 dcamp.kr에서 보는 프로그램 페이지입니다.

| 프로그램 | 사용자 URL | 설명 | 하위 카테고리 |
|---------|-----------|------|--------------|
| **dcamp batch** | /program/batch | 스타트업 액셀러레이팅 프로그램 | - |
| **space** | /program/space | 입주 공간 지원 프로그램 | - |
| **officehour** | /program/officehour | 전문가 1:1 멘토링 | 벤처투자, 사업협력 |
| **investment** | /program/investment | 투자 연계 프로그램 | - |
| **growth coaching** | /program/growth-coaching | 성장 단계별 코칭 | - |
| **family benefit** | /program/family-benefit | 패밀리 혜택 안내 | - |
| **global** | /program/global | 해외 진출 지원 | 미국, 일본 |

### 관리자 메뉴 ↔ 사용자 화면 연결

| 관리자 메뉴 | 사용자 화면 | 이벤트 신청 | 신청 방식 |
|------------|-----------|:----------:|----------|
| 디캠프 배치 | dcamp batch | ✓ | 단일 신청 |
| 오피스아워 | officehour | ✓ | 이벤트 목록 |
| 그로스코칭 | growth coaching | ✓ | 단일 신청 |
| 글로벌 | global | ✓ | 이벤트 목록 |
| - | space | - | - |
| - | investment | - | - |
| - | family benefit | - | - |

- **이벤트 신청 ✓**: 관리자가 이벤트를 생성하고 지원서를 받을 수 있음
- **단일 신청**: 프로그램 페이지에서 바로 "신청하기" → 신청 폼으로 이동
- **이벤트 목록**: 여러 이벤트(node) 중 선택 → 개별 이벤트 상세 → 신청

### 접근 권한 매트릭스

| 관리자 메뉴 | planning | investment | global_business | business | bizops | growth | resource | space |
|------------|:--------:|:----------:|:---------------:|:--------:|:------:|:------:|:--------:|:-----:|
| 디캠프 배치 | ✓ | ✓ | ✓ | ✓ | ✓ | - | - | - |
| 오피스아워 | ✓ | - | - | ✓ | ✓ | ✓ | - | - |
| 그로스코칭 | ✓ | - | - | ✓ | ✓ | ✓ | - | - |
| 글로벌 | ✓ | - | ✓ | - | - | - | - | - |

> **참고**: Administrator는 모든 프로그램에 접근 가능합니다. 본인 역할에서 접근할 수 없는 프로그램은 메뉴에 표시되지 않습니다.

## 2. 이벤트 목록 조회

### 접근 경로

DCAMP 관리자 메뉴 → 프로그램 관리 → 각 프로그램 선택

| 관리자 메뉴 | 경로 | 상태 |
|------------|------|------|
| 프로그램 전체 | `/admin/dcamp/program` | Administrator 전용 |
| 디캠프 배치 | `/admin/dcamp/program/batch` | 사용 중 |
| 오피스아워 | `/admin/dcamp/program/officehour` | 사용 중 |
| 그로스코칭 | `/admin/dcamp/program/growth-coaching` | 사용 중 |
| 글로벌 | `/admin/dcamp/program/global` | 사용 중 |
| 비즈니스 데스크 | `/admin/dcamp/program/business-desk` | 숨김 |
| 리크루터 | `/admin/dcamp/program/recruiter` | 숨김 |

### 목록 화면 구성

각 프로그램 목록 페이지에는 다음 요소가 포함됩니다:

- **이벤트 목록**: 해당 프로그램의 등록된 이벤트 목록
- **프로그램 추가 버튼**: 새 이벤트 생성
- **사용자 화면 링크**: dcamp.kr의 해당 프로그램 페이지로 이동
- **웹사이트 관리 링크**: 프로그램 페이지 설정 (웹사이트 관리 메뉴)

### 이벤트 목록 화면

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 제목 | 이벤트명 | 클릭 시 상세 페이지 이동 |
| 유형 | 이벤트 종류 | 배치, 오피스아워 등 |
| 상태 | 게시/미게시 | Published / Unpublished |
| 접수 기간 | 지원 접수 시작~종료일 | 날짜 형식: YYYY-MM-DD |
| 생성일 | 이벤트 생성일 | - |
| 작성자 | 담당자 | 생성자 이름 |

### 이벤트 검색 및 필터

```
┌─────────────────────────────────────────────────────────────┐
│  제목 검색: [________________________] [검색]                │
│                                                             │
│  유형 필터: [전체 ▼]    상태 필터: [전체 ▼]                   │
└─────────────────────────────────────────────────────────────┘
```

- **제목 검색**: 이벤트명으로 검색
- **유형 필터**: 프로그램 종류별 필터 (배치, 오피스아워, 그로스코칭 등)
- **상태 필터**: 게시/미게시 필터

### 필터 활용 예시

| 목적 | 필터 설정 |
|------|----------|
| 진행 중인 배치 프로그램 확인 | 유형: 배치, 상태: 게시 |
| 미게시 상태 이벤트 정리 | 상태: 미게시 |
| 특정 이벤트 검색 | 제목 검색창에 이벤트명 입력 |

## 3. 이벤트 생성

### 생성 전 확인사항

- [ ] 프로그램 유형이 명확한가? (배치, 오피스아워 등)
- [ ] 접수 기간이 정해졌는가?
- [ ] 지원서(웹폼)가 준비되어 있는가?
- [ ] 필요한 이미지(썸네일)가 준비되어 있는가?

### 새 이벤트 만들기

1. `/admin/content/event` 접속
2. **"+ 이벤트 추가"** 버튼 클릭
3. 이벤트 유형 선택

### 이벤트 유형별 특징

| 유형 | 특징 | 심사 기능 |
|------|------|----------|
| **dcamp batch** | 기수별 운영, 다단계 심사 | ✓ (필수) |
| **space** | 입주 공간 지원, 심사 필요 | ✓ (필수) |
| **officehour** | 정기 운영, 멘토 매칭 | - |
| **investment** | 투자 연계 | ✓ (선택) |
| **growth coaching** | 단계별 코칭 프로그램 | - |

### 이벤트 기본 정보 입력

| 필드 | 설명 | 필수 | 입력 예시 |
|------|------|:----:|----------|
| 제목 | 이벤트명 | O | "디캠프 배치 26기" |
| 설명 | 이벤트 소개 | O | 프로그램 상세 설명 |
| 썸네일 | 대표 이미지 | - | 권장: 1200x630px |
| 접수 시작일 | 지원 접수 시작 | O | 2026-02-01 |
| 접수 종료일 | 지원 접수 마감 | O | 2026-02-28 |
| 이벤트 일시 | 실제 행사 일정 | - | 2026-03-15 ~ 2026-06-15 |
| 장소 | 행사 장소 | - | "디캠프 선릉" |
| 상태 | 게시/미게시 | O | 준비 중에는 미게시 |

### 이미지 가이드

| 이미지 종류 | 권장 크기 | 파일 형식 | 용량 |
|------------|----------|----------|------|
| 썸네일 | 1200 x 630px | JPG, PNG | 1MB 이하 |
| 상세 이미지 | 1200 x auto | JPG, PNG | 2MB 이하 |

### 지원서(웹폼) 연결

이벤트에 지원서(웹폼)를 연결하여 지원자가 신청할 수 있도록 설정합니다.

> **참고**: 웹폼이 미리 생성되어 있어야 연결할 수 있습니다. 새 웹폼이 필요한 경우 시스템 관리자에게 요청하세요.

#### 웹폼 선택

1. 이벤트 편집 페이지에서 **"지원서"** 섹션
2. 기존에 등록된 웹폼 목록에서 사용할 웹폼 선택

#### 필드 선택 (체크박스)

웹폼을 선택하면 해당 웹폼의 필드 목록이 체크박스로 표시됩니다.

- **체크 해제**: 이번 이벤트 등록 시 해당 필드를 **노출하지 않음**
- **체크 유지**: 해당 필드를 사용자에게 노출

이를 통해 동일한 웹폼을 사용하면서도 이벤트별로 필요한 필드만 선택적으로 노출할 수 있습니다.

#### 미리보기

**"미리보기"** 버튼을 클릭하면 전체 웹폼이 사용자 화면(dcamp.kr)에서 어떻게 표현되는지 확인할 수 있습니다.

- 관리자가 신청폼 구성을 등록 전에 미리 확인 가능
- 필드 선택(체크박스) 설정이 반영된 상태로 미리보기

## 4. 지원자 관리

### 접근 경로

```
이벤트 목록 → 이벤트 선택 → 지원자 관리
또는: /admin/content/event/applicant/{event_id}
```

### 접근 권한

해당 프로그램에 대한 접근 권한이 있어야 지원자 목록을 볼 수 있습니다.

### 지원자 목록 화면

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 지원자명 | 지원자 이름 | 클릭 시 상세 조회 |
| 이메일 | 연락처 | - |
| 소속 | 회사/팀명 | - |
| 지원일 | 제출 일시 | 정렬 가능 |
| 상태 | 지원 상태 | 접수/검토중/심사중 등 |
| 심사 결과 | 합격/불합격/대기 | 심사 완료 후 표시 |

### 지원자 상태 관리

| 상태 | 설명 | 다음 단계 |
|------|------|----------|
| **접수** | 지원서 제출 완료 | → 검토중 |
| **검토중** | 서류 검토 중 | → 심사중 또는 불합격 |
| **심사중** | 심사위원 평가 중 | → 합격/불합격/대기 |
| **합격** | 최종 합격 | 완료 |
| **불합격** | 최종 불합격 | 완료 |
| **대기** | 후보 대기 (차순위) | → 합격 또는 불합격 |

### 상태 변경 방법

1. 지원자 목록에서 대상 선택 (체크박스)
2. 상단 **"작업"** 드롭다운에서 상태 선택
3. **"적용"** 버튼 클릭

### 지원서 상세 조회

1. 지원자 목록에서 이름 클릭
2. 제출된 지원서 내용 확인:
   - 기본 정보 (이름, 연락처, 소속)
   - 지원 내용 (질문별 답변)
   - 첨부 파일 (사업계획서, 발표자료 등)
3. 첨부 파일 다운로드 가능

### 지원자 데이터 내보내기

지원자 목록을 파일로 다운로드할 수 있습니다.

1. 지원자 목록 페이지 접근
2. 필터 적용 (필요시 - 특정 상태만 등)
3. **"내보내기"** 버튼 클릭
4. 형식 선택 (CSV, Excel)
5. 다운로드

> **개인정보 주의**: 내보낸 파일에는 지원자 개인정보가 포함됩니다. 업무 목적으로만 사용하고, 사용 후 파일을 삭제해주세요.

## 5. 심사 시스템

디캠프 배치 등 심사가 필요한 프로그램을 위한 심사 기능입니다.

### 심사 프로세스 흐름

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 지원 접수 │ → │ 서류 검토 │ → │ 심사위원  │ → │ 심사 진행 │ → │ 결과 확정 │
│          │    │          │    │   배정    │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 5.1 심사 설정

#### 접근 경로

```
이벤트 → 지원서 관리 → 심사위원 설정
/admin/content/event/application/{event_id}/setting
```

#### 심사 항목 설정

심사 기준과 평가 항목을 정의합니다.

1. **"심사 항목 추가"** 버튼 클릭
2. 평가 항목 입력:

| 필드 | 설명 | 예시 |
|------|------|------|
| 항목명 | 평가 기준 이름 | "시장성", "팀 역량", "기술력" |
| 배점 | 해당 항목 최대 점수 | 20점, 30점, 50점 |
| 설명 | 평가 가이드 | "목표 시장 규모와 성장 가능성을 평가" |

3. 항목 순서 조정 (드래그 앤 드롭)
4. **"저장"** 클릭

#### 심사 항목 예시 (배치 프로그램)

| 항목 | 배점 | 설명 |
|------|------|------|
| 문제 인식 | 20점 | 해결하고자 하는 문제의 명확성 |
| 솔루션 | 25점 | 문제 해결 방안의 적절성 |
| 시장성 | 20점 | 목표 시장 규모와 성장 가능성 |
| 팀 역량 | 20점 | 팀 구성 및 실행 능력 |
| 사업화 가능성 | 15점 | 수익 모델 및 확장성 |
| **총점** | **100점** | - |

### 5.2 심사위원 관리

#### 심사위원 목록

```
/admin/content/event/application/{event_id}/list
```

#### 심사위원 등록 (변경 예정)

> **변경 예정**: 개인정보 보호 정책에 따라 심사위원 등록 및 인증 방식이 변경될 예정입니다.

**기존 방식:**
- 심사위원 역할(judge)을 가진 관리자 회원 중 선택

**변경 예정 방식:**

1. **회원 등록**: 심사위원을 일반 회원으로 등록
2. **심사위원 등록**: 해당 이벤트에 심사위원으로 등록
3. **심사 화면 접근 시**: MFA 인증번호 안내 메일 발송
4. **인증 후 접근**: 원타임 로그인으로 심사 화면 접근

| 단계 | 설명 |
|------|------|
| 회원 등록 | 심사위원 이름, 이메일로 회원 생성 |
| 심사위원 등록 | 이벤트에 심사위원 배정 |
| 인증 메일 | 심사 화면 접근 시 MFA 인증번호 메일 자동 발송 |
| 원타임 로그인 | 인증번호 확인 후 해당 세션에서만 심사 가능 |

경로: `/admin/content/event/application/{event_id}/add`

### 5.3 심사위원 배정

#### 지원자-심사위원 배정

각 지원자에게 심사위원을 배정합니다.

1. 심사위원 설정 페이지 접근
2. 배정 방식 선택:

| 방식 | 설명 | 사용 상황 |
|------|------|----------|
| **수동 배정** | 개별 지정 | 분야별로 다른 심사위원 배정 시 |
| **자동 배정** | 균등 분배 | 대량 지원자를 균등하게 배분 시 |

3. 배정 완료 후 확인

#### 배정 원칙

- 한 지원자당 최소 2명 이상의 심사위원 배정 권장
- 이해관계 충돌 방지 (동일 회사, 경쟁사 등)
- 심사위원별 적정 배정 수 유지 (20~30개 권장)

### 5.4 심사 진행

#### 심사위원 심사 페이지

심사위원은 별도의 심사 페이지에서 심사를 진행합니다:

```
/judge
```

> **참고**: 심사 페이지는 관리자 페이지와 별도입니다. 심사위원은 MFA 인증을 통한 원타임 로그인으로 접근합니다.

#### 심사 흐름 (변경 예정)

```
1. 관리자: 심사위원 등록 (회원 등록 → 심사위원 배정)
         ↓
2. 심사위원: 심사 페이지(/judge) 접근 시도
         ↓
3. 시스템: MFA 인증번호 메일 자동 발송
         ↓
4. 심사위원: 메일에서 인증번호 확인
         ↓
5. 심사위원: 인증번호 입력 → 원타임 로그인
         ↓
6. 심사위원: 배정된 지원자 목록 확인
         ↓
7. 심사위원: 각 지원자 심사
   - 지원서 검토
   - 평가 항목별 점수 입력
   - 종합 의견 작성
         ↓
8. 심사위원: 심사 제출
```

### 5.5 심사 결과

#### 결과 조회

```
/admin/content/event/application/{event_id}/result
```

#### 결과 화면

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 지원자 | 지원자명 | 클릭 시 상세 조회 |
| 평균 점수 | 심사위원 평균 점수 | 자동 계산 |
| 심사 현황 | 완료/미완료 심사위원 수 | 예: 2/3 완료 |
| 최종 결과 | 합격/불합격/대기 | 관리자 설정 |

#### 결과 분석

- **점수 분포 확인**: 전체 지원자의 점수 분포 파악
- **심사위원별 경향**: 각 심사위원의 평가 경향 확인
- **항목별 점수**: 평가 항목별 평균 점수 분석

#### 최종 결과 확정

1. 결과 페이지에서 심사 점수 확인
2. 합격선 설정:
   - **자동**: 상위 N% 또는 N명 선택
   - **수동**: 개별 선택
3. 최종 결과 확정
4. **"저장"** 클릭

> **주의**: 결과 확정 후에는 변경이 어려우므로 신중하게 진행하세요.

## 6. 이메일 발송

### 접근 경로

```
/admin/content/event/application/{event_id}/email
```

### 이메일 발송 기능

지원자에게 일괄 이메일을 발송할 수 있습니다.

#### 발송 절차

1. **대상 선택**:

| 대상 | 설명 |
|------|------|
| 전체 지원자 | 모든 지원자에게 발송 |
| 합격자만 | 합격 상태인 지원자만 |
| 불합격자만 | 불합격 상태인 지원자만 |
| 대기자만 | 대기 상태인 지원자만 |
| 특정 상태 | 접수, 검토중 등 특정 상태 |

2. **이메일 작성**:
   - 템플릿 선택 또는 직접 작성
   - 제목 입력
   - 본문 작성

3. **발송 미리보기**:
   - 실제 발송 전 내용 확인
   - 수신자 수 확인

4. **발송**

#### 이메일 템플릿

| 템플릿 | 용도 |
|--------|------|
| 접수 확인 | 지원서 제출 확인 안내 |
| 서류 합격 | 서류 심사 합격 안내 |
| 최종 합격 | 프로그램 최종 합격 안내 |
| 불합격 | 심사 불합격 안내 |
| 대기 안내 | 후보 대기 상태 안내 |

#### 변수 사용

이메일 본문에 변수를 사용하여 개인화된 메시지를 발송할 수 있습니다.

| 변수 | 설명 | 예시 |
|------|------|------|
| `[name]` | 지원자 이름 | 홍길동 |
| `[email]` | 지원자 이메일 | hong@example.com |
| `[company]` | 소속 회사명 | 스타트업A |
| `[program]` | 프로그램명 | 디캠프 배치 26기 |

### 이메일 이력 확인

발송된 이메일 이력은 `mailhistory` 엔티티로 저장됩니다.

- 발송 일시
- 수신자 목록
- 이메일 제목 및 내용
- 발송 상태 (성공/실패)

## 9. 자주 묻는 질문 (FAQ)

### Q1. 내가 관리하는 프로그램만 보이나요?

**A**: 네, 역할에 따라 접근 가능한 프로그램만 메뉴에 표시됩니다. 예를 들어 `growth` 역할은 오피스아워, 그로스코칭만 볼 수 있습니다.

### Q2. 지원서 양식을 변경하고 싶어요.

**A**: 지원서(웹폼)는 시스템 관리자만 수정할 수 있습니다. 변경이 필요한 경우 요청해주세요.

### Q3. 심사위원이 심사 페이지에 접근하지 못한다고 합니다.

**A**: 
1. 심사위원 이메일 주소가 정확히 등록되었는지 확인
2. MFA 인증 메일이 스팸함에 있는지 확인 안내
3. 회원 등록 및 심사위원 배정이 정상적으로 되었는지 확인

### Q4. 지원자 정보를 수정할 수 있나요?

**A**: 지원자가 제출한 정보는 원칙적으로 수정하지 않습니다. 오류 수정이 필요한 경우 지원자에게 재제출을 요청하거나 시스템 관리자에게 문의하세요.

### Q5. 접수 기간을 연장하고 싶어요.

**A**: 이벤트 편집 페이지에서 "접수 종료일"을 변경하면 됩니다. 연장 공지를 별도로 진행해주세요.
