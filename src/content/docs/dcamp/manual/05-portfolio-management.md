## 1. 포트폴리오 개요

포트폴리오는 디캠프와 관련된 기업 및 공간 정보를 관리하는 기능입니다.

### 포트폴리오 유형

| 유형 | 설명 | 주요 관리 내용 |
|------|------|---------------|
| **스타트업 (Startup)** | 디캠프 프로그램 참여 스타트업 | 기업 정보, 투자 현황, 참여 프로그램 |
| **파트너 (Partner)** | 협력 파트너사 (투자사, 기업 등) | 기업 정보, 협력 내용, 연결 스타트업 |
| **센터 (Campus)** | 디캠프 센터 및 공간 정보 | 위치, 시설, 운영 정보 |

### 접근 권한

| 기능 | planning | investment | global_business | business | bizops | growth | resource | space |
|------|:--------:|:----------:|:---------------:|:--------:|:------:|:------:|:--------:|:-----:|
| 스타트업 관리 | ✓ | - | ✓ | ✓ | - | - | - | - |
| 파트너 관리 | ✓ | ✓ | ✓ | - | ✓ | ✓ | ✓ | ✓ |
| 포트폴리오 조회 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 포트폴리오 생성/수정 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

> **참고**: Administrator는 모든 기능에 접근 가능합니다.

## 3. 스타트업 관리

스타트업 관리에서 등록/수정한 내용은 사용자 화면(dcamp.kr)의 스타트업 페이지에 반영됩니다.

### 사용자 화면 연결

| 관리자 메뉴 | 사용자 화면 URL | 설명 |
|------------|----------------|------|
| 스타트업 관리 | dcamp.kr/startups | 스타트업 목록 페이지 |

- 관리자에서 스타트업을 **게시** 상태로 저장하면 사용자 화면에 노출됩니다.
- 관리자에서 **미게시** 상태로 변경하면 사용자 화면에서 숨겨집니다.
- 사용자 화면에서 스타트업 상세 정보는 **모달(팝업)**로 표시됩니다. (개별 상세 페이지 없음)

### 사용자 화면 필드 구성

#### 패싯(필터)에 사용되는 필드

사용자가 스타트업을 검색/필터링할 때 사용되는 필드입니다.

| 필터 | 관리자 필드 | 설명 |
|------|-----------|------|
| dcamp batch | 배치 기수 | 배치 1기, 2기, ... |
| 구분 | 입주 상태, 투자 여부, 글로벌 | 입주/졸업/투자/글로벌 |
| 분류 | 산업 분류 (sector) | 대분류 > 소분류 계층 구조 |

> **팁**: 필터에 사용되는 필드는 정확하게 입력해야 사용자가 스타트업을 쉽게 찾을 수 있습니다.

#### 목록 카드에 표시되는 필드

스타트업 목록에서 각 카드에 표시되는 정보입니다.

| 분류 | 산업 분류 (대분류 > 소분류) |
| 태그 | 입주/졸업/투자/글로벌/배치 기수 |
| 채용중 | 채용 정보 링크 (있는 경우) |

#### 모달(상세)에 표시되는 필드

스타트업 클릭 시 모달에 표시되는 상세 정보입니다.

| 표시 항목 | 관리자 필드 | 비고 |

| 서비스명 | 서비스/제품명 | |

### 3.1 스타트업 등록

#### 등록 전 확인사항

- [ ] 스타트업 기본 정보 (회사명, 대표자) 확보
- [ ] 로고 이미지 준비 (400x400px, PNG)
- [ ] 대표 이미지 준비 (1200x630px)
- [ ] 회사 소개 텍스트 준비

#### 등록 절차

1. `/admin/content/portfolio` 접속
2. **"+ 스타트업 추가"** 버튼 클릭
3. 정보 입력 (아래 표 참조)
4. **"저장"** 클릭

### 필드 구분

스타트업 필드는 **사용자 화면 노출 여부**에 따라 두 가지로 구분됩니다.

#### 사용자 화면 노출 필드

dcamp.kr/startups에 표시되는 정보입니다. **정확하고 최신 정보**를 입력해주세요.

| 필드 | 설명 | 필수 | 입력 가이드 |
|------|------|:----:|------------|
| 법인명 | 회사명 | O | 공식 회사명 사용 |
| 로고 | 회사 로고 이미지 | O | 400x400px PNG, 투명 배경 권장 |
| 소개 | 회사 소개 (간략) | O | 한 줄 소개 (100자 이내), 명확하게 |
| 산업 분류 | 대분류 > 소분류 | - | 패싯 필터에 사용됨 |
| 서비스/제품명 | 주요 서비스명 | - | 모달에 표시됨 |
| 홈페이지 | 회사 웹사이트 URL | - | https:// 포함 전체 URL |
| 대표자 | 대표이사명 | - | 모달에 표시됨 |
| 설립일 | 법인 설립일 | - | YYYY-MM-DD 형식, 모달에 표시됨 |
| 입주 상태 | 입주/졸업 여부 | - | 패싯 필터 및 태그에 사용됨 |
| 입주연도 | 입주 시작 연도 | - | 모달에 표시됨 |
| 입주위치 | 입주 센터/층 | - | 모달에 표시됨 |
| 배치 기수 | dcamp batch 기수 | - | 패싯 필터 및 태그에 사용됨 |
| 투자 여부 | 투자 유치 여부 | - | 패싯 필터 및 태그에 사용됨 |
| 글로벌 여부 | 글로벌 진출 여부 | - | 패싯 필터 및 태그에 사용됨 |
| 채용 정보 링크 | 채용 페이지 URL | - | 있으면 "채용중" 표시 및 링크 |

> **팁**: 사용자 화면에 노출되는 정보이므로, 스타트업과 협의된 공식 정보를 입력하세요.

#### 내부 관리용 필드

사용자 화면에 노출되지 않으며, **내부 데이터 관리 목적**으로 사용합니다.

| 필드 | 설명 | 입력 가이드 |
|------|------|------------|
| 누적 투자액 | 총 투자 유치 금액 | 내부 현황 파악용 (예: 50억원) |
| 주요 투자사 | 투자한 VC/기업 목록 | 내부 관계 관리용 |
| 입주 기간 | 디캠프 입주 기간 | 공간 관리용 (예: 2024-03 ~ 2025-02) |
| 담당자 | 디캠프 내 담당 매니저 | 내부 담당자 지정용 |

> **참고**: 내부 관리용 필드는 외부에 공개되지 않으므로, 관리에 필요한 정보를 자유롭게 입력하세요.

#### 투자 단계 옵션

| 단계 | 설명 |
|------|------|
| Pre-Seed | 초기 아이디어 단계 |
| Seed | 시드 투자 유치 |
| Series A | 시리즈 A 투자 유치 |
| Series B | 시리즈 B 투자 유치 |
| Series C+ | 시리즈 C 이상 |
| Pre-IPO | 상장 준비 단계 |
| IPO | 상장 완료 |

### 3.2 스타트업 수정

1. 스타트업 목록에서 대상 선택
2. **"편집"** 클릭
3. 정보 수정
4. **"저장"** 클릭

### 3.3 스타트업 상태 관리

| 상태 | 설명 | 프론트엔드 노출 |

| **졸업** | 프로그램 졸업 | ✓ (졸업 표시) |
| **비공개 (미게시)** | 목록에서 숨김 | - |

## 4. 파트너사 관리

### 4.1 파트너사 등록

#### 등록 전 확인사항

- [ ] 파트너 기업 정보 확보
- [ ] 로고 이미지 준비 (400x400px, PNG)
- [ ] 파트너 유형 확정

#### 등록 절차

1. `/admin/content/portfolio/partners` 접속
2. **"+ 파트너 추가"** 버튼 클릭
3. 정보 입력
4. **"저장"** 클릭

#### 파트너 정보

| 필드 | 설명 | 필수 | 입력 예시 |
|------|------|:----:|----------|
| 파트너명 | 기업명 | O | "ABC벤처스" |
| 로고 | 기업 로고 | O | 400x400px PNG |
| 유형 | 파트너 유형 | O | VC, 대기업 등 |
| 소개 | 파트너 소개 | - | 기업 소개 텍스트 |
| 홈페이지 | 웹사이트 URL | - | https://example.com |
| 협력 분야 | 협력 내용 | - | 투자, 멘토링, 사업 연계 등 |

### 4.2 파트너 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| **VC** | 벤처캐피탈 | 소프트뱅크벤처스, 알토스벤처스 |
| **CVC** | 기업형 벤처캐피탈 | 삼성벤처투자, 현대자동차그룹 |
| **대기업** | 대기업 파트너 | 삼성, LG, SK 등 |
| **중견기업** | 중견기업 파트너 | - |
| **공공기관** | 정부/공공 기관 | 중소벤처기업부, KOTRA |
| **액셀러레이터** | 액셀러레이터 | 프라이머, 스파크랩 |
| **기타** | 기타 파트너 | - |

### 4.3 파트너별 스타트업 연결

파트너사와 관련된 스타트업을 연결합니다 (투자 관계, 협력 관계 등).

#### 연결 경로

```
/admin/content/portfolio/partners/{partner_id}
```

#### 연결 절차

1. 파트너 상세 페이지 접근
2. **"연결 스타트업"** 섹션
3. **"스타트업 추가"** 클릭
4. 스타트업 검색 및 선택
5. 연결 유형 선택 (투자, 협력 등)
6. **"저장"** 클릭

#### 연결 유형

| 유형 | 설명 |
|------|------|
| 투자 | 해당 파트너가 투자한 스타트업 |
| 협력 | 사업 협력 관계 |
| 멘토링 | 멘토링 제공 관계 |

### 4.4 파트너 수정 및 삭제

#### 수정

1. 파트너 목록에서 대상 선택
2. **"편집"** 클릭
3. 정보 수정
4. **"저장"** 클릭

#### 삭제 (비공개 처리)

> **주의**: 파트너는 삭제하지 않고 미게시(비공개) 처리를 권장합니다.

1. 파트너 편집 페이지
2. 상태를 **"미게시"**로 변경
3. **"저장"** 클릭

## 6. 포트폴리오 데이터 관리

### 6.1 데이터 내보내기

포트폴리오 데이터를 파일로 다운로드할 수 있습니다.

> **개인정보 보호**: 포트폴리오 데이터에는 기업 및 대표자 개인정보가 포함되어 있으므로, 다운로드 시 **사유 입력이 필수**이며 모든 다운로드 이력이 기록됩니다.

#### 내보내기 절차

1. 포트폴리오 목록 페이지 접근
2. 필터 적용 (필요시)
3. **"내보내기"** 버튼 클릭
4. **다운로드 사유 입력** (필수)
5. 형식 선택 (CSV, Excel)
6. 다운로드

#### 다운로드 사유 입력

| 항목 | 설명 |
|------|------|
| **사유 입력** | 다운로드 목적을 구체적으로 작성 |
| **이력 기록** | 다운로드 일시, 담당자, 사유가 자동으로 기록됨 |
| **감사 추적** | 관리자가 다운로드 이력을 조회할 수 있음 |

#### 다운로드 이력 관리

| 기록 항목 | 설명 |
|----------|------|
| 다운로드 일시 | 파일 다운로드 시점 |
| 담당자 | 다운로드를 실행한 관리자 계정 |
| 다운로드 사유 | 입력한 사유 내용 |
| 다운로드 범위 | 적용된 필터 조건 및 건수 |

#### 내보내기 항목

| 항목 | 포함 여부 |
|------|:--------:|
| 기업명 | ✓ |
| 유형 | ✓ |
| 대표자 | ✓ |
| 설립일 | ✓ |
| 사업 분야 | ✓ |
| 투자 단계 | ✓ |
| 참여 프로그램 | ✓ |
| 상태 | ✓ |

### 6.2 일괄 수정

## 9. 자주 묻는 질문 (FAQ)

### Q1. 스타트업 로고가 잘 안 보여요.

**A**: 로고 이미지 사양을 확인해주세요.

- 형식: PNG (투명 배경)
- 로고가 너무 작거나 복잡하면 축소 시 가독성이 떨어집니다.

**A**: 삭제 대신 미게시(비공개) 처리를 권장합니다. 연결된 데이터 보존을 위해 완전 삭제는 피해주세요.
