## 1. 콘텐츠 관리 개요

디캠프 웹사이트(dcamp.kr)에 게시되는 다양한 콘텐츠를 관리합니다.

### 콘텐츠 유형

| 유형 | 설명 | 관리자 경로 | 사용자 화면 |
|------|------|------------|------------|
| **공지사항** | 디캠프 공지사항 | 뉴스 관리 → 공지사항 관리 (`/admin/dcamp/notice`) | dcamp.kr/news/notice |
| **스토리** | 스타트업 스토리, 아티클 | 뉴스 관리 → 스토리 관리 (`/admin/dcamp/insights`) | dcamp.kr/news/story |
| **미디어** | 외부 언론 보도 (외부 링크) | 뉴스 관리 → 미디어 관리 (`/admin/dcamp/media`) | dcamp.kr/news/media |

### 접근 권한

| 기능 | planning | investment | global_business | business | bizops | growth | resource | space |
|------|:--------:|:----------:|:---------------:|:--------:|:------:|:------:|:--------:|:-----:|
| 공지사항 관리 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 스토리 관리 | ✓ | - | - | - | ✓ | - | - | - |
| 미디어 관리 | ✓ | - | - | - | ✓ | - | - | - |

> **참고**: Administrator는 모든 콘텐츠 관리 권한을 가집니다. 공지사항은 모든 부서에서 관리 가능하지만, 스토리와 미디어는 기획실과 BizOps만 접근 가능합니다.

## 3. 공지사항 관리

공지사항 관리에서 등록/수정한 내용은 사용자 화면(dcamp.kr)의 공지사항 페이지에 반영됩니다.

### 사용자 화면 연결

| 관리자 메뉴 | 사용자 화면 URL | 설명 |
|------------|----------------|------|
| 공지사항 관리 | dcamp.kr/news/notice | 공지사항 목록 페이지 |
| 공지사항 상세 | dcamp.kr/news/notice/{id} | 공지사항 상세 페이지 |

- 관리자에서 공지사항을 **게시** 상태로 저장하면 사용자 화면에 노출됩니다.
- **상단 고정(sticky)** 설정된 공지는 목록 최상단에 표시됩니다.

### 사용자 화면 필드 구성

#### 패싯(필터)에 사용되는 필드

| 필터 | 관리자 필드 | 설명 |
|------|-----------|------|
| 카테고리 | 카테고리 (field_category) | ESG / Notice |
| 검색 | 제목 (title) | 제목 내 키워드 검색 |

#### 목록에 표시되는 필드

| 표시 항목 | 관리자 필드 |
|----------|-----------|
| 제목 | 제목 (title) |
| 카테고리 | 카테고리 (field_category) |
| 썸네일 | 대표 이미지 (field_image) |
| 작성일 | 생성일 (created) |

#### 상세 페이지에 표시되는 필드

| 표시 항목 | 관리자 필드 |
|----------|-----------|
| 제목 | 제목 (title) |
| 카테고리 | 카테고리 (field_category) |
| 작성일 | 생성일 (created) |
| 본문 | 본문 (body) |
| 첨부파일 | 첨부파일 (field_attachment) |
| 대표 이미지 | 대표 이미지 (field_image) |

### 3.1 공지사항 목록

```
뉴스 관리 → 공지사항 관리 (/admin/dcamp/notice)
```

### 3.2 공지사항 작성

#### 작성 전 확인사항

- [ ] 공지 내용 검토 완료
- [ ] 첨부파일 준비 (해당 시)
- [ ] 썸네일 이미지 준비 (해당 시)
- [ ] 게시일 확정

#### 작성 절차

1. 뉴스 관리 → 공지사항 관리 (`/admin/dcamp/notice`) 접속
2. **"공지사항 작성"** 버튼 클릭
3. 정보 입력 후 **"저장"**

#### 입력 항목

| 필드 | 설명 | 필수 | 입력 예시 |
|------|------|:----:|----------|
| 제목 | 공지사항 제목 | O | "디캠프 배치 26기 모집 안내" |
| 본문 | 공지사항 내용 (에디터) | O | 상세 내용 작성 |
| 카테고리 | 분류 | O | Notice, Report |
| 썸네일 | 대표 이미지 | - | 1200x630px |
| 첨부파일 | 관련 파일 | - | PDF, DOC 등 |
| 게시 상태 | 게시/미게시 | O | 기본값: 미게시 |
| 상단 고정 | 목록 상단 고정 여부 | - | 홍보 옵션 > 목록 맨 위에 고정하기 |

#### 공지사항 카테고리

| 카테고리 | 값 | 용도 |
|----------|-----|------|
| **Notice** | notice | 일반 공지사항 (기본값) |
| **ESG** | report | ESG 리포트, 보고서 |
| **News** | news | 미디어(언론 보도)용 - 미디어 목록에 표시됨 |

> **참고**: 카테고리를 "News"로 설정하면 공지사항이 아닌 **미디어 목록**에 표시됩니다.

### 3.3 공지사항 수정

1. 공지사항 목록에서 제목 클릭
2. **"편집"** 탭 클릭
3. 내용 수정
4. **"저장"** 클릭

### 3.4 공지사항 상단 고정

중요한 공지를 목록 최상단에 고정합니다.

1. 공지사항 편집 페이지
2. **"상단 고정"** 체크박스 선택
3. **"저장"** 클릭

> **참고**: 상단 고정된 공지는 게시일과 관계없이 항상 목록 최상단에 표시됩니다. 여러 개가 고정된 경우 게시일 역순으로 정렬됩니다.

### 3.5 공지사항 삭제

1. 공지사항 편집 페이지
2. 하단 **"삭제"** 버튼 클릭
3. 삭제 확인

> **주의**: 삭제된 콘텐츠는 복구할 수 없습니다. 외부에 노출하고 싶지 않은 경우 **"미게시"**로 변경하여 숨김 처리를 권장합니다.

## 4. 스토리 관리

스타트업 스토리, 인터뷰, 아티클 등의 콘텐츠를 관리합니다.

### 접근 권한

> **참고**: 스토리 관리는 `planning`(기획실)과 `bizops`(BizOps) 역할만 접근 가능합니다.

### 사용자 화면 연결

| 관리자 메뉴 | 사용자 화면 URL | 설명 |
|------------|----------------|------|
| 스토리 관리 | dcamp.kr/news/story | 스토리 목록 페이지 |
| 스토리 상세 | dcamp.kr/news/story/{id} | 스토리 상세 페이지 |

- 관리자에서 스토리를 **게시** 상태로 저장하면 사용자 화면에 노출됩니다.
- **상단 고정(sticky)** 설정된 스토리는 목록 상단 슬라이더에 표시됩니다.

### 사용자 화면 필드 구성

#### 패싯(필터)에 사용되는 필드

| 필터 | 관리자 필드 | 설명 |
|------|-----------|------|
| 카테고리 | 카테고리 (field_category) | 인터뷰/아티클 등 |
| 검색 | 제목 (title) | 제목 내 키워드 검색 |

#### 목록에 표시되는 필드

| 표시 항목 | 관리자 필드 |
|----------|-----------|
| 제목 | 제목 (title) |
| 썸네일 | 대표 이미지 (field_image) |
| 요약 | 본문 요약 (body.summary) |
| 작성일 | 생성일 (created) |

#### 상세 페이지에 표시되는 필드

| 표시 항목 | 관리자 필드 |
|----------|-----------|
| 제목 | 제목 (title) |
| 작성일 | 생성일 (created) |
| 본문 | 본문 (body) |
| 대표 이미지 | 대표 이미지 (field_image) |

### 4.1 스토리 작성

#### 작성 전 확인사항

- [ ] 콘텐츠 기획 및 원고 준비
- [ ] 썸네일 이미지 준비 (1200x630px)
- [ ] 카테고리 결정

#### 작성 절차

1. 뉴스 관리 → 스토리 관리 (`/admin/dcamp/insights`) 접속
2. **"스토리 작성"** 버튼 클릭
3. 정보 입력 후 **"저장"**

#### 입력 항목

| 필드 | 설명 | 필수 | 입력 예시 |
|------|------|:----:|----------|
| 제목 | 스토리 제목 | O | "배치 25기 성공 스토리: A사" |
| 부제목 | 서브 타이틀 | - | "시드 투자 100억 유치의 비결" |
| 본문 | 본문 내용 (에디터) | O | 상세 내용 작성 |
| 본문 요약 | 목록에 표시될 요약 | - | 2~3문장 요약 |
| 카테고리 | 분류 | O | News, Column, Startup |
| 썸네일 | 대표 이미지 | O | 1200x630px |
| 상단 고정 | 슬라이더 노출 여부 | - | 홍보 옵션 > 목록 맨 위에 고정하기 |
| 게시 상태 | 게시/미게시 | O | 기본값: 미게시 |

> **중요**: 상단 고정된 스토리는 슬라이더에 **본문 요약**이 표시됩니다. 고정 게시글은 반드시 본문 요약을 입력하세요.

> **참고**: 스토리 상세 페이지 하단의 "관련 스토리"는 같은 카테고리의 최신 글 4개가 자동으로 표시됩니다.

### 4.2 스토리 카테고리

| 카테고리 | 값 | 설명 |
|----------|-----|------|
| **News** | news | 뉴스 (기본값) |
| **Column** | column | 칼럼, 아티클 |
| **Startup** | startup | 스타트업 스토리 |

## 5. 미디어 관리

외부 언론 보도 링크를 관리합니다. 미디어는 외부 URL로 연결되며, **상세 페이지가 없습니다**.

### 접근 권한

> **참고**: 미디어 관리는 `planning`(기획실)과 `bizops`(BizOps) 역할만 접근 가능합니다.

### 사용자 화면 연결

| 관리자 메뉴 | 사용자 화면 URL | 설명 |
|------------|----------------|------|
| 미디어 관리 | dcamp.kr/news/media | 미디어 목록 페이지 |

- 관리자에서 미디어를 **게시** 상태로 저장하면 사용자 화면에 노출됩니다.
- 사용자가 미디어 항목을 클릭하면 **외부 URL**로 이동합니다. (상세 페이지 없음)
- **상단 고정(sticky)** 설정된 미디어는 목록 최상단에 표시됩니다.

### 사용자 화면 필드 구성

#### 목록에 표시되는 필드

| 표시 항목 | 관리자 필드 |
|----------|-----------|
| 제목 | 제목 (title) |
| 썸네일 | 대표 이미지 (field_image) |
| 요약 | 본문 요약 (body.summary) |
| 작성일 | 생성일 (created) |

> **참고**: 미디어 클릭 시 외부 링크(field_url)로 이동합니다.

### 5.1 미디어 작성

#### 작성 전 확인사항

- [ ] 외부 기사 URL 확보
- [ ] 썸네일 이미지 준비 (1200x630px)
- [ ] 기사 제목 및 요약 준비

#### 작성 절차

1. 뉴스 관리 → 미디어 관리 (`/admin/dcamp/media`) 접속
2. **"미디어 작성"** 버튼 클릭
3. 정보 입력 후 **"저장"**

> **참고**: 미디어는 Notice 타입으로 생성되며, 카테고리가 자동으로 "News"로 설정됩니다.

#### 입력 항목

| 필드 | 설명 | 필수 | 입력 예시 |
|------|------|:----:|----------|
| 제목 | 기사 제목 | O | "디캠프 스타트업 A사, 100억 투자 유치" |
| 외부 링크 | 기사 원문 URL | O | https://news.example.com/article/123 |
| 본문 요약 | 목록에 표시될 요약 | - | 기사 요약 2~3문장 |
| 카테고리 | **News** 선택 | O | News (미디어 분류) |
| 썸네일 | 대표 이미지 | - | 1200x630px |
| 상단 고정 | 목록 상단 고정 | - | 홍보 옵션 > 목록 맨 위에 고정하기 |
| 게시 상태 | 게시/미게시 | O | 기본값: 미게시 |

#### 미디어 상단 고정 시 주의사항

- **상단 고정된 게시글**은 사용자 화면에서 본문 상세 내용을 확인할 수 있습니다.
- **일반 게시글**은 제목 클릭 시 외부 링크로 바로 이동합니다.
- 주요 홍보 게시글에만 선별적으로 상단 고정 기능을 사용하세요.

> **중요**: 상단 고정된 미디어는 목록에 **본문 요약**이 표시됩니다. 고정 게시글은 반드시 본문 요약을 입력하세요.

## 6. 에디터 사용법 (CKEditor)

콘텐츠 본문 작성 시 CKEditor를 사용합니다.

### 6.1 에디터 툴바

```
┌─────────────────────────────────────────────────────────────────────────┐
│ B I U S │ H2 H3 H4 │ ≡ ≡ │ 🔗 📷 📹 │ 📎 │ < > │ ⟲ ⟳ │               │
│ 서식    │ 제목     │ 목록 │ 미디어   │ 파일│ 코드│ 실행취소         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 6.2 기본 서식

| 기능 | 단축키 | 설명 |
|------|--------|------|
| **굵게** | Ctrl+B | 텍스트 강조 |
| *기울임* | Ctrl+I | 이탤릭체 |
| <u>밑줄</u> | Ctrl+U | 밑줄 |
| ~~취소선~~ | - | 취소선 |
| 제목 | - | H2, H3, H4 등 |
| 목록 | - | 순서/비순서 목록 |
| 링크 | Ctrl+K | 하이퍼링크 삽입 |

### 6.3 이미지 삽입

#### 삽입 방법

1. 에디터 툴바에서 **이미지 아이콘** 클릭
2. 이미지 업로드 또는 URL 입력
3. **대체 텍스트 입력** (접근성 - 필수)
4. 크기 및 정렬 설정
5. **"삽입"** 클릭

#### 이미지 설정

| 설정 | 설명 | 권장값 |
|------|------|--------|
| 대체 텍스트 | 이미지 설명 (스크린리더용) | 필수 입력 |
| 너비 | 이미지 너비 | 자동 또는 픽셀 지정 |
| 정렬 | 좌/중앙/우 정렬 | 본문에 맞게 |

### 6.4 동영상 삽입

YouTube, Vimeo 등의 동영상을 삽입할 수 있습니다.

1. 에디터 툴바에서 **미디어 아이콘** 클릭
2. 동영상 URL 입력 (YouTube, Vimeo 등)
3. **"삽입"** 클릭

#### 지원 플랫폼

| 플랫폼 | URL 형식 |
|--------|----------|
| YouTube | https://www.youtube.com/watch?v=... |
| Vimeo | https://vimeo.com/... |

### 6.5 표 삽입

1. 에디터 툴바에서 **표 아이콘** 클릭
2. 행/열 수 설정
3. 표 삽입 후 내용 입력

### 6.6 소스 코드 편집

HTML을 직접 편집해야 하는 경우:

1. 에디터 툴바에서 **"소스"** 버튼 클릭
2. HTML 코드 직접 편집
3. 다시 **"소스"** 클릭하여 편집 모드로 복귀

> **주의**: 소스 코드 편집은 HTML에 익숙한 경우에만 사용하세요. 잘못된 코드는 레이아웃 깨짐을 유발할 수 있습니다.

## 8. 자주 묻는 질문 (FAQ)

### Q1. 콘텐츠를 잘못 삭제했어요. 복구할 수 있나요?

**A**: 삭제된 콘텐츠는 복구가 어렵습니다. 삭제 대신 "미게시" 처리를 권장합니다. 긴급한 경우 시스템 관리자에게 문의하세요.

### Q2. 이미지가 업로드되지 않아요.

**A**: 다음을 확인해주세요.
- 파일 형식: JPG, PNG만 지원
- 파일 용량: 20MB 이하
- 파일명: 특수문자 없이 영문/숫자만

### Q3. 스토리/미디어 메뉴가 안 보여요.

**A**: 스토리와 미디어 관리는 `planning`(기획실)과 `bizops`(BizOps) 역할만 접근 가능합니다. 권한이 필요한 경우 관리자에게 요청하세요.
