## 1. 회원 관리 개요

> **중요!** 일반 회원과 관리자 계정은 완전히 분리되어 있습니다. 관리자 시스템(admin.dcamp.kr)에서는 **관리자 계정만** 관리합니다.

### 계정 유형과 관리 범위

| 구분 | 일반 회원 (`user.user`) | 관리자 (`user.manager`) |
|------|------------------------|------------------------|
| **관리 위치** | 관리 대상 아님 (직접 관리 불가) | admin.dcamp.kr에서 관리 |
| **가입 경로** | dcamp.kr에서 직접 가입 | 관리자가 직접 생성 |
| **접속 사이트** | dcamp.kr | admin.dcamp.kr |
| **비밀번호 재설정** | 본인이 직접 처리 | 관리자가 재설정 가능 |

### 관리자가 할 수 있는 것과 없는 것

| 가능한 작업 | 불가능한 작업 |
|------------|--------------|
| 관리자 계정 생성/수정/차단 | 일반 회원 정보 직접 조회 |
| 관리자 역할(부서) 지정 | 일반 회원 비밀번호 재설정 |
| 관리자 비밀번호 재설정 | 일반 회원 강제 탈퇴 처리 |
| 퇴사자 계정 비활성화 | 일반 회원 계정 생성 |

> **참고**: 일반 회원 관련 문의는 사용자가 직접 dcamp.kr에서 처리하도록 안내해주세요. 프로그램 신청 내역 등 활동 데이터는 해당 프로그램 관리 메뉴에서 확인할 수 있습니다.

## 2. 관리자 회원 목록 조회

### 접근 경로

```
관리자 메뉴 → People (사용자) → /admin/people
```

### 접근 권한

| 역할 | 목록 조회 | 상세 조회 | 편집 | 역할 변경 |
|------|:--------:|:--------:|:----:|:--------:|
| Administrator | ✓ | ✓ | ✓ | ✓ |
| planning (기획실) | ✓ | ✓ | ✓ | ✓ |
| 기타 부서 | - | - | - | - |

> **참고**: 회원 관리 권한은 `Administrator`와 `planning`(기획실) 역할에만 부여됩니다.

### 회원 목록 화면

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 이름 | 사용자 표시명 | 클릭 시 상세 페이지 이동 |
| 이메일 | 계정 이메일 주소 | 로그인 ID로 사용 |
| 상태 | 활성/차단 여부 | 활성(Active) / 차단됨(Blocked) |
| 역할 | 부여된 역할 목록 | 복수 역할 가능 |
| 최근 접속 | 마지막 로그인 시간 | 접속 기록 확인용 |
| 가입일 | 계정 생성일 | - |

### 회원 검색 및 필터

```
┌─────────────────────────────────────────────────────────────┐
│  이름/이메일 검색: [________________________] [검색]         │
│                                                             │
│  역할 필터: [전체 ▼]    상태 필터: [전체 ▼]                  │
└─────────────────────────────────────────────────────────────┘
```

- **이름/이메일 검색**: 검색창에 입력하여 특정 사용자 검색
- **역할 필터**: administrator, planning, investment 등 특정 역할의 회원만 조회
- **상태 필터**: 활성(Active) / 차단됨(Blocked) 회원 필터링

### 필터 활용 예시

| 목적 | 필터 설정 |
|------|----------|
| 퇴사자 목록 확인 | 상태: 차단됨 |
| 투자실 담당자 확인 | 역할: investment |
| 특정 인물 검색 | 이름 또는 이메일 입력 |

## 3. 새 관리자 계정 생성

### 생성 전 확인사항

- [ ] Cloudflare Access에 해당 이메일이 등록되어 있는가?
- [ ] 어떤 부서/역할을 부여할 것인가?
- [ ] 기존에 동일 이메일로 계정이 있는가?

> **중요**: Cloudflare Access에 먼저 등록되어 있어야 관리자 페이지에 접근할 수 있습니다. Cloudflare Access 등록은 시스템 관리자에게 요청하세요.

### 생성 절차

1. `/admin/people` 접속
2. **"+ 사용자 추가"** 버튼 클릭
3. 필수 정보 입력:

| 필드 | 입력 내용 | 비고 |
|------|----------|------|
| 이메일 주소 | 업무용 이메일 | 로그인 ID로 사용, Cloudflare Access 등록 이메일과 동일해야 함 |
| 사용자명 | 표시 이름 | 한글 이름 권장 |
| 비밀번호 | 초기 비밀번호 | 8자 이상, 특수문자 포함 권장 |
| 상태 | 활성 | 기본값 유지 |

4. **역할 지정** (부서에 맞는 역할 선택):

| 부서 | 선택할 역할 |
|------|-----------|
| 기획실 | `planning` |
| 투자실 | `investment` |
| 글로벌사업실 | `global_business` |
| 사업실 | `business` |
| BizOps | `bizops` |
| Growth | `growth` |
| Resource | `resource` |
| Space/경영본부 | `space` |

5. **"계정 만들기"** 버튼 클릭

### 생성 후 안내사항

새로 생성된 계정 담당자에게 안내할 내용:

```
[관리자 계정 발급 안내]

1. 접속 주소: https://admin.dcamp.kr
2. 로그인 이메일: (발급된 이메일)
3. 초기 비밀번호: (설정한 비밀번호)

* 첫 로그인 후 비밀번호를 변경해주세요.
* Cloudflare 이메일 인증 → Drupal 로그인 순서로 진행됩니다.
* 문의사항은 기획실로 연락해주세요.
```

## 4. 관리자 계정 관리

### 관리자 상세 조회

1. 회원 목록에서 이름 클릭
2. 관리자 프로필 페이지로 이동
3. 확인 가능 정보:
   - 기본 정보 (이름, 이메일)
   - 부여된 역할 (부서)
   - 가입일 및 최근 접속일
   - 계정 상태

### 관리자 정보 수정

1. 관리자 상세 페이지에서 **"편집"** 탭 클릭
2. 수정 가능 항목:

| 항목 | 수정 가능 | 비고 |
|------|:--------:|------|
| 이메일 주소 | ✓ | 변경 시 Cloudflare Access도 함께 변경 필요 |
| 사용자명 | ✓ | 표시 이름 |
| 비밀번호 | ✓ | 재설정 가능 |
| 역할 | ✓ | 부서 변경 시 |
| 상태 | ✓ | 활성/차단 |

3. **"저장"** 버튼 클릭

### 관리자 역할 변경

부서 이동이나 업무 변경 시 역할을 수정합니다.

1. 대상 관리자 계정 편집 페이지 접근
2. **"역할"** 섹션에서 역할 수정:
   - 역할 추가: 해당 역할 체크박스 선택
   - 역할 제거: 해당 역할 체크박스 해제
3. **"저장"** 버튼 클릭

> **참고**: 복수 역할 부여가 가능합니다. 예를 들어, 기획실 담당자가 투자 관련 업무도 병행하는 경우 `planning`과 `investment` 역할을 모두 부여할 수 있습니다.

### 퇴사자 계정 처리

퇴사자 발생 시 **반드시** 계정을 삭제해야 합니다.

#### 처리 절차

1. Cloudflare Access에서 해당 이메일 제거 요청 (시스템 관리자에게)
2. 해당 계정 편집 페이지 접근
3. **"계정 삭제"** 버튼 클릭
4. 삭제 확인

#### 주의사항

| 구분 | 내용 |
|------|------|
| **즉시 처리** | 퇴사일 당일 또는 익일 이내 처리 권장 |
| **Cloudflare 먼저** | Drupal 삭제 전 Cloudflare Access에서 먼저 제거 |

> **보안 주의**: 퇴사자 계정 처리가 지연되면 보안 사고로 이어질 수 있습니다. 퇴사 확정 즉시 처리해주세요.

## 5. 비밀번호 관리

### 비밀번호 정책

| 항목 | 정책 |
|------|------|
| 최소 길이 | 8자 이상 |
| 복잡성 | 특수문자 포함 권장 |
| 로그인 실패 | 5회 실패 시 계정 잠금 |
| 변경 주기 | 정기 변경 권장 (3개월) |

### 비밀번호 재설정 (관리자가 직접)

관리자가 비밀번호를 분실한 경우:

**방법 1: 직접 재설정**
1. 해당 관리자 편집 페이지 접근
2. "비밀번호" 필드에 새 비밀번호 입력
3. "저장" 클릭
4. 본인에게 새 비밀번호 안내

**방법 2: 재설정 링크 발송**
1. 해당 관리자 편집 페이지 접근
2. "비밀번호 재설정 이메일 발송" 옵션 클릭
3. 본인 이메일로 재설정 링크 발송됨
4. 본인이 직접 새 비밀번호 설정

> **권장**: 보안상 방법 2(재설정 링크 발송)를 권장합니다. 관리자가 직접 비밀번호를 알지 않아도 됩니다.

### 계정 잠금 해제

5회 로그인 실패로 계정이 잠긴 경우:

1. 해당 관리자 편집 페이지 접근
2. 잠금 상태 해제 (있는 경우)
3. 필요 시 비밀번호 재설정
4. "저장" 클릭

## 6. 회원 일괄 처리

여러 관리자 계정을 한 번에 처리해야 하는 경우 사용합니다.

### 일괄 작업 방법

1. 회원 목록에서 대상 회원 **체크박스 선택**
2. 상단 **"작업"** 드롭다운에서 원하는 작업 선택:

| 작업 | 설명 | 사용 예 |
|------|------|---------|
| 사용자 차단 | 선택된 계정 일괄 차단 | 퇴사자 다수 처리 |
| 사용자 차단 해제 | 선택된 계정 일괄 활성화 | - |
| 역할 추가 | 선택된 계정에 역할 일괄 추가 | 새 프로젝트 팀 구성 |
| 역할 제거 | 선택된 계정에서 역할 일괄 제거 | 프로젝트 종료 시 |

3. **"적용"** 버튼 클릭

> **주의**: 일괄 처리는 되돌리기 어려우므로 신중하게 진행하세요.

## 7. 회원 데이터 내보내기

관리자 목록을 파일로 다운로드해야 하는 경우 사용합니다.

> **개인정보 보호**: 회원 데이터에는 개인정보가 포함되어 있으므로, 다운로드 시 **사유 입력이 필수**이며 모든 다운로드 이력이 기록됩니다.

### 내보내기 방법

1. 회원 목록 페이지 접근
2. 필터 적용 (필요시)
3. **"내보내기"** 버튼 클릭
4. **다운로드 사유 입력** (필수)
5. 형식 선택 (CSV, Excel 등)
6. 다운로드

### 다운로드 사유 입력

개인정보 보호를 위해 다운로드 시 사유를 반드시 입력해야 합니다.

| 항목 | 설명 |
|------|------|
| **사유 입력** | 다운로드 목적을 구체적으로 작성 (예: "2026년 1월 정기 인원 현황 보고") |
| **이력 기록** | 다운로드 일시, 담당자, 사유가 자동으로 기록됨 |
| **감사 추적** | 관리자가 다운로드 이력을 조회할 수 있음 |

### 내보내기 항목

| 항목 | 포함 여부 |
|------|:--------:|
| 사용자 ID | ✓ |
| 이름 | ✓ |
| 이메일 | ✓ |
| 역할 | ✓ |
| 상태 | ✓ |
| 가입일 | ✓ |
| 최근 접속일 | ✓ |

### 다운로드 이력 관리

| 기록 항목 | 설명 |
|----------|------|
| 다운로드 일시 | 파일 다운로드 시점 |
| 담당자 | 다운로드를 실행한 관리자 계정 |
| 다운로드 사유 | 입력한 사유 내용 |
| 다운로드 범위 | 적용된 필터 조건 및 건수 |

> **주의**: 다운로드 이력은 정기적으로 감사되며, 부적절한 사유나 과도한 다운로드는 보안 점검 대상이 될 수 있습니다. 업무 목적으로만 사용하고, 사용 후 파일을 삭제해주세요.

## 8. 자주 묻는 질문 (FAQ)

### Q1. 일반 회원이 비밀번호를 잊어버렸다고 합니다.

**A**: dcamp.kr 로그인 페이지에서 "비밀번호 찾기" 기능을 이용하도록 안내해주세요. 관리자가 일반 회원의 비밀번호를 재설정할 수 없습니다.

### Q2. 퇴사자 계정은 어떻게 처리하나요?

**A**: 퇴사자 계정은 **삭제**해야 합니다. 계정 삭제 전 Cloudflare Access에서도 해당 이메일을 제거해주세요.

### Q3. 한 사람에게 여러 역할을 줄 수 있나요?

**A**: 네, 복수 역할 부여가 가능합니다. 해당 역할들의 권한이 합쳐져 적용됩니다.

### Q4. Cloudflare Access 등록은 누가 하나요?

**A**: 시스템 관리자(스컹크웍스스튜디오)에게 요청해주세요. Drupal 계정 생성 전에 먼저 Cloudflare Access에 등록되어 있어야 합니다.
