## 1. 문의 관리 개요

디캠프 웹사이트(dcamp.kr/contact)를 통해 접수되는 사용자 문의를 관리합니다.

### 접근 경로

```
DCAMP 관리자 메뉴 → 문의 관리
/admin/dcamp/contact-inquiry
```

### 데이터 보관

> **중요**: 문의 데이터는 **답변 완료 후 30일**이 지나면 자동으로 삭제됩니다.

---

## 2. 사용자 화면 - 문의 페이지

사용자가 문의하는 페이지입니다.

### 페이지 경로

```
https://dcamp.kr/contact
```

### 문의 유형별 연락처

문의 페이지 하단에 문의 유형별 연락처가 안내되어 있습니다.

| 문의 유형 | 연락 방법 | 링크/이메일 |
|----------|----------|-------------|
| **일반 문의** | 문의하기 버튼 | `/contact/inquiry` (내부 문의 폼) |
| **제휴문의** | 문의하기 버튼 | Google Forms (외부 링크) |
| **대관 신청** | 바로가기 버튼 | taapspace.kr (외부 대관 시스템) |
| **디캠프 배치 문의** | 이메일 | batch@dcamp.kr |
| **글로벌 협업 문의** | 이메일 | global@dcamp.kr |

> **참고**: 일반 문의만 내부 문의 폼(`/contact/inquiry`)을 통해 접수됩니다. 제휴문의는 Google Forms, 대관 신청은 taapspace.kr 외부 시스템을 사용합니다.

### 문의 안내 사항

문의 페이지에 다음 안내 사항이 표시됩니다:

- 문의하신 내용은 담당자가 검토 후, 보통 2-3 영업일(최대 7일) 이내 답변해 드립니다.
- 작성하신 문의내용은 수정이 불가능 합니다.
- **작성하신 문의 내역은 개인정보보호를 위해 답변 완료 후 30일이 지나면 자동 삭제됩니다.**
- 광고성 또는 비방용 게시글 등 운영취지와 부합되지 않는 글들은 관리자에 의하여 삭제될 수 있습니다.

## 3. 사용자 화면 - 문의 폼

일반 문의를 작성하는 폼 화면입니다.

### 폼 경로

```
https://dcamp.kr/contact/inquiry
```

### 입력 필드

| 필드 | 필수 | 설명 | 예시 |
|------|:----:|------|------|
| **이름** | ✓ | 문의자 이름 | 홍길동 |
| **이메일** | ✓ | 연락 이메일 | hong@example.com |
| **휴대전화번호** | ✓ | 연락처 | 010-1234-5678 |
| **제목** | ✓ | 문의 제목 | 프로그램 참여 문의 |
| **문의 내용** | ✓ | 상세 문의 내용 | 문의 본문 |
| **첨부파일** | - | 첨부 파일 (PDF, TXT) | 사업계획서.pdf |
| **개인정보 동의** | ✓ | 개인정보 수집 이용 동의 | 체크 |

### 첨부파일 제한

| 항목 | 제한 |
|------|------|
| 파일 형식 | PDF, TXT |
| 최대 용량 | 20MB |
| 최대 개수 | 1개 |

### 제출 완료

문의 제출 후 확인 메시지가 표시됩니다:
- **제목**: "문의가 접수되었습니다"
- **메시지**: "문의하신 내용은 담당자가 검토 후, 보통 2-3 영업일(최대 7일) 이내 답변해 드립니다."

## 4. 관리자 화면 - 문의 목록

접수된 문의 목록을 조회합니다.

### 접근 경로

```
DCAMP 관리자 메뉴 → 문의 관리
/admin/dcamp/contact-inquiry
```

### 목록 컬럼

| 컬럼 | 설명 |
|------|------|
| **번호** | 문의 고유 ID |
| **이름** | 문의자 이름 |
| **이메일** | 문의자 이메일 |
| **전화번호** | 문의자 연락처 |
| **제목** | 문의 제목 |
| **상태** | 대기 / 답변완료 |
| **등록일** | 문의 접수 일시 |
| **관리** | 상세보기 버튼 |

### 필터 기능

| 필터 | 설명 | 옵션 |
|------|------|------|
| **검색** | 이름, 이메일, 전화번호, 제목 검색 | 키워드 입력 |
| **상태** | 처리 상태별 필터 | 전체 / 대기 / 답변완료 |

### 상태 구분

| 상태 | 설명 |
|------|------|
| **대기** | 아직 답변하지 않은 문의 |
| **답변완료** | 답변이 저장된 문의 |

## 5. 관리자 화면 - 문의 상세

개별 문의의 상세 내용을 확인하고 답변합니다.

### 접근 방법

1. 문의 목록에서 **"상세보기"** 버튼 클릭
2. 또는 직접 URL 접근: `/admin/dcamp/contact-inquiry/{submission_id}`

### 상세 정보

| 항목 | 설명 |
|------|------|
| **이름** | 문의자 이름 |
| **이메일** | 문의자 이메일 |
| **전화번호** | 문의자 연락처 |
| **제목** | 문의 제목 |
| **문의 내용** | 문의 본문 |
| **첨부파일** | 첨부된 파일 (클릭 시 다운로드) |
| **개인정보 동의** | 동의함 / 동의하지 않음 |
| **등록일** | 문의 접수 일시 |

## 6. 문의 답변

문의에 대한 답변을 작성하고 이메일로 발송합니다.

### 답변 작성

1. 문의 상세 페이지 하단 **"답변"** 섹션 확인
2. 답변 내용 입력
3. **"답변 저장"** 버튼 클릭

### 답변 저장 시 동작

| 동작 | 설명 |
|------|------|
| **답변 저장** | 시스템에 답변 내용 저장 |
| **상태 변경** | "대기" → "답변완료"로 자동 변경 |
| **이메일 발송** | 문의자에게 답변 이메일 자동 발송 |

> **참고**: 이메일은 **최초 답변 저장 시에만** 발송됩니다. 답변 수정 시에는 이메일이 발송되지 않습니다.

### 답변 수정/삭제

| 작업 | 방법 |
|------|------|
| **답변 수정** | 답변 내용 수정 후 "답변 저장" 클릭 |
| **답변 삭제** | "답변 삭제" 버튼 클릭 (상태가 "대기"로 변경됨) |

### 답변 이메일 내용

발송되는 이메일에는 다음 정보가 포함됩니다:

- 문의자 이름
- 문의 제목
- 문의 내용
- 문의 일시
- 답변 내용
- 답변 일시

## 9. 자주 묻는 질문 (FAQ)

### Q1. 답변 이메일이 발송되지 않아요.

**A**: 다음을 확인해주세요.
- 문의자 이메일 주소가 올바른지 확인
- 최초 답변인지 확인 (수정 시에는 이메일 미발송)
- 이메일 서비스 상태 확인 (시스템 관리자 문의)

### Q2. 삭제된 문의를 복구할 수 있나요?

**A**: 30일 경과 후 자동 삭제된 문의는 복구할 수 없습니다.

### Q3. 문의자에게 직접 연락하려면?

**A**: 문의 상세에서 이메일 또는 전화번호를 확인하여 직접 연락할 수 있습니다.

### Q4. 첨부파일이 열리지 않아요.

**A**: 첨부파일 링크를 클릭하면 다운로드됩니다. PDF 뷰어가 설치되어 있는지 확인해주세요.
