## 1. 사용자 화면 관리 개요

디캠프 웹사이트(dcamp.kr)의 메인화면과 각종 페이지의 구성 요소를 관리합니다. 이 기능은 **별도의 관리 화면**으로 구현되어 있어 일반 Drupal 관리 화면과 다른 인터페이스를 가집니다.

### 접근 경로

```
DCAMP 관리자 메뉴 → 웹사이트 관리
```

### 웹사이트 관리 하위 메뉴

| 메뉴 | 설명 |
|------|------|
| **메인화면** | 홈페이지 메인 구성 |
| **소개** | About 페이지 설정 |
| **Program** | 프로그램 페이지 설정 |
| **Featured Contents** | 주요 콘텐츠 관리 |
| **스타트업** | 스타트업 페이지 관리 |
| **영문 메인 (EN)** | 영문 메인 페이지 설정 (연동 예정) |
| **일본어 메인 (JP)** | 일본어 메인 페이지 설정 (연동 예정) |

### 접근 권한

> **참고**: 메인화면 관리 기능은 모든 부서 역할에서 접근 가능합니다. 단, 수정 시에는 담당 부서 확인 후 진행해주세요.

| 역할 | 접근 | 비고 |
|------|:----:|------|
| Administrator | ✓ | 모든 기능 |
| 모든 부서 역할 | ✓ | 조회 및 수정 가능 |

## 2. 메인화면

### 접근 경로

```
웹사이트 관리 → 메인화면
/admin/dcamp/main
```

### 메인화면 구조

```
┌─────────────────────────────────────────────────────────────┐
│                     히어로 섹션 (Hero)                        │
│              팝업 박스 + KV (메인 비주얼)                      │
├─────────────────────────────────────────────────────────────┤
│                     What We Do 섹션                          │
│              dcamp 활동 소개 카드 (최대 4개)                   │
├─────────────────────────────────────────────────────────────┤
│                     프로그램 섹션                             │
│              현재 모집 중인 프로그램                          │
├─────────────────────────────────────────────────────────────┤
│                     스타트업 섹션                             │
│              주요 스타트업 로고                               │
├─────────────────────────────────────────────────────────────┤
│                     뉴스 섹션                                 │
│              고정 뉴스 + 그리드 뉴스                          │
├─────────────────────────────────────────────────────────────┤
│                     Impact 섹션                              │
│              dcamp 성과 지표                                 │
└─────────────────────────────────────────────────────────────┘
```

### 2.1 히어로 섹션 (Hero)

메인 상단의 대표 영역입니다. **팝업 박스**와 **KV (Key Visual)** 두 가지 요소로 구성됩니다.

#### 2.1.1 팝업 박스 (Popup Box)

메인화면 우측 상단에 표시되는 작은 배너입니다.

| 항목 | 설명 | 입력 예시 |
|------|------|----------|
| 제목 | 팝업 타이틀 | "dcamp batch 17기 모집" |
| 이미지 | 팝업 이미지 | 400x300px JPG/PNG |
| 링크 | 클릭 시 이동 URL | /program/batch |

#### 2.1.2 KV (Key Visual)

메인화면 중앙의 메인 비주얼 영역입니다.

| 항목 | 설명 | 입력 예시 |
|------|------|----------|
| 타이틀 | 메인 제목 | "스타트업의 성장을 함께합니다" |
| 서브타이틀 | 부제목 | "dcamp는 스타트업 생태계를 지원합니다" |
| 링크 | 클릭 시 이동 URL | /about/who-we-are |
| 미디어 | 배경 영상 또는 이미지 | MP4 영상 또는 JPG 이미지 |

#### 미디어 가이드

| 유형 | 권장 사양 | 비고 |
|------|----------|------|
| **영상** | 1920x1080px, MP4, 15초 이내, 10MB 이하 | 기본 권장, 자동 재생 |
| **이미지** | 1920x1080px, JPG, 2MB 이하 | 영상 대체용 |

### 2.2 What We Do 섹션

dcamp의 주요 활동을 소개하는 카드형 섹션입니다. 최대 4개 항목을 설정할 수 있습니다.

| 항목 | 설명 | 입력 예시 |
|------|------|----------|
| 제목 | 카드 타이틀 | "Accelerating" |
| 설명 | 카드 설명 텍스트 | "스타트업 성장 가속화 프로그램" |
| 이미지 | 카드 배경 이미지 | 600x400px JPG |
| 링크 | 클릭 시 이동 URL | /program/batch |

#### 관리 방법

1. "항목 추가" 버튼 클릭 (최대 4개)
2. 제목, 설명, 이미지, 링크 입력
3. 드래그 앤 드롭으로 순서 변경
4. X 버튼으로 항목 삭제

### 2.3 프로그램 섹션

현재 모집 중인 프로그램 목록을 표시합니다.

| 항목 | 설명 | 설정 옵션 |
|------|------|----------|
| 표시 프로그램 | 노출할 프로그램 선택 | 포트폴리오에서 수동 선택 |

#### 관리 방법

1. "프로그램 선택" 버튼 클릭
2. 모달에서 프로그램 검색/선택
3. 확인 클릭 → 자동 저장

### 2.4 스타트업 섹션

주요 스타트업 로고를 표시합니다.

| 항목 | 설명 | 설정 옵션 |
|------|------|----------|
| 표시 스타트업 | 노출할 스타트업 선택 | 포트폴리오에서 수동 선택 |

#### 관리 방법

1. "스타트업 선택" 버튼 클릭
2. 모달에서 스타트업 검색/선택
3. 확인 클릭 → 자동 저장

### 2.5 뉴스 섹션

최신 뉴스를 **고정 뉴스**와 **그리드 뉴스** 두 영역으로 나눠 표시합니다.

| 영역 | 설명 | 최대 개수 |
|------|------|:--------:|
| **고정 뉴스 (Pinned)** | 상단 강조 영역 | 1개 |
| **그리드 뉴스 (Grid)** | 하단 목록 영역 | 3개 |

#### 관리 방법

1. "고정 뉴스 선택" 또는 "그리드 뉴스 선택" 버튼 클릭
2. 모달에서 공지사항/인사이트 검색/선택
3. 확인 클릭 → 자동 저장

> **참고**: 뉴스 소스는 공지사항(notice)과 인사이트(insight) 콘텐츠입니다.

### 2.6 Impact 섹션

dcamp의 성과 지표를 표시하는 섹션입니다.

| 항목 | 설명 | 입력 예시 |
|------|------|----------|
| 기준 연도 | 성과 기준 연도 | "2024" |

#### Impact 항목 설정

각 성과 지표별로 다음 항목을 입력합니다:

| 항목 | 설명 | 입력 예시 |
|------|------|----------|
| 제목 | 지표 타이틀 | "누적 투자 유치" |
| 라벨 | 지표 부제목 | "포트폴리오사 합산" |
| 값 | 숫자 값 | 50000 |
| 단위 | 표시 단위 | "억원" |
| 이미지 | 아이콘/이미지 | 200x200px PNG |

#### 관리 방법

1. "항목 추가" 버튼 클릭
2. 제목, 라벨, 값, 단위, 이미지 입력
3. X 버튼으로 항목 삭제

### 메인화면 저장

- 대부분의 필드는 **자동 저장**됩니다 (입력 후 포커스 해제 시)
- 엔티티 선택(스타트업, 뉴스 등)은 선택 즉시 자동 저장됩니다

> **참고**: 저장 후 캐시로 인해 즉시 반영되지 않을 수 있습니다. 몇 분 후 확인하거나 캐시를 갱신하세요.

## 3. 소개 (About)

About 페이지의 설정을 관리합니다.

### 접근 경로

```
웹사이트 관리 → 소개
```

### 설정 가능한 페이지

| 페이지 | 설명 | 사용자 화면 경로 |
|--------|------|-----------------|
| Who we are | 디캠프 소개 | /about/who-we-are |
| What we do | 활동 소개 | /about/what-we-do |

### 3.1 Who we are

디캠프 소개 페이지의 하단 섹션을 관리합니다.

```
웹사이트 관리 → 소개 → Who we are
/admin/dcamp/pages/who-we-are
```

#### 설정 항목

| 항목 | 설명 | 비고 |
|------|------|------|
| **Partners** | 파트너사 로고 목록 | 로고 이미지 + 파트너명 |
| ~~**Insights**~~ | ~~관련 인사이트 선택~~ | 현재 숨김 처리 |

#### Partners 관리

- **로고 추가**: "로고 추가" 버튼 클릭 → 이미지 업로드 → 파트너명 입력
- **로고 삭제**: 로고에 마우스 오버 → 삭제 버튼 클릭
- 권장 이미지: 400 x 200px, PNG (투명 배경)

### 3.2 What we do

활동 소개 페이지의 프로그램 아코디언을 관리합니다.

```
웹사이트 관리 → 소개 → What we do
/admin/dcamp/pages/what-we-do
```

#### 설정 항목

| 항목 | 설명 | 비고 |
|------|------|------|
| **프로그램 아코디언** | 프로그램 소개 항목 (최대 4개) | 제목, 본문, 링크 |

#### 아코디언 관리

- **항목 추가**: "항목 추가" 버튼 클릭 (최대 4개)
- **항목 삭제**: 각 항목의 삭제 버튼 클릭
- 각 항목별 입력 필드:
  - **제목**: 프로그램 이름
  - **본문 내용**: 프로그램 설명
  - **링크 URL**: 클릭 시 이동할 경로 (예: /program/batch)

> **참고**: Insights 섹션은 현재 story로 명칭이 변경되어 숨김 처리 중입니다.

## 5. Featured Contents

메인화면 메뉴 영역에 표시될 주요 콘텐츠를 선택합니다.

### 접근 경로

```
웹사이트 관리 → Featured Contents
/admin/dcamp/featured-contents
```

### 관리 항목

| 항목 | 설명 | 최대 개수 |
|------|------|:--------:|
| **Program** | 메뉴에 표시할 프로그램 | 4개 |
| **News** | 메뉴에 표시할 뉴스/공지 | 4개 |

### 5.1 Program

Event 엔티티에서 applicant, application 타입을 선택합니다.

#### 관리 방법

1. "Program 선택" 버튼 클릭
2. 모달에서 프로그램 검색/선택 (최대 4개)
3. "확인" 클릭 → 자동 저장

#### 링크 설정

선택된 각 프로그램에 커스텀 링크를 추가할 수 있습니다.

- **링크 추가**: 프로그램 카드 하단 "링크 추가" 클릭 → URL 입력 → 저장
- **링크 수정**: 기존 링크의 수정 아이콘 클릭
- **링크 삭제**: 링크의 삭제 아이콘 클릭

#### 프로그램 제거

- 프로그램 카드 우측 상단 X 버튼 클릭

### 5.2 News

Node에서 insight, notice 타입을 선택합니다.

#### 관리 방법

1. "News 선택" 버튼 클릭
2. 모달에서 뉴스/공지 검색/선택 (최대 4개)
3. "확인" 클릭 → 자동 저장

#### 뉴스 제거

- 뉴스 카드 우측 상단 X 버튼 클릭

> **참고**: Featured Contents에서 제거해도 원본 콘텐츠(프로그램, 뉴스)는 삭제되지 않습니다. 단순히 메뉴 노출에서 제외됩니다.

## 6. 스타트업

스타트업 목록 페이지(/startups)의 상단 배너를 관리합니다.

### 접근 경로

```
웹사이트 관리 → 스타트업
/admin/dcamp/startups
```

### 관리 항목

스타트업 페이지 상단에 표시되는 배너를 설정합니다.

| 항목 | 설명 | 입력 예시 |
|------|------|----------|
| **서브 타이틀** | 배너 상단 작은 텍스트 | "Portfolio" |
| **타이틀** | 배너 메인 제목 | "함께 성장하는 스타트업" |
| **링크** | 클릭 시 이동 URL | /about/who-we-are |
| **이미지** | 배너 배경 이미지 | 1920x600px JPG |

### 배너 이미지 가이드

| 항목 | 권장 사양 |
|------|----------|
| 크기 | 1920 x 600px |
| 형식 | JPG, PNG |
| 용량 | 2MB 이하 |
| 비고 | 중요 요소가 중앙에 오도록 배치

### 저장

1. 각 필드 입력
2. **"저장"** 버튼 클릭
3. 저장 완료 메시지 확인

> **참고**: 스타트업 목록의 필터(산업 분야, 투자 단계 등) 및 정렬은 사용자 화면에서 자동으로 제공됩니다. 별도의 관리자 설정은 없습니다.

## 9. 자주 묻는 질문 (FAQ)

### Q1. 변경 사항이 사이트에 반영되지 않아요.

**A**: 캐시 문제일 수 있습니다.
1. 브라우저 강력 새로고침 (Ctrl+Shift+R / Cmd+Shift+R)
2. 5분 정도 대기 후 다시 확인
3. 계속 안 되면 캐시 수동 갱신

### Q2. 이미지가 업로드되지 않아요.

**A**: 다음을 확인해주세요.
- 파일 형식: JPG, PNG만 지원
- 파일 용량: 권장 용량 이하
- 파일명: 특수문자 없이 영문/숫자만

### Q3. 히어로 영상이 재생되지 않아요.

**A**: 
- 영상 형식: MP4만 지원
- 영상 용량: 10MB 이하 권장
- 영상 길이: 15초 이내 권장
- 브라우저 자동재생 정책으로 무음 영상만 자동재생

### Q4. 모바일에서 레이아웃이 깨져요.

**A**: 
- 이미지 크기가 너무 큰지 확인
- 텍스트 길이가 너무 긴지 확인
