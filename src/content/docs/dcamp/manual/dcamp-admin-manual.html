시스템 개요

1. 디캠프(dcamp) 소개

디캠프는 스타트업과 투자사를 연결하고, 다양한 프로그램과 행사를 통해 사람과 정보 공유를 촉진하여 스타트업의 성장을 지원하는 플랫폼입니다.

2. 관리자 시스템 개요

DCAMP-ADMIN은 디캠프 웹사이트의 헤드리스 CMS(Content Management System) 백엔드입니다.

헤드리스 아키텍처란?

"주방(기능)과 홀(서비스)의 분리"

기존 CMS(Monolithic)는 백엔드와 프론트엔드가 하나의 시스템에 묶여있어 확장이 어려웠습니다. 헤드리스 구조에서는 각자의 역할에 집중하여 더 나은 서비스를 제공합니다.

  • 프론트엔드 (Front): 사용자에게 보여지는 디캠프 웹사이트

2. 로그인

접속 URL

관리자 사이트: https://admin.dcamp.kr

다중 보안 레이어 (3단계 로그인)

관리자 페이지는 3단계 보안 레이어로 보호됩니다.

Step 1. Cloudflare Access (MFA)

관리자 도메인 접근 시 1차 검증이 수행됩니다.

  1. admin.dcamp.kr 접속
  2. Cloudflare Access 인증 화면 표시
  3. 등록된 이메일로 인증 코드 수신
  4. 인증 코드 입력하여 통과
  • 이메일 인증 필수
  • 사전 등록자만 허용 (일반 사용자는 URL을 알아도 접근 불가)

Step 2. Drupal Login

Cloudflare 인증 통과 후 시스템 로그인을 진행합니다.

  1. 로그인 페이지에서 이메일과 비밀번호 입력
  2. "로그인" 버튼 클릭
  • 5회 실패 시 계정 잠금
  • 소셜 로그인 불가 (이메일/비밀번호만 허용)

Step 3. 세션 제어

로그인 이후에도 지속적인 보안 상태가 모니터링됩니다.

  • 30분 타임아웃: 무활동 시 자동 로그아웃
  • 동시접속 차단: 다른 기기에서 로그인 시 기존 세션 종료

비밀번호 재설정

  1. 로그인 페이지에서 "비밀번호 찾기" 클릭
  2. 등록된 이메일 주소 입력
  3. 이메일로 발송된 재설정 링크 클릭
  4. 새 비밀번호 설정

참고: Cloudflare Access 인증을 먼저 통과해야 비밀번호 재설정 페이지에 접근할 수 있습니다.

Q1. 일반 회원이 비밀번호를 잊어버렸다고 합니다.

A: dcamp.kr 로그인 페이지에서 "비밀번호 찾기" 기능을 이용하도록 안내해주세요. 관리자가 일반 회원의 비밀번호를 재설정할 수 없습니다.

Q2. 퇴사자 계정은 어떻게 처리하나요?

A: 퇴사자 계정은 삭제해야 합니다. 계정 삭제 전 Cloudflare Access에서도 해당 이메일을 제거해주세요.

Q3. 한 사람에게 여러 역할을 줄 수 있나요?

A: 네, 복수 역할 부여가 가능합니다. 해당 역할들의 권한이 합쳐져 적용됩니다.

Q4. Cloudflare Access 등록은 누가 하나요?

A: 시스템 관리자(스컹크웍스스튜디오)에게 요청해주세요. Drupal 계정 생성 전에 먼저 Cloudflare Access에 등록되어 있어야 합니다.

지원서(웹폼) 연결

이벤트에 지원서(웹폼)를 연결하여 지원자가 신청할 수 있도록 설정합니다.

웹폼 선택

  1. 이벤트 편집 페이지에서 "지원서" 섹션
  2. 기존에 등록된 웹폼 목록에서 사용할 웹폼 선택

필드 선택 (체크박스)

웹폼을 선택하면 해당 웹폼의 필드 목록이 체크박스로 표시됩니다.

  • 체크 해제: 이번 이벤트 등록 시 해당 필드를 노출하지 않음
  • 체크 유지: 해당 필드를 사용자에게 노출

이를 통해 동일한 웹폼을 사용하면서도 이벤트별로 필요한 필드만 선택적으로 노출할 수 있습니다.

미리보기

"미리보기" 버튼을 클릭하면 전체 웹폼이 사용자 화면(dcamp.kr)에서 어떻게 표현되는지 확인할 수 있습니다.

  • 관리자가 신청폼 구성을 등록 전에 미리 확인 가능
  • 필드 선택(체크박스) 설정이 반영된 상태로 미리보기

변경 예정 방식:

  1. 회원 등록: 심사위원을 일반 회원으로 등록
  2. 심사위원 등록: 해당 이벤트에 심사위원으로 등록
  3. 심사 화면 접근 시: MFA 인증번호 안내 메일 발송
  4. 인증 후 접근: 원타임 로그인으로 심사 화면 접근
단계 설명
회원 등록 심사위원 이름, 이메일로 회원 생성
심사위원 등록 이벤트에 심사위원 배정
인증 메일 심사 화면 접근 시 MFA 인증번호 메일 자동 발송
원타임 로그인 인증번호 확인 후 해당 세션에서만 심사 가능

방식 설명 사용 상황

5.4 심사 진행

심사위원 심사 페이지

심사위원은 별도의 심사 페이지에서 심사를 진행합니다:

/judge

참고: 심사 페이지는 관리자 페이지와 별도입니다. 심사위원은 MFA 인증을 통한 원타임 로그인으로 접근합니다.

심사 흐름 (변경 예정)

1. 관리자: 심사위원 등록 (회원 등록 → 심사위원 배정)
         ↓
2. 심사위원: 심사 페이지(/judge) 접근 시도
         ↓
3. 시스템: MFA 인증번호 메일 자동 발송
         ↓
4. 심사위원: 메일에서 인증번호 확인
         ↓
5. 심사위원: 인증번호 입력 → 원타임 로그인
         ↓
6. 심사위원: 배정된 지원자 목록 확인
         ↓
7. 심사위원: 각 지원자 심사
   - 지원서 검토
   - 평가 항목별 점수 입력
   - 종합 의견 작성
         ↓
8. 심사위원: 심사 제출

9. 자주 묻는 질문 (FAQ)

Q1. 내가 관리하는 프로그램만 보이나요?

A: 네, 역할에 따라 접근 가능한 프로그램만 메뉴에 표시됩니다. 예를 들어 growth 역할은 오피스아워, 그로스코칭만 볼 수 있습니다.

Q2. 지원서 양식을 변경하고 싶어요.

A: 지원서(웹폼)는 시스템 관리자만 수정할 수 있습니다. 변경이 필요한 경우 요청해주세요.

Q3. 심사위원이 심사 페이지에 접근하지 못한다고 합니다.

A:

  1. 심사위원 이메일 주소가 정확히 등록되었는지 확인
  2. MFA 인증 메일이 스팸함에 있는지 확인 안내
  3. 회원 등록 및 심사위원 배정이 정상적으로 되었는지 확인

Q4. 지원자 정보를 수정할 수 있나요?

A: 지원자가 제출한 정보는 원칙적으로 수정하지 않습니다. 오류 수정이 필요한 경우 지원자에게 재제출을 요청하거나 시스템 관리자에게 문의하세요.

Q5. 접수 기간을 연장하고 싶어요.

A: 이벤트 편집 페이지에서 "접수 종료일"을 변경하면 됩니다. 연장 공지를 별도로 진행해주세요.

3.4 공지사항 상단 고정

  1. 공지사항 편집 페이지
  2. "상단 고정" 체크박스 선택

참고: 상단 고정된 공지는 게시일과 관계없이 항상 목록 최상단에 표시됩니다. 여러 개가 고정된 경우 게시일 역순으로 정렬됩니다.

접근 권한

참고: 미디어 관리는 planning(기획실)과 bizops(BizOps) 역할만 접근 가능합니다.

  • 상단 고정(sticky) 설정된 미디어는 목록 최상단에 표시됩니다.

8. 자주 묻는 질문 (FAQ)

Q1. 콘텐츠를 잘못 삭제했어요. 복구할 수 있나요?

A: 삭제된 콘텐츠는 복구가 어렵습니다. 삭제 대신 "미게시" 처리를 권장합니다. 긴급한 경우 시스템 관리자에게 문의하세요.

Q2. 이미지가 업로드되지 않아요.

A: 다음을 확인해주세요.

  • 파일 형식: JPG, PNG만 지원
  • 파일 용량: 20MB 이하
  • 파일명: 특수문자 없이 영문/숫자만

Q3. 스토리/미디어 메뉴가 안 보여요.

A: 스토리와 미디어 관리는 planning(기획실)과 bizops(BizOps) 역할만 접근 가능합니다. 권한이 필요한 경우 관리자에게 요청하세요.

2.1 히어로 섹션 (Hero)

메인 상단의 대표 영역입니다. 팝업 박스와 KV (Key Visual) 두 가지 요소로 구성됩니다.

2.1.1 팝업 박스 (Popup Box)

메인화면 우측 상단에 표시되는 작은 배너입니다.

항목 설명 입력 예시
제목 팝업 타이틀 "dcamp batch 17기 모집"
이미지 팝업 이미지 400x300px JPG/PNG
링크 클릭 시 이동 URL /program/batch

2.1.2 KV (Key Visual)

메인화면 중앙의 메인 비주얼 영역입니다.

항목 설명 입력 예시
타이틀 메인 제목 "스타트업의 성장을 함께합니다"
서브타이틀 부제목 "dcamp는 스타트업 생태계를 지원합니다"
링크 클릭 시 이동 URL /about/who-we-are
미디어 배경 영상 또는 이미지 MP4 영상 또는 JPG 이미지

미디어 가이드

유형 권장 사양 비고
영상 1920x1080px, MP4, 15초 이내, 10MB 이하 기본 권장, 자동 재생
이미지 1920x1080px, JPG, 2MB 이하 영상 대체용

2.2 What We Do 섹션

dcamp의 주요 활동을 소개하는 카드형 섹션입니다. 최대 4개 항목을 설정할 수 있습니다.

항목 설명 입력 예시
제목 카드 타이틀 "Accelerating"
설명 카드 설명 텍스트 "스타트업 성장 가속화 프로그램"
이미지 카드 배경 이미지 600x400px JPG
링크 클릭 시 이동 URL /program/batch

관리 방법

  1. "항목 추가" 버튼 클릭 (최대 4개)
  2. 제목, 설명, 이미지, 링크 입력
  3. 드래그 앤 드롭으로 순서 변경
  4. X 버튼으로 항목 삭제

관리 방법

  1. "스타트업 선택" 버튼 클릭

2.5 뉴스 섹션

최신 뉴스를 고정 뉴스와 그리드 뉴스 두 영역으로 나눠 표시합니다.

영역 설명 최대 개수
고정 뉴스 (Pinned) 상단 강조 영역 1개
그리드 뉴스 (Grid) 하단 목록 영역 3개

관리 방법

  1. "고정 뉴스 선택" 또는 "그리드 뉴스 선택" 버튼 클릭
  2. 모달에서 공지사항/인사이트 검색/선택
  3. 확인 클릭 → 자동 저장

참고: 뉴스 소스는 공지사항(notice)과 인사이트(insight) 콘텐츠입니다.

2.6 Impact 섹션

dcamp의 성과 지표를 표시하는 섹션입니다.

항목 설명 입력 예시
기준 연도 성과 기준 연도 "2024"

Impact 항목 설정

각 성과 지표별로 다음 항목을 입력합니다:

항목 설명 입력 예시
제목 지표 타이틀 "누적 투자 유치"
라벨 지표 부제목 "포트폴리오사 합산"
값 숫자 값 50000
단위 표시 단위 "억원"
이미지 아이콘/이미지 200x200px PNG

관리 방법

  1. "항목 추가" 버튼 클릭
  2. 제목, 라벨, 값, 단위, 이미지 입력
  3. X 버튼으로 항목 삭제

메인화면 저장

  • 대부분의 필드는 자동 저장됩니다 (입력 후 포커스 해제 시)
  • 엔티티 선택(스타트업, 뉴스 등)은 선택 즉시 자동 저장됩니다

참고: 저장 후 캐시로 인해 즉시 반영되지 않을 수 있습니다. 몇 분 후 확인하거나 캐시를 갱신하세요.

5. Featured Contents

메인화면 메뉴 영역에 표시될 주요 콘텐츠를 선택합니다.

접근 경로

웹사이트 관리 → Featured Contents
/admin/dcamp/featured-contents

관리 항목

항목 설명 최대 개수
Program 메뉴에 표시할 프로그램 4개
News 메뉴에 표시할 뉴스/공지 4개

5.1 Program

Event 엔티티에서 applicant, application 타입을 선택합니다.

관리 방법

  1. "Program 선택" 버튼 클릭
  2. 모달에서 프로그램 검색/선택 (최대 4개)
  3. "확인" 클릭 → 자동 저장

링크 설정

선택된 각 프로그램에 커스텀 링크를 추가할 수 있습니다.

  • 링크 추가: 프로그램 카드 하단 "링크 추가" 클릭 → URL 입력 → 저장
  • 링크 수정: 기존 링크의 수정 아이콘 클릭
  • 링크 삭제: 링크의 삭제 아이콘 클릭

프로그램 제거

  • 프로그램 카드 우측 상단 X 버튼 클릭

5.2 News

Node에서 insight, notice 타입을 선택합니다.

관리 방법

  1. "News 선택" 버튼 클릭
  2. 모달에서 뉴스/공지 검색/선택 (최대 4개)
  3. "확인" 클릭 → 자동 저장

뉴스 제거

  • 뉴스 카드 우측 상단 X 버튼 클릭

참고: Featured Contents에서 제거해도 원본 콘텐츠(프로그램, 뉴스)는 삭제되지 않습니다. 단순히 메뉴 노출에서 제외됩니다.

9. 자주 묻는 질문 (FAQ)

Q1. 변경 사항이 사이트에 반영되지 않아요.

A: 캐시 문제일 수 있습니다.

  1. 브라우저 강력 새로고침 (Ctrl+Shift+R / Cmd+Shift+R)
  2. 5분 정도 대기 후 다시 확인
  3. 계속 안 되면 캐시 수동 갱신

Q2. 이미지가 업로드되지 않아요.

A: 다음을 확인해주세요.

  • 파일 형식: JPG, PNG만 지원
  • 파일 용량: 권장 용량 이하
  • 파일명: 특수문자 없이 영문/숫자만

Q3. 히어로 영상이 재생되지 않아요.

A:

  • 영상 형식: MP4만 지원
  • 영상 용량: 10MB 이하 권장
  • 영상 길이: 15초 이내 권장
  • 브라우저 자동재생 정책으로 무음 영상만 자동재생

Q4. 모바일에서 레이아웃이 깨져요.

A:

  • 이미지 크기가 너무 큰지 확인
  • 텍스트 길이가 너무 긴지 확인
