## 8.1 용어집

### 일반 용어

| 용어 | 설명 |
|------|------|
| CMS | Content Management System, 콘텐츠 관리 시스템 |
| 헤드리스 CMS | 화면(프론트엔드) 없이 API만 제공하는 CMS |
| API | Application Programming Interface, 시스템 간 데이터 통신 규격 |
| JSON:API | JSON 형식의 표준 API 규격 |

### Drupal 용어

| 용어 | 설명 |
|------|------|
| 엔티티 (Entity) | Drupal의 데이터 단위 (Node, User, Portfolio 등) |
| 번들 (Bundle) | 엔티티의 세부 유형 (예: startup, partner) |
| 필드 (Field) | 엔티티에 추가되는 데이터 항목 |
| 모듈 (Module) | Drupal의 기능 확장 단위 |
| Drush | Drupal Shell, CLI 도구 |

### 보안 용어

| 용어 | 설명 |
|------|------|
| OAuth | 인증을 위한 개방형 표준 프로토콜 |
| JWT | JSON Web Token, 토큰 기반 인증 |
| MFA | Multi-Factor Authentication, 다중 인증 |
