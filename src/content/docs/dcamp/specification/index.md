┌─────────────────────────────────────────────────────────────────┐
│                         사용자 접점                              │

               │                              │
               ▼                              ▼
┌──────────────────────────────┐  ┌───────────────────────────────┐
│     dcamp.kr (프론트엔드)      │  │  admin.dcamp.kr (관리 시스템)   │
│                              │  │                               │
│  - Astro 프레임워크           │  │  - Drupal 11 CMS              │

               │                              │
