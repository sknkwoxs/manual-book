3 기술 스택 사용 기술, 프레임워크, 개발 환경
4 데이터베이스 설계 주요 데이터 구조, 엔티티 정의
5 API 명세 데이터 통신 방식, 주요 엔드포인트
6 커스텀 모듈 자체 개발 기능 상세
7 보안 설계 인증, 권한, 보안 정책
8 부록 용어집, 참고자료
