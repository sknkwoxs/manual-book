# Part 5. 작업 시나리오

실제 교체 작업은 4단계로 진행됩니다. 각 단계별로 담당 부서와 작업 내용을 정리했습니다.

---

## Phase 1: 사전 준비 (D-14 ~ D-7)

교체 2주 전부터 준비 작업을 시작합니다.

| 작업 | 담당 | 산출물 | 설명 |
|------|------|--------|------|
| 신규 로고 파일 수령 | 디자인팀 | 이미지 파일 세트 | SVG, PNG, ICO 형식 필요 |
| 신규 도메인 SSL 인증서 발급 | 인프라팀 | SSL 인증서 | 보안 접속(https)을 위해 필요 |
| 신규 도메인 DNS 설정 | 인프라팀 | DNS 레코드 | 새 도메인 주소가 서버를 가리키도록 설정 |
| 스테이징 환경 구성 | 개발팀 | 테스트 서버 | 실제 배포 전 테스트용 환경 |

---

## Phase 2: 개발 작업 (D-7 ~ D-3)

교체 1주일 전부터 실제 코드 수정 작업을 진행합니다.

| 작업 | 예상 소요 | 상세 |
|------|----------|------|
| 로고 이미지 교체 | 2시간 | 24개 파일 교체 |
| Favicon 교체 | 30분 | 6개 파일 교체 |
| 텍스트 일괄 변경 | 4시간 | Twig 템플릿, PHP 파일 |
| CSS 파일 수정 | 1시간 | 로고 경로 참조 |
| 환경변수 업데이트 | 30분 | .env 파일 |
| 메타데이터/Schema 수정 | 1시간 | SEO 관련 설정 |
| 301 리다이렉트 설정 | 2시간 | nginx/Apache 설정 |
| **DB 게시물 사명 변경** | **8시간** | **약 780개 게시물 일괄 수정 및 검증** |
| **뉴스레터 OG 이미지 교체** | **1시간** | **SNS 공유용 이미지 교체** |
| **대리점 마커 이미지 교체** | **1시간** | **지도 마커 4개 파일** |
| **예비 시간** | **8시간** | **예상치 못한 이슈 대응** |

**총 예상 소요 시간: 약 36시간 (권장 6일)**

---

## Phase 3: 외부 서비스 업데이트 (D-3 ~ D-1)

교체 3일 전부터 외부 서비스 설정을 변경합니다.

| 작업 | 담당 | 상세 |
|------|------|------|
| GTM/GA4 설정 변경 | 마케팅팀 | 속성명, 도메인 필터 |
| Search Console 주소 변경 | 마케팅팀 | Google, Naver |
| 카카오맵/구글맵 API 키 갱신 | 개발팀 | 도메인 화이트리스트 |
| SNS 계정 프로필 업데이트 | 마케팅팀 | Instagram, YouTube 등 |

---

## Phase 4: 배포 및 검증 (D-Day)

3월 26일 당일 배포 일정입니다. **새벽 시간 배포를 권장**합니다 (방문자가 적은 시간).

| 시간 | 작업 |
|------|------|
| 00:00-02:00 | 스테이징 최종 확인 |
| 02:00-04:00 | 프로덕션 배포 |
| 04:00-06:00 | 전체 페이지 스모크 테스트 |
| 06:00-12:00 | 모니터링 및 이슈 대응 |

> **스모크 테스트란?** 기본적인 기능이 정상 작동하는지 빠르게 확인하는 테스트입니다. 모든 페이지의 로고가 제대로 표시되는지, 링크가 작동하는지 등을 확인합니다.
