# Part 4. 검색 및 SEO 영향 분석

**SEO(검색엔진최적화)란?** 구글, 네이버 등에서 검색했을 때 우리 웹사이트가 상위에 노출되도록 하는 작업입니다. 도메인 변경은 SEO에 가장 큰 영향을 미치는 작업 중 하나입니다.

**현재 사이트맵 URL:** https://samhwa.com/sitemap.xml

**301 리다이렉트 테스트 URL 예시:**
- 메인: https://samhwa.com → [신규도메인]
- 회사소개: https://samhwa.com/company/intro → [신규도메인]/company/intro
- 뉴스 상세: https://samhwa.com/culture/news/[ID] → [신규도메인]/culture/news/[ID]
- 영문 메인: https://samhwa.com/en/ → [신규도메인]/en/

---

## 4.1 도메인 변경이 중요한 이유

인터넷에서 도메인(samhwa.com)은 회사의 "주소"와 같습니다. 도메인을 변경하면 다음과 같은 영향이 있습니다:

| 항목 | 영향도 | 쉬운 설명 |
|------|--------|----------|
| **검색 순위** | **높음** | 구글이 새 도메인을 신뢰하기까지 시간이 걸려, 일시적으로 검색 순위가 하락할 수 있습니다 |
| **백링크** | **높음** | 다른 웹사이트에서 우리 사이트로 연결된 링크들이 끊어집니다. 301 리다이렉트로 대응해야 합니다 |
| **북마크** | **중간** | 기존 주소를 즐겨찾기해둔 사용자들이 접속 시 새 주소로 자동 이동됩니다 |
| **외부 링크** | **높음** | 뉴스 기사, 파트너사 웹사이트, 블로그 등에 게시된 링크들 |

---

## 4.2 필수 SEO 조치

### 1) 301 리다이렉트 설정

**301 리다이렉트란?** "이 주소는 영구적으로 새 주소로 이전했습니다"라고 알려주는 기술입니다. 기존 주소로 접속하면 자동으로 새 주소로 이동됩니다.

- samhwa.com의 모든 페이지 → 신규 도메인의 동일 페이지로 연결
- 예: `samhwa.com/company/intro` → `[신규도메인]/company/intro`
- **최소 1년 이상 유지 권장** (검색엔진이 새 주소를 인식하는 데 시간이 필요)

### 2) Google Search Console 주소 변경

- Google Search Console에서 "주소 변경" 도구 사용
- 신규 도메인 속성 추가
- sitemap.xml 재제출

### 3) Sitemap 업데이트

**Sitemap이란?** 웹사이트의 모든 페이지 목록을 담은 파일입니다. 검색엔진이 우리 사이트의 구조를 파악하는 데 사용됩니다.

- 현재 파일: `/web/sitemap-240214.xml`
- 신규 도메인으로 재생성 필요

### 4) 사명 검색어 대응

기존에 "삼화페인트"로 검색하던 사용자들이 새 사명을 모를 수 있습니다.

**대응 방안:**
- 신규 사명으로 검색광고 집행
- 구조화 데이터에 기존 사명을 `alternateName`으로 추가 (검색엔진에 "이전 이름"을 알려줌)
- 일정 기간 "삼화페인트" 키워드 검색광고 유지

---

## 4.3 환경변수 변경 필요

**환경변수란?** 웹사이트의 기본 설정값을 저장하는 파일입니다. 도메인 주소 등 핵심 정보가 여기에 저장됩니다.

**파일 위치:** `.env`

```bash
# 현재
WP_HOME='https://samhwa.com'
DOMAIN_CURRENT_SITE='samhwa.com'

# 변경 후
WP_HOME='https://[신규도메인]'
DOMAIN_CURRENT_SITE='[신규도메인]'
```
