## 핵심 요약

| 구분 | 수량 | 설명 |
|------|------|------|
| 로고 이미지 파일 | 24개 | PC/모바일, 한국어/영문 테마 포함 |
| 대리점 마커 이미지 | 4개 | 대리점 찾기 지도 마커 (한/영) |
| Favicon 파일 | 6개 | 브라우저 탭에 표시되는 작은 아이콘 |
| 텍스트 수정 위치 | 약 30곳 | 회사명, Copyright, 메일 제목 등 |
| 외부 연동 서비스 | 10개 이상 | GA, GTM, 검색엔진, 지도 API 등 |
| **DB 게시물 수정** | **약 780개** | **뉴스, 뉴스레터 등 기존 게시물 내 사명 일괄 변경** |
| MIS 연동 (제품/대리점) | ✅ 수정 불필요 | 테이블명/컬럼명에 회사명 없음, 동적 조회 |
