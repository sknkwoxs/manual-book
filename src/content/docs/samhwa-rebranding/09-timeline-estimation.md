# Part 9. 작업별 예상 소요시간 (보수적 산정)

전체 리브랜딩 작업에 대한 **보수적인 소요시간 산정**입니다. 예상치 못한 이슈 발생 시 추가 시간이 필요할 수 있습니다.

---

## 9.1 개발 작업 (총 예상: 36시간 / 6일 권장)

| 작업 항목 | 예상 시간 | 비고 |
|----------|----------|------|
| **로고 이미지 교체** | 3시간 | 24개 파일 + 검증 |
| **Favicon 교체** | 1시간 | 6개 파일 |
| **대리점 마커 이미지 교체** | 1시간 | 4개 파일 (한/영) |
| **템플릿 텍스트 변경** | 6시간 | Twig, PHP 약 30곳 |
| **CSS 파일 수정** | 2시간 | 로고 경로 참조 |
| **환경변수 업데이트** | 1시간 | .env 파일 |
| **Schema/메타데이터** | 2시간 | SEO 관련 |
| **301 리다이렉트 설정** | 4시간 | nginx/Apache 설정 |
| **DB 게시물 사명 변경** | 8시간 | **약 780개 게시물, 검증 포함** |
| **뉴스레터 OG 이미지** | 1시간 | 이미지 4개 교체 |
| **예비 시간** | 7시간 | 예상치 못한 이슈 대응 |
| **합계** | **36시간** | **약 6일 권장 (하루 6시간 실작업 기준)** |

---

## 9.2 테스트 작업 (총 예상: 20시간 / 3일)

| 테스트 항목 | 예상 시간 | 비고 |
|------------|----------|------|
| 로고/이미지 표시 테스트 | 2시간 | PC/모바일/브라우저별 |
| 텍스트 변경 확인 | 1.5시간 | 주요 페이지 |
| DB 게시물 테스트 | 2시간 | 유형별 샘플 확인 |
| 외부 연동 테스트 | 2시간 | 지도, 분석도구, SNS |
| 이메일 발송 테스트 | 1.5시간 | 6개 폼 테스트 |
| SEO/메타데이터 테스트 | 1시간 | Schema, OG태그 |
| 301 리다이렉트 테스트 | 1시간 | 주요 URL |
| 영문 사이트 테스트 | 1시간 | /en/ 전체 |
| 크로스 브라우저 테스트 | 1.5시간 | 5개 브라우저 |
| **MIS 연동 테스트** | **1.5시간** | **제품/자료/대리점 조회** |
| 재테스트/버그 수정 | 2시간 | 발견된 이슈 재확인 |
| **예비 시간** | 3시간 | 추가 테스트/이슈 대응 |
| **합계** | **20시간** | **약 3일** |

## 9.4 전체 작업 소요시간 요약

| 구분 | 예상 시간 | 권장 일정 |
|------|----------|----------|
| 개발 작업 | 36시간 | **6일** (여유 포함) |
| 테스트 작업 | 20시간 | **3일** |
| 외부 서비스 | 8시간 | **2일** |
| 배포/검증 | 8시간 | **1일** (D-Day) |
| **총 소요시간** | **72시간** | **총 12일 권장** |

> **주의:** 위 일정은 순수 작업 시간입니다. 실제로는 커뮤니케이션, 승인 대기, 예상치 못한 이슈 대응 등으로 **2배 이상의 캘린더 일정**이 필요할 수 있습니다. 3월 26일 배포 기준 **최소 3월 3일**부터는 개발 작업을 시작해야 합니다.
