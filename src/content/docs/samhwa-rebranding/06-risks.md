# Part 6. 리스크 및 고려사항

모든 프로젝트에는 리스크가 있습니다. 미리 파악하고 대비하면 문제 발생 시 빠르게 대응할 수 있습니다.

**주요 확인 URL:**
- 구매포털: https://gume.samhwa.com
- 채용사이트: https://samhwa.recruiter.co.kr
- Family Site (푸터에서 확인): https://samhwa.com

---

## 6.1 고위험 항목

반드시 대비해야 하는 중요한 리스크입니다.

| 리스크 | 영향 | 완화 방안 |
|--------|------|----------|
| **SEO 순위 급락** | 검색을 통한 웹사이트 방문자 감소 | 301 리다이렉트 철저히 설정, 검색광고 병행 |
| **외부 백링크 끊김** | 다른 사이트에서의 유입 감소 | 주요 파트너사에 사전 안내, 301 리다이렉트 |
| **브라우저 캐시** | 사용자에게 이전 로고가 계속 보임 | 파일명 변경 또는 버전 파라미터 추가 |
| **이메일 발송 실패** | 고객 문의 접수 누락 | 메일 서버 SPF/DKIM 재설정, 발송 테스트 |

---

## 6.2 중위험 항목

| 리스크 | 영향 | 완화 방안 |
|--------|------|----------|
| **하드코딩된 URL** | 일부 페이지 오류 | 코드 전수 조사 |
| **외부 임베드 콘텐츠** | 일부 콘텐츠 깨짐 | iframe, 외부 위젯 점검 |
| **구매포털 연동** | 대리점 로그인 실패 | `gume.samhwa.com` 도메인 유지 여부 확인 |
| **Family Site 링크** | 연관 사이트 접근 불가 | 연관 사이트 도메인 확인 |

---

## 6.3 캐시 관련 고려사항

**캐시란?** 웹사이트를 빠르게 표시하기 위해 이미지, CSS 등을 임시 저장하는 것입니다. 로고를 변경해도 사용자의 브라우저에 이전 로고가 저장되어 있으면 계속 이전 로고가 보일 수 있습니다.

| 캐시 유형 | 설명 | 대응 방안 |
|----------|------|----------|
| **브라우저 캐시** | 사용자 컴퓨터에 저장된 파일 | 파일명 변경 또는 `?v=2` 같은 버전 파라미터 추가 |
| **CDN 캐시** | 전 세계 서버에 분산 저장된 파일 | 배포 시 전체 캐시 무효화 |
| **WordPress 캐시** | 서버에서 생성한 페이지 캐시 | W3 Total Cache 전체 퍼지 |
| **DNS 캐시** | 도메인-IP 매핑 정보 | 배포 24시간 전에 TTL(유효시간) 단축 |
