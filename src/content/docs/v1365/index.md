## 문서 구성

### 1. [현황 분석](./analysis/)

현행 Omeka Classic 시스템의 기술 구조와 데이터 현황, 운영상의 문제점을 분석합니다.

- **시스템 아키텍처** — LAMP 스택 구성, Omeka 엔진, 프론트엔드 기술 스택
- **콘텐츠 구조 및 데이터** — 아이템·컬렉션 데이터 모델, 메타데이터 구조, 메뉴-콘텐츠 매핑
- **어드민 시스템** — 관리자 패널 기능과 한계, API 현황, 사용자 역할 체계
- **기술적 이슈** — 브라우저 오류(404, jQuery 이중 로드 등), 레거시 스택 리스크, 개선 우선순위

### 2. [운영유지 가이드](./operations/)

스컹크웍스스튜디오가 수행하는 운영유지 범위, 과업 체계, 표준 프로세스를 정의합니다.

- **운영유지 3대 범위** — ① CMS 코어 및 모듈 보안 업데이트 ② 웹사이트 정보 업데이트 ③ 기능 수정 및 개선
- **시스템 업데이트 실행 가이드** — 범위별 구체적 실행 절차
- **정기 유지보수** — 인프라 관리, 백업, 호스팅·SSL·도메인 갱신, 보고서
- **모니터링 및 장애 대응** — 상태 점검, 이슈 분류·에스컬레이션, 장애 복구

### 3. [CMS 어드민 컨버팅 로드맵(제안)](./roadmap/)

현행 시스템의 기술적 한계를 근본적으로 해결하기 위한 Drupal CMS 전환 제안입니다.

- **즉시 대응** — CMS 전환 착수 전 현행 시스템 안정화 조치
- **마이그레이션 전략** — CMS 비교 평가, Drupal 선정 사유, 전환 단계, 리스크 관리
- **데이터 마이그레이션** — 19,000건 기록물 데이터 이전 계획 및 무결성 검증
- **프론트엔드 재구축** — 사용자 화면 현대화, 접근성·성능·SEO 개선
