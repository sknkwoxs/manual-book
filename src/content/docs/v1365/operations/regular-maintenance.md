# 정기 유지보수

운영유지 범위 01~03의 안정적인 수행을 위한 기반 업무입니다. 시스템 인프라 관리, 백업, 호스팅/SSL/도메인 관리, 유지보수 보고서 작성을 포함합니다.

---

## 인프라 관리

### 서버 환경

| 항목 | 내용 |
| :--- | :--- |
| **OS** | Linux (LAMP 스택) |
| **웹서버** | Apache |
| **PHP** | 7.1+ |
| **DB** | MySQL 5.5.5+ |
| **검색엔진** | Apache Solr |
| **CMS** | Omeka Classic |

### 서버 점검 항목

*   **디스크 사용량**: 파일 저장소(`/files/`) 용량 모니터링 — original, fullsize, thumbnails, square_thumbnails 디렉토리
*   **PHP 에러 로그**: `/logs/` 또는 서버 설정에 따른 로그 파일 점검
*   **Apache 로그**: 접근 로그 및 에러 로그 확인
*   **MySQL 상태**: 느린 쿼리(slow query), 커넥션 수 모니터링

## 백업 전략

### 백업 대상

| 대상 | 경로/방법 | 주기 |
| :--- | :--- | :--- |
| **데이터베이스** | `mysqldump` 전체 백업 | 일 1회 (자동화 권장) |
| **파일 저장소** | `/files/` 디렉토리 전체 | 주 1회 |
| **테마 파일** | `/themes/v1365/` | 변경 시 |
| **플러그인** | `/plugins/` 디렉토리 | 변경 시 |
| **설정 파일** | `db.ini`, `config.ini`, `.htaccess` | 변경 시 |

### 백업 보관

*   최소 **30일분** 보관
*   원격지 백업 1벌 이상 유지 권장
*   복원 테스트를 연 1회 이상 수행

:::tip[백업 자동화]
cron 작업을 통해 DB 백업을 자동화하고, 백업 완료 알림을 설정하면 안정성이 향상됩니다.
:::

## 호스팅/SSL/도메인 관리

### 관리 항목

| 항목 | 주기 | 상세 |
| :--- | :--- | :--- |
| **호스팅** | 연 1회 | 호스팅 계약 만료 전 갱신 확인 |
| **SSL 인증서** | 연 1회 | 만료일 확인 및 갱신 (Let's Encrypt 자동 갱신 설정 권장) |
| **도메인** | 연 1회 | 도메인 만료 전 갱신 확인 |

### 갱신 프로세스

1.  만료 **60일 전** 고객사에 갱신 안내
2.  고객사 승인 후 갱신 절차 진행
3.  갱신 완료 후 정상 접속 확인
4.  갱신 내역을 유지보수 보고서에 기록

:::danger[만료 주의]
SSL 인증서 또는 도메인 만료 시 사이트 접속이 불가능해질 수 있습니다. 만료일을 캘린더에 등록하여 사전에 대응하십시오.
:::
