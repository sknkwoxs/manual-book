# CMS 어드민 컨버팅 로드맵(제안)

한국자원봉사아카이브의 현행 시스템(Omeka Classic)은 Zend Framework 1 기반으로 개발되어 **보안 취약점 노출, 확장성 부재, 관리자 UX 미흡** 등 근본적인 한계가 지속되고 있습니다. 본 로드맵은 **Drupal CMS**로의 어드민 컨버팅을 통해 이러한 기술적 부채를 해소하고, 현대적이고 안정적인 아카이브 관리 환경을 구축하기 위한 전략적 실행 계획을 제시합니다.

---

## 핵심 추진 배경

1. **기술적 부채 해결**: EOL(End of Life)이 선언된 Zend Framework 1 기반 시스템 탈피
2. **보안 강화**: 전담 보안팀이 운영하는 현대적 CMS로 전환하여 보안 리스크 근본적 해소
3. **관리 편의성 증대**: 한국어 100% 지원, 반응형 관리자 UI, 직관적인 콘텐츠 관리 환경 확보
4. **유연한 확장성 확보**: 수평 확장, 클라우드 네이티브 아키텍처, API 기반 서비스 연동 기반 마련
5. **현황분석 기술적 이슈 일괄 해소**: [기술적 이슈 및 개선 영역](/v1365/analysis/technical-issues/)에서 도출된 10개 핵심 이슈를 Drupal 전환으로 근본적으로 해결

---

## 왜 Drupal인가

**Drupal**은 전 세계 정부기관, 대학, 박물관 등에서 널리 사용되는 엔터프라이즈급 오픈소스 콘텐츠 관리 시스템(CMS)입니다. 최신 안정 버전인 **Drupal 11**(2024년 8월 출시)은 현대적 기술 기반 위에 구축되어 장기적인 보안과 성능을 보장합니다. 다른 CMS 후보군과의 상세 비교 평가는 [마이그레이션 전략](./migration-strategy/) 문서를 참고하시기 바랍니다.

### Drupal의 주요 강점

| 영역 | 특징 |
| :--- | :--- |
| **보안** | 전담 보안팀 운영, 주간 보안 권고 발행, 취약점 체계적 추적 |
| **다국어** | 100개 이상 언어 기본 내장, 한국어 완전 지원 |
| **확장성** | 캐싱, CDN 통합 지원, 수평 확장 및 클라우드 배포 가능 |
| **관리자 UX** | 반응형 관리자 화면 기본 제공, 시각적 레이아웃 편집 기능 |
| **외부 연동** | API 기본 내장으로 외부 시스템과의 데이터 연동이 용이 |
| **콘텐츠 모델링** | 아카이브 메타데이터 구조를 기관 요구사항에 맞게 유연하게 설계 가능 |

### 기록물 관리를 넘어선 콘텐츠 활용

현행 Omeka Classic은 **기록 아이템의 등록·보관**에는 적합하지만, 아이템을 **참조하는 다양한 콘텐츠를 생성하는 데 구조적 한계**가 있습니다. 예를 들어, 기획 전시 페이지에서 특정 기록물을 인용하거나, 칼럼·스토리에서 관련 아이템을 연결하려면 복잡한 우회 방식이 필요합니다.

Drupal은 이 부분에서 근본적인 차이를 보입니다.

| 콘텐츠 활용 영역 | 현행 (Omeka Classic) | Drupal 전환 시 |
| :--- | :--- | :--- |
| **기획 전시 제작** | 별도 플러그인 필요, 제한된 레이아웃 | 시각적 편집기로 자유로운 전시 페이지 구성, 기록물 직접 참조 |
| **칼럼·스토리 작성** | 기록 아이템과의 연결이 수동적·제한적 | 본문 내에서 기록물을 직접 참조·삽입하여 풍부한 콘텐츠 생성 |
| **연구 자료·보고서** | 별도 페이지로만 관리, 아이템과 분리 | 기록물과 연구 자료 간 양방향 참조 관계 설정 |
| **주제별 큐레이션** | 태그 기반 수동 분류만 가능 | 다양한 조건으로 기록물을 자동 수집·구성하는 큐레이션 페이지 생성 |
| **기관별 특화 페이지** | 컬렉션 목록 수준의 단순 표시 | 공동운영기관별로 소개, 기록물, 활동 이력을 통합한 전용 페이지 구성 |

:::note[핵심]
Drupal은 기록물 보관뿐 아니라, 기록물을 **소재로 활용하는 2차 콘텐츠 생산**까지 하나의 시스템에서 체계적으로 관리할 수 있습니다. 이는 아카이브의 가치를 단순 보존에서 **적극적 활용**으로 확장하는 데 핵심적인 차이입니다.
:::

### 아카이브 분야 도입 사례

Drupal은 **GLAM(Gallery, Library, Archive, Museum)** 분야에서 검증된 플랫폼입니다.

- **Smithsonian Institution**: 세계 최대 박물관 복합체(19개 박물관)가 Drupal 기반으로 운영
- **Islandora**: Drupal 기반 디지털 리포지토리 플랫폼으로, 더블린 코어를 포함한 다양한 아카이브 메타데이터 표준을 기본 지원
- **Europeana 연계 기관** 다수가 Drupal을 디지털 아카이브 플랫폼으로 채택

### 현행 기술적 이슈와 Drupal 해결 매핑

[현황분석에서 도출된 기술적 이슈](/v1365/analysis/technical-issues/)를 Drupal 전환으로 해결할 수 있습니다.

| 현행 이슈 | Drupal 전환 시 해결 |
| :--- | :--- |
| 핵심 프레임워크 지원 종료 (보안 패치 중단) | 현대적 프레임워크 기반, 전담 보안팀 운영 |
| 구버전 기술 환경 제한 | 최신 기술 환경 지원으로 장기적 안정성 확보 |
| 한국어 지원 미흡 (41%) | 100개 이상 언어 기본 내장, 한국어 100% |
| 비반응형 관리자 UI | 반응형 관리자 화면 기본 제공 |
| 단일 서버, 확장 불가 | 캐싱, CDN 통합, 클라우드 환경 지원 |
| 캐싱 없음 | 다단계 캐싱 기본 내장 |
| 파일 저장소 로컬만 | 클라우드 스토리지 지원 |
| 외부 연동(API) 제한적 | API 기본 내장, 외부 시스템 연동 용이 |
| 한국어 검색 품질 미흡 | 한국어 형태소 분석 지원 가능 |
| 라이브러리 충돌 (이중 로드 등) | 현대적 프론트엔드 구조 |
