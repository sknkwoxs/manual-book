## 국회기록원의 특성

### 국민 알권리와 민주주의 기록

국회기록은 **민주주의의 근간**이다. 국민이 이 기록에 쉽게 접근하고 이해할 수 있어야 한다.

| 서비스 원칙 | 내용 |
|-------------|------|
| **접근성** | 누구나, 언제, 어디서나 |
| **이해가능성** | 전문 지식 없이도 파악 가능 |
| **신뢰성** | 정확한 정보, 출처 명시 |
| **중립성** | 정파적 편향 없는 정보 제공 |

### 이용자 유형별 니즈

국회기록 서비스의 이용자는 다양하며, 각각 다른 니즈를 가진다:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       이용자 유형별 니즈                                 │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   [일반 국민]                    [연구자]                               │
│   • "우리 지역 의원 뭐했어?"     • "20년간 연금법 변천사"                │
│   • "이 법안 쉽게 설명해줘"      • "의원 표결 패턴 분석 데이터"          │
│   • "요즘 국회에서 뭐가 이슈야?" • "특정 정책 관련 발언 전수 조사"       │
│                                                                         │
│   [언론]                         [시민단체]                             │
│   • "이 법안 쟁점이 뭐야?"       • "공약 이행 여부 확인"                 │
│   • "의원 발언 팩트체크"         • "특정 이슈 국회 대응 모니터링"        │
│   • "과거 유사 사례 찾기"        • "의원 활동 비교 분석"                 │
│                                                                         │
│   [정부/공공기관]                [의원실/국회]                          │
│   • "관련 입법 동향 파악"        • "유사 법안 현황"                      │
│   • "국감 질의 예상 준비"        • "상대 의원 활동 분석"                 │
│   • "정책 영향 분석"             • "위원회 심사 현황"                    │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 현행 서비스의 한계

| 현행 서비스 | 한계 |
|-------------|------|
| **의안정보시스템** | 법안 메타정보 위주, 맥락 파악 어려움 |
| **회의록검색** | 키워드 검색만, 의미 검색 불가 |
| **국회기록보존소** | 전문가용, 일반 국민 접근 어려움 |
| **열린국회정보** | 데이터 중심, 스토리텔링 부재 |

## 7대 참여자의 역할

### 참여자별 서비스 니즈

| 참여자 | 주요 서비스 니즈 | 핵심 기능 |
|--------|------------------|-----------|
| **의원실** | 입법 동향, 유사 법안, 상대방 분석 | 법안 비교, 의원 활동 분석 |
| **위원회** | 심사 현황, 쟁점 정리, 전문가 의견 | 심사 대시보드, 이슈 트래킹 |
| **국회기록원** | 아카이브 현황, 이용 통계 | 관리 대시보드, 품질 모니터링 |
| **국민** | 쉬운 설명, 의원 활동, 법안 현황 | AI 요약, 대화형 QA, 타임라인 |
| **연구자/언론** | 심층 검색, 데이터 다운로드, 분석 | 고급 검색, API, 분석 도구 |
| **정부부처** | 입법 동향, 국감 대비, 정책 연계 | 알림 서비스, 분석 리포트 |
| **시민단체** | 모니터링, 비교 분석, 공약 추적 | 의원 평가, 이슈 대시보드 |

```

AI 응답:
┌─────────────────────────────────────────────────────────────────────┐
│ 김OO 의원 (강남갑, OO당)                                            │
│                                                                     │
│ 최근 3개월 활동 요약                                                │

```
