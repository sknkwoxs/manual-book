## 5대 기록 유형의 수집 전략

각 기록 유형별로 수집 경로와 AI 적용 방안을 정의한다.

---

## 회의록/속기록

**수집 경로:**
- **본회의/위원회**: 의사국 → 국회기록원 자동 연계
- **비공개 회의**: 암호화 수집, 접근 제한

**AI 적용:**
| 기능 | 내용 |
|------|------|
| STT (음성→텍스트) | 실시간 회의 음성 텍스트 변환 |
| 화자 분리 | 발언자별 발언 구간 자동 분리 |
| 메타추출 | 회의정보, 참석자, 안건 자동 인식 |

---

## 법안/의안

**수집 경로:**
- **의안정보시스템 API 연동**: 법안 등록 즉시 자동 수집
- **첨부 문서**: 제안이유서, 비용추계서 자동 포함

**AI 적용:**
| 기능 | 내용 |
|------|------|
| 조문 파싱 | 법안 구조(조, 항, 호) 자동 분석 |
| 관련 법안 연결 | 모법, 개정안, 대안 관계 자동 탐지 |

---

## 의정활동 기록

**수집 경로:**
- **의원실 클라우드 동기화**: Google Drive, Naver Works 연동
- **업무용 메신저**: 정책 논의 기록 (승인 범위 내)
- **이메일 아카이빙**: 공식 소통 기록

**AI 적용:**
| 기능 | 내용 |
|------|------|
| 자동 분류 | 활동 유형 (질의, 토론, 표결) 판단 |
| 관계 연결 | 활동-법안-회의 자동 연결 |

---

## 국정감사 기록

**수집 경로:**
- **위원회 제출자료 시스템 연동**: 피감기관 자료 자동 수집
- **국감 회의록 연계**: 질의-답변-자료 3자 연결

**AI 적용:**
| 기능 | 내용 |
|------|------|
| QA 추출 | 질의-답변 쌍 자동 추출 |
| 자료 OCR | 스캔 문서 텍스트 추출 |

---

## 행정기록

**수집 경로:**
- **전자문서시스템 연계**: 결재 완료 문서 자동 이관
- **보존 기간 기반 분류**: 기록 가치별 자동 분류

**AI 적용:**
| 기능 | 내용 |
|------|------|
| 문서 분류 | 문서 유형 자동 분류 |
| 개인정보 탐지 | 비식별화 대상 자동 탐지 |
| 보존 가치 평가 | 폐기/보존 판단 보조 |

---

## 기록 유형별 수집 요약

| 기록 유형 | 주요 수집 경로 | AI 핵심 기능 |
|-----------|---------------|-------------|
| 회의록/속기록 | 의사국 자동 연계 | STT, 화자 분리 |
| 법안/의안 | 의안정보시스템 API | 조문 파싱, 관련 법안 연결 |
| 의정활동 | 클라우드 동기화 | 자동 분류, 관계 연결 |
| 국정감사 | 제출자료 시스템 | QA 추출, OCR |
| 행정기록 | 전자문서시스템 | 분류, 개인정보 탐지 |
