## As-Is 분석 방법론

### 1. 의원실 업무 프로세스 추적 조사 (Shadowing)

**목적**: 문서 생성~폐기 경로 파악 및 Pain Point 식별

| 분석 항목 | 상세 내용 |
|----------|----------|
| **대상** | 보좌진의 하루 업무 관찰 |
| **방법** | 워크 쉐도잉, 인터뷰 |
| **파악 내용** | 문서 생성 → 활용 → 보관 → 폐기 경로 |
| **Pain Point** | 수동 이관의 번거로움, 파일 유실 지점 |

**조사 항목**:
```
□ 문서 작성 도구 및 포맷 (한글, MS Office, PDF 등)
□ 문서 저장 위치 (로컬 PC, 공유 폴더, 클라우드)
□ 문서 분류 체계 (폴더 구조, 명명 규칙)
□ 문서 이관 절차 및 주기
□ 문서 폐기 기준 및 절차
```

### 2. 레거시 데이터 프로파일링 (Data Profiling)

**목적**: 기존 시스템 내 데이터 구조 및 품질 진단

| 분석 대상 | 분석 내용 |
|----------|----------|
| **의안시스템** | 데이터 구조, 테이블 관계, 데이터 품질 |
| **그룹웨어** | 문서 저장 현황, 메타데이터 수준 |
| **비정형 데이터** | 한글 파일, PDF, 이메일의 포맷/암호화 현황 |

**프로파일링 항목**:
- 데이터 볼륨 (레코드 수, 파일 수, 용량)
- 데이터 품질 (완전성, 정확성, 일관성)
- 메타데이터 현황 (누락, 불일치)
- 포맷 다양성 (HWP, DOCX, PDF, JPG 등)

## To-Be 요구 기능

### 1. Zero-Effort 자동 수집 에이전트

**개념**: 의원실 업무에 전혀 부담을 주지 않는 백그라운드 자동 수집

```
┌─────────────────────────────────────────────────────────────────┐
│                    자동 수집 에이전트 구조                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────┐      ┌─────────────┐      ┌─────────────┐    │
│  │ 지정 폴더   │      │ 클라우드    │      │ 이메일      │    │
│  │ (로컬 PC)   │      │ (OneDrive등)│      │ (Outlook등) │    │
│  └──────┬──────┘      └──────┬──────┘      └──────┬──────┘    │
│         │                    │                    │            │
│         └────────────────────┼────────────────────┘            │
│                              ▼                                  │
│                    ┌─────────────────┐                         │
│                    │  백그라운드     │                         │
│                    │  동기화 엔진    │                         │
│                    └────────┬────────┘                         │
│                             │                                   │
│                             ▼                                   │
│                    ┌─────────────────┐                         │
│                    │  암호화 전송    │                         │
│                    │  (TLS/E2E)      │                         │
│                    └────────┬────────┘                         │
│                             │                                   │
│                             ▼                                   │
│                    ┌─────────────────┐                         │
│                    │  중앙 저장소    │                         │
│                    └─────────────────┘                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**핵심 기능**:
| 기능 | 설명 |
|------|------|
| 폴더 동기화 | 지정 폴더의 변경 사항 실시간 감지 및 자동 전송 |
| 백그라운드 동작 | 사용자 작업에 영향 없이 저사양 동작 |
| 변경분 전송 | 전체 파일이 아닌 변경분만 효율적 전송 |
| 오프라인 지원 | 네트워크 단절 시 큐잉 후 자동 재전송 |

### 2. 지능형 분류 및 메타데이터 태깅 (AI Tagging)

**개념**: NLP 기반 자동 메타데이터 추출 및 분류

| 추출 항목 | 기술 | 설명 |
|----------|------|------|
| 작성자 | NER | 문서 내 인명 자동 인식 |
| 작성 시점 | 날짜 추출 | 문서 내용에서 날짜 정보 추출 |
| 관련 법안 | 키워드 매칭 | 법안명, 법안번호 자동 연결 |
| 주제 분류 | 텍스트 분류 | 미리 정의된 분류 체계에 따른 자동 분류 |
| 요약 | 텍스트 요약 | 문서 핵심 내용 자동 요약 |

### 3. 멀티미디어 수집 파이프라인

**개념**: 의정 활동 사진/영상의 대용량 처리 자동화

```
┌───────────┐    ┌───────────┐    ┌───────────┐    ┌───────────┐
│  업로드   │───►│ 트랜스코딩│───►│ 메타데이터│───►│  저장소   │
│  (대용량) │    │ (포맷변환)│    │  추출     │    │  (Object) │
└───────────┘    └───────────┘    └───────────┘    └───────────┘
```

| 기능 | 설명 |
|------|------|
| 청크 업로드 | 대용량 파일 분할 업로드 |
| 자동 트랜스코딩 | 다양한 해상도/포맷 자동 변환 |
| 썸네일 생성 | 이미지/영상 미리보기 자동 생성 |
| EXIF 추출 | 촬영 일시, 위치 등 메타데이터 자동 추출 |
