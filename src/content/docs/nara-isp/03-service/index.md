## As-Is 분석 방법론

### 1. 사용자 경험(UX) 분석

#### 페르소나(Persona) 정의

| 페르소나 | 특성 | 주요 니즈 |
|----------|------|----------|
| **일반 국민** | 정치에 관심 있는 30~40대 직장인 | 쉬운 언어로 법안 이해, 내 지역 의원 활동 확인 |
| **기자** | 정치부 기자, 팩트체크 필요 | 빠른 정보 접근, 법안 변천 과정 추적 |
| **연구자** | 정치학/법학 교수, 대학원생 | 대량 데이터 다운로드, 통계 분석, 인용 정보 |
| **시민단체** | NGO 활동가, 정책 모니터링 | 특정 이슈 법안 추적, 의원 표결 이력 |

#### 사용자 여정 지도 (Journey Map)

```
[일반 국민의 법안 검색 여정]

인지 → 접근 → 검색 → 이해 → 활용
 │      │      │      │      │
 │      │      │      │      └─ 공유, 의견 표출
 │      │      │      └─ 내용 파악 (어려움 발생 지점)
 │      │      └─ 검색 실패 (전문 용어, 정확한 법안명)
 │      └─ 사이트 진입 (복잡한 메뉴 구조)
 └─ 뉴스에서 법안 정보 접함
```

### 2. 대국민 서비스 로그 분석

**분석 대상**: 기존 국회 사이트 이용 로그

| 분석 항목 | 목적 |
|----------|------|
| 검색 실패율 | 검색 결과 0건 비율 파악 |
| 이탈률 | 검색 후 상세 페이지 미진입 비율 |
| 다빈도 검색어 | 국민 관심 키워드 파악 |
| 체류 시간 | 콘텐츠 이해도 간접 측정 |

### 3. 해외 선진 사례 벤치마킹

| 기관 | 특징 | 시사점 |
|------|------|--------|
| **영국 의회** (Parliament UK) | 법안 타임라인 시각화 | 직관적 UI/UX |
| **미국 NARA** | 디지털 전시, 스토리텔링 | 콘텐츠 큐레이션 |
| **미국 Congress.gov** | 법안 비교, 관계 시각화 | 데이터 연결 활용 |
| **호주 의회** | 간결한 법안 요약 | 쉬운 언어 |

## To-Be 요구 기능

### 1. 입법 타임라인 시각화 뷰어

**개념**: 법안의 생애주기를 직관적으로 보여주는 인터랙티브 UI

```
법안 타임라인 예시
──────────────────────────────────────────────────────────────────────

2024.03.15        2024.04.20        2024.06.10        2024.09.01
    │                 │                 │                 │
    ▼                 ▼                 ▼                 ▼
┌───────┐        ┌───────┐        ┌───────┐        ┌───────┐
│ 발의  │───────►│위원회 │───────►│본회의 │───────►│ 공포  │
│       │        │ 심사  │        │ 의결  │        │       │
└───────┘        └───────┘        └───────┘        └───────┘
    │                 │                 │                 │
  홍길동           법사위            찬성 180        대통령
  의원 외         수정가결           반대 20         서명
  10인                                               

클릭 시 → 상세 정보, 관련 문서, 회의록 연결
──────────────────────────────────────────────────────────────────────
```

**핵심 기능**:
| 기능 | 설명 |
|------|------|
| 단계별 시각화 | 발의 → 위원회 → 본회의 → 공포 과정 표시 |
| 인터랙티브 | 각 단계 클릭 시 상세 정보 표시 |
| 관계 탐색 | 발의 의원, 관련 법안, 유사 법안 연결 |
| 비교 뷰 | 원안 vs 수정안 비교 기능 |

### 2. 생성형 AI (LLM) 기반 서비스

**개념**: AI를 활용한 쉬운 입법 정보 제공

| 서비스 | 설명 | 예시 |
|--------|------|------|
| **법안 3줄 요약** | 긴 법안을 핵심 3줄로 요약 | "이 법안은 ~을 위해 ~를 개정하며, ~한 효과가 예상됩니다." |
| **쉬운 용어 해설** | 법률 용어를 일상 언어로 변환 | "기속행위 → 법에서 정한 대로만 해야 하는 행위" |
| **대화형 검색 챗봇** | 자연어 질문으로 정보 검색 | "최근 환경 관련 법안 알려줘" |
| **영향 분석** | 법안 통과 시 예상 영향 설명 | "이 법안이 통과되면 ~에게 ~한 영향이 있습니다." |

```
┌─────────────────────────────────────────────────────────────────┐
│                    AI 서비스 아키텍처                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  사용자 질문                                                     │
│      │                                                          │
│      ▼                                                          │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐        │
│  │ 의도 파악   │───►│ 검색/추출   │───►│ 응답 생성   │        │
│  │ (Intent)    │    │ (RAG)       │    │ (LLM)       │        │
│  └─────────────┘    └─────────────┘    └─────────────┘        │
│                            │                                    │
│                            ▼                                    │
│                     ┌─────────────┐                            │
│                     │ 지식 그래프 │                            │
│                     │ + 벡터 DB   │                            │
│                     └─────────────┘                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3. 개인화 대시보드 (My Archive)

**개념**: 사용자 맞춤 정보 제공 공간

| 기능 | 설명 |
|------|------|
| 관심 의원 설정 | 특정 의원의 활동 알림 수신 |
| 관심 법안 추적 | 법안 진행 상황 변경 시 알림 |
| 스크랩북 | 관심 문서/법안 저장 및 폴더 관리 |
| 맞춤 추천 | 관심 분야 기반 관련 법안 추천 |
| 검색 히스토리 | 이전 검색 기록 및 재검색 |
