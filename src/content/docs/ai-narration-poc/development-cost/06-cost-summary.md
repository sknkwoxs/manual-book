## 시나리오별 비용 비교

### 시나리오 A: 최소 PoC (P0만)

핵심 파이프라인만 구축하여 **"영상 → AI 해설 텍스트"** 가능성을 검증합니다.

| 항목 | 내용 |
|------|------|
| 범위 | 영상 입력 → Gemini 분석 → 해설 텍스트 생성 |
| 기간 | **4\~7주** |
| 비용 | **₩16,292,000 \~ ₩28,788,000** (\~$11,806 \~ $20,861) |
| 인력 | 2명 (백엔드 1 + AI/ML 1) |
| 제한 | 편집 UI 없음, TTS 없음, 해설 텍스트만 출력 |
| 적합 대상 | AI 분석 정확도 검증, 기술 실현 가능성 확인 |

### 시나리오 B: 핵심 기능 (P0+P1)

사용자가 실제로 활용할 수 있는 **최소 완성 서비스**를 구축합니다.

| 항목 | 내용 |
|------|------|
| 범위 | 영상 입력 → 분석 → 해설 생성 → 편집 UI → TTS 합성 → 영상 배포 |
| 기간 | **8\~13주** |
| 비용 | **₩27,805,000 \~ ₩45,993,000** (\~$20,148 \~ $33,329) |
| 인력 | 3명 (백엔드 1 + AI/ML 1 + 프론트엔드 1) |
| 제한 | 단일 사용자 편집, 버전 관리 없음 |
| 적합 대상 | 내부 파일럿 운영, 소규모 실사용 테스트 |

|------|-----------|-------------|
