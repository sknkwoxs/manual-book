## 산출 방법론

본 개발 비용 추산은 **M/M(Man-Month) 기반 투입 공수 산정** 방식을 사용합니다.

| 항목 | 기준 |
|------|------|
| 산출 단위 | M/M (Man-Month, 1인 1개월 투입) |
| 1 M/M | 22 영업일 (월 기준) |
| 1주 | 5 영업일 = 약 0.23 M/M |
| 단가 기준 | 2025년 한국소프트웨어산업협회(KOSA) SW기술자 등급별 노임단가 참고 |
| 통화 | KRW (₩) 기준, 참고용 USD 병기 (₩1,380/$ 기준) |

## 인력 구성

### 역할별 투입 인력

| 역할 | 등급 | 주요 업무 | 투입 시점 |
|------|------|-----------|-----------|
| **백엔드 개발자** | 중급 (특급\~고급) | FastAPI 서버, API 설계, Celery 비동기 처리, DB 설계 | P0\~P2 |
| **AI/ML 엔지니어** | 고급 (특급) | Gemini API 연동, 프롬프트 엔지니어링, 파이프라인 구축 | P0\~P3 |
| **프론트엔드 개발자** | 중급 (고급) | React 편집 UI, 영상 플레이어, CRDT 실시간 편집 | P1\~P2 |
| **인프라/DevOps** | 중급 (고급) | AWS 인프라, CI/CD, 모니터링, 배포 자동화 | P0\~P1 |
| **PM/QA** | — | 프로젝트 관리, 품질 검증, 테스트 (겸임 가능) | 전 기간 |

> **PoC 특성**: 소규모 팀(3\~4명)으로 역할 겸임이 가능합니다. 백엔드 개발자가 인프라를 겸임하거나, AI/ML 엔지니어가 백엔드를 일부 담당하는 구성이 현실적입니다.

### 최소 투입 인력 (PoC 기준)

| 구성 | 인원 | 비고 |
|------|------|------|
| **최소 구성** | 2명 | 백엔드+AI/ML 1명, 프론트엔드+인프라 1명 |
| **권장 구성** | 3명 | 백엔드 1명, AI/ML 1명, 프론트엔드 1명 (인프라 겸임) |
| **이상적 구성** | 4명 | 각 역할 전담 + PM/QA 겸임 |

## 인건비 단가

### KOSA 2025년 SW기술자 등급별 노임단가 (참고)

한국소프트웨어산업협회에서 매년 공시하는 SW기술자 노임단가를 기준으로 산정합니다.

| 등급 | 월 단가 (M/M) | 일 단가 | 비고 |
|------|---------------|---------|------|
| 특급기술자 | ₩14,000,000 | ₩636,364 | 10년 이상 경력, AI/ML 전문가 |
| 고급기술자 | ₩11,500,000 | ₩522,727 | 6\~10년 경력, 시니어 개발자 |
| 중급기술자 | ₩9,000,000 | ₩409,091 | 3\~6년 경력, 미드레벨 개발자 |
| 초급기술자 | ₩6,500,000 | ₩295,455 | 1\~3년 경력 |

> **참고**: 실제 KOSA 공시 단가는 매년 조정됩니다. 위 수치는 2025년 기준 시장 실거래가를 반영한 참고 단가이며, 프리랜서 시장에서는 ±10\~20% 차이가 있을 수 있습니다.

### 본 프로젝트 적용 단가

| 역할 | 적용 등급 | 월 단가 (M/M) | 비고 |
|------|-----------|---------------|------|
| AI/ML 엔지니어 | 특급 | **₩14,000,000** | Gemini API, 프롬프트 엔지니어링, Fine-tuning |
| 백엔드 개발자 | 고급 | **₩11,500,000** | FastAPI, PostgreSQL, Celery, AWS |
| 프론트엔드 개발자 | 고급 | **₩11,500,000** | React, Video.js, CRDT/WebSocket |
| 인프라/DevOps | 고급 | **₩11,500,000** | AWS, CI/CD, 모니터링 |
| PM/QA (겸임) | — | **₩0** | 개발자 겸임 (별도 산정 안 함) |

> **단가 산정 근거**: AI/ML 분야는 시장 수요 대비 인력 공급이 부족하여 특급 단가를 적용합니다. 백엔드/프론트엔드/인프라는 고급 단가 기준으로 산정하되, PoC 규모를 감안하여 PM/QA는 개발자 겸임으로 별도 비용을 산정하지 않습니다.

## 비용 산출 전제 조건

| 항목 | 전제 |
|------|------|
| 근무 형태 | 풀타임 (주 5일, 일 8시간) |
| 개발 환경 | 개발자 개인 장비 사용 (별도 장비 비용 미포함) |
| 오피스/시설 | 원격 근무 기준 (시설 비용 미포함) |
| 라이선스 | 오픈소스 기반 (별도 상용 라이선스 비용 없음) |
| 클라우드 비용 | 개발/테스트 환경 AWS 비용은 운영 비용에 포함 |
| 예비비 | 단계별 10% 예비비 반영 |
| 위험 요소 | AI API 변경, 요구사항 변경 등 리스크 버퍼 포함 |
