서지정보(메타데이터)를 기술하는 다양한 방식과 포토라이브러리에서 사용하는 필드를 안내합니다.

## 메타데이터란?

**"데이터에 대한 데이터"** — 책 자체가 아니라 책을 설명하는 정보입니다.

| 구분 | 예시 |
|------|------|
| 데이터 | 책의 내용, 사진, 텍스트 |
| 메타데이터 | 제목, 저자, 출판사, ISBN, 청구기호 |

---

## 메타데이터 표준 비교

### 1. MARC (Machine-Readable Cataloging)

**용도**: 전문 도서관, 사서용  
**특징**: 매우 상세하고 구조화된 필드, 숫자 태그 체계

| MARC 태그 | 필드명 | 설명 |
|-----------|--------|------|
| 020 | ISBN | 국제표준도서번호 |
| 100 | 기본표목-개인명 | 주저자 |
| 245 | 표제사항 | 본표제, 부표제, 책임사항 |
| 260 | 발행사항 | 발행지, 발행처, 발행연도 |
| 300 | 형태사항 | 페이지 수, 크기, 삽도 |
| 650 | 주제명부출표목 | 주제 분류 |
| 700 | 부출표목-개인명 | 공저자, 편집자, 사진가 |

**장점**: 국제 표준, 도서관 간 호환성  
**단점**: 복잡한 구조, 전문 지식 필요

---

### 2. Dublin Core (더블린 코어)

**용도**: 웹, 디지털 아카이브  
**특징**: 15개 핵심 요소, 단순하고 범용적

| 요소 | 영문 | 설명 |
|------|------|------|
| 표제 | Title | 자원의 이름 |
| 창작자 | Creator | 저자, 작가, 사진가 |
| 주제 | Subject | 키워드, 분류 |
| 설명 | Description | 초록, 내용 요약 |
| 발행자 | Publisher | 출판사, 발행 기관 |
| 기여자 | Contributor | 편집자, 디자이너 등 |
| 날짜 | Date | 발행일, 제작일 |
| 유형 | Type | 도서, 사진집, 전시도록 |
| 형식 | Format | 페이지 수, 크기, 파일 형식 |
| 식별자 | Identifier | ISBN, URL, 등록번호 |
| 출처 | Source | 원본 자료 |
| 언어 | Language | 한국어, 영어 등 |
| 관계 | Relation | 관련 자료, 시리즈 |
| 범위 | Coverage | 지역, 시대 |
| 권한 | Rights | 저작권 정보 |

**장점**: 학습 용이, 범용성  
**단점**: 도서관 고유 요소(청구기호 등) 미포함

---

### 3. 일반적 표기 (서점/일반인)

**용도**: 서점, 온라인 쇼핑몰, 일반 독자  
**특징**: 직관적, 구매/열람에 필요한 최소 정보

| 필드 | 설명 | 예시 |
|------|------|------|
| 제목 | 책 이름 | 서울, 기록 |
| 저자 | 글쓴이/사진가 | 김영수 |
| 출판사 | 발행 기관 | 사진책방 |
| 출판일 | 발행 연월 | 2023년 5월 |
| 정가 | 판매 가격 | 35,000원 |
| ISBN | 바코드 번호 | 979-11-000000-0-0 |
| 페이지 | 분량 | 240쪽 |
| 크기 | 물리적 규격 | 210 x 297mm |

## 포토라이브러리 메타데이터 필드

서울시립사진미술관 포토라이브러리에서 실제 사용하는 필드입니다.

### 서지정보 (Bibliography)

| 필드명 | 영문 | MARC | Dublin Core | 필수 |
|--------|------|------|-------------|------|
| 서명 | title | 245 | Title | O |
| 저자 | author | 100/700 | Creator | O |
| 발행사항 | publisher | 260$b | Publisher | - |
| 발행연도 | publish_year | 260$c | Date | O |
| ISBN | ea_isbn | 020 | Identifier | - |

### 소장정보 (Collection)

| 필드명 | 영문 | 설명 | 필수 |
|--------|------|------|------|
| 자료실명 | lib_name | 소장 도서관/자료실 | - |
| 청구기호 | call_no | 서가 위치 코드 | - |
| 등록번호 | reg_no | 고유 식별자 (PK) | O |
| 자료유형 | form_code_desc | 도서, 잡지, DVD 등 | - |
| 자료상태 | working_status_desc | 배가/대출중/비치 | - |

### 위치정보 (Location)

| 필드명 | 영문 | 선택지 |
|--------|------|--------|
| 시설 | room | 열람실, 특수자료실, 보존서고, 수장고, 필름수장고 |
| 열람실 | reading | A-D, E-G, CURATION, WRM |

## 필드별 명확성 분류

### 명확한 필드 (객관적 기술)

누가 작성해도 동일한 결과가 나오는 필드입니다.

| 필드 | 근거 | 예시 |
|------|------|------|
| ISBN | 책에 인쇄됨 | 979-11-000000-0-0 |
| 발행연도 | 판권면에 명시 | 2023 |
| 페이지 수 | 물리적 확인 | 240 |
| 출판사 | 판권면에 명시 | 사진책방 |
| 크기 | 실측 가능 | 210 x 297mm |
| 등록번호 | 라벨에 부착 | WRM000001523 |

### 해석이 필요한 필드 (주관적 기술)

작성자의 판단이 개입되는 필드입니다.

| 필드 | 해석 포인트 | 예시 |
|------|-------------|------|
| 제목 | 본표제 vs 부표제 구분, 시리즈명 포함 여부 | "서울, 기록" vs "서울, 기록: 1990-2020" |
| 저자 | 복수 저자 순서, 역할 구분 (글/사진/편집) | "김영수 사진; 이철수 글" |
| 주제/키워드 | 어떤 개념으로 분류할 것인가 | 다큐멘터리? 풍경? 도시? |
| 분류기호 | DDC, KDC 등 체계 선택 | 660.9 vs 779.4 |

## 사진도서의 특수 메타데이터

일반 도서와 달리 사진도서에서 중요한 요소들입니다.

### 물질성 관련

| 요소 | 설명 | 예시 |
|------|------|------|
| 판형 | 제본 방식 | 양장, 무선, 아코디언, 낱장 |
| 인쇄 방식 | 제판/인쇄 기법 | 오프셋, 리소, 실크스크린, 은염 |
| 종이 | 용지 종류 | 아트지, 모조지, 수제지 |
| 에디션 | 한정판 정보 | 500부 한정, 넘버링 |
| 서명 | 작가 사인 여부 | Signed copy |

### 내용 관련

| 요소 | 설명 |
|------|------|
| 사진가 | 이미지 창작자 (저자와 다를 수 있음) |
| 시퀀스 | 사진 배열 구조 (시간순, 주제별 등) |
| 텍스트 | 에세이, 캡션, 작가노트 포함 여부 |
| 시리즈 | 연작의 일부인 경우 |

## 워크숍에서 기술할 필드

교육 참여자가 입력할 필드는 다음과 같습니다.

### 필수 입력 (5개)

1. **서명** (title) — 책 표지/속표지의 제목
2. **저자** (author) — 사진가, 글쓴이 (세미콜론으로 구분)
3. **발행연도** (publish_year) — 4자리 숫자
4. **등록번호** (reg_no) — 라벨의 고유번호
5. **나의 한 줄** — 이 책을 한 문장으로 (주관적 해석)

### 선택 입력 (4개)

6. 출판사 (publisher)
7. ISBN (ea_isbn)
8. 자료유형 (form_code_desc)
9. 특이사항 — 물질성, 에디션, 컨디션 메모
