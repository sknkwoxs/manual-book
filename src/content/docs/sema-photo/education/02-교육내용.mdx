## 주제

**도서 서지(메타데이터) 등록해보기**

라이브러리에 있는 사진도서 한 권을 선택하여, 스스로 서지정보를 파악하고 수집하고 등록해보는 체험형 교육.

---

## 교육 목표

### 지식 목표
- 서지정보(메타데이터)의 개념 이해
- 도서관/아카이브에서 서지정보가 왜 중요한지 체감
- 검색 시스템이 어떻게 서지정보를 활용하는지 이해

### 기능 목표
- 사진도서에서 서지정보 항목을 직접 찾아낼 수 있다
- 포토라이브러리 검색 시스템을 활용할 수 있다
- 서지정보 양식을 작성할 수 있다

### 태도 목표
- 책을 "정보"의 관점에서 바라보는 시선 획득
- 아카이브 작업에 대한 관심과 이해

---

## 참여자 활동

### Step 1. 도서 선택

포토라이브러리 서가에서 **사진도서 1권**을 직접 선택한다.

- 자유롭게 서가를 둘러보며 선택
- "왜 이 책을 골랐는가"도 하나의 관점

### Step 2. 서지정보 수집

선택한 도서를 살펴보며 다음 정보를 찾아 기록한다:

| 항목 | 설명 | 찾는 위치 |
|------|------|----------|
| 제목 (서명) | 책의 공식 제목 | 표지, 속표지, 판권 |
| 저자 | 사진가, 저자, 편집자 | 표지, 판권 |
| 출판사 | 출판사명 | 판권 페이지 |
| 출판연도 | 초판 발행년도 | 판권 페이지 |
| 크기 (판형) | 가로 × 세로 cm | 직접 측정 |
| 페이지 수 | 총 페이지 | 직접 세거나 판권 확인 |
| ISBN | 국제표준도서번호 | 뒤표지, 판권 |
| 주제 / 키워드 | 내용을 설명하는 단어들 | **참여자가 직접 부여** |

### Step 3. 서지정보 등록

수집한 정보를 **양식(워크시트)**에 기입한다.

- 종이 양식 또는 디지털 폼
- 검색 시스템에 어떻게 반영되는지 설명

### Step 4. 발표 및 공유

각자 작성한 서지정보를 발표하고 비교한다.

- 같은 책도 다른 키워드를 부여할 수 있음
- 서로의 관점 차이 발견

## 교육 환경의 특수성

### 휴관일 진행의 장점

- 열람실 독점 사용 가능
- 비어있는 미술관에서 자유롭게 이동
- 서가 전체를 교육 공간으로 활용

### 사진도서의 특수성

- 이미지 중심 — 글을 읽지 않아도 접근 가능
- 물질성이 중요 — 종이, 인쇄, 제본의 미학
- 파라텍스트가 풍부 — 작가 노트, 에세이, 에디션 정보

---

## 기대 효과

1. **사진도서와의 새로운 만남** — 평소와 다른 방식으로 책을 경험
2. **메타데이터 리터러시 향상** — 정보 구조에 대한 이해
3. **아카이브 인식 제고** — 도서관/아카이브 작업의 가치 인식
4. **참여의 즐거움** — 직접 정보를 생산하는 경험
