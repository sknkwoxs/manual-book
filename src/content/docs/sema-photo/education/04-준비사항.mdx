## 교육 자료

### 필수 자료

- [ ] **서지정보 기입 양식**
  - `edu.semaphotolibrary.org` 내 자체 폼으로 대체

- [ ] **서지정보 항목 설명 가이드**

  - 사진도서 특화 항목 포함 (에디션, 사진가 표기 등)

- [ ] **포토라이브러리 검색 시스템 사용 가이드**
  - 기본 검색 방법
  - 필터 활용법
  - 스크린샷 포함

### 선택 자료

- [ ] 서지정보 예시 책 (실물)
  - 강의 시 시연용
  - 파라텍스트가 풍부한 사진집

- [ ] 프레젠테이션 슬라이드
  - 1부 강의용

## 워크숍 도구: 교육 플랫폼

### 개요

교육 자료 + 서지정보 입력 + 도서카드 갤러리를 하나의 웹사이트에서 제공하는 원스톱 플랫폼.

- **도메인**: `edu.semaphotolibrary.org`
- **호스팅**: Cloudflare Workers
- **참고**: [neworder.xyz](https://neworder.xyz/) 스타일 단일 페이지
- **도서카드 UI 참고**: [birdcall.online/library-card.html](https://birdcall.online/library-card.html)

### 사이트 구조

```
edu.semaphotolibrary.org (단일 페이지, 스크롤)
│
├── 섹션 1: 교육 소개
│   ├── 교육 제목, 일정, 장소
│   └── 교육 목표, 흐름 안내
│
├── 섹션 2: 서지정보 가이드
│   ├── 서지정보란?
│   ├── 항목별 설명 (제목, 저자, 출판사...)
│   └── 찾는 방법 안내
│
├── 섹션 3: 서지정보 입력 (폼)
│   └── 자체 폼 → Google Sheets 연동
│       (빈티지 도서카드 스타일 UI)
│
└── 섹션 4: 도서카드 갤러리
    └── 제출된 서지정보 실시간 표시 + 검색
```

### 기술 스택

| 구성 | 도구 | 비고 |
|------|------|------|
| 폼 | 자체 HTML 폼 | 도서카드 스타일 UI |
| 저장 | Google Apps Script → Sheets | 제출 즉시 반영 |
| CSS | Pico CSS (Sand 테마) | 빈티지 도서카드 스타일 |
| 검색 | Fuse.js | 클라이언트 fuzzy search |
| 파싱 | PapaParse | CSV → JSON |
| 호스팅 | Cloudflare Workers | `edu.semaphotolibrary.org` |

### 참여자 경험

1. **접속**: QR 코드 스캔 → `edu.semaphotolibrary.org`
2. **학습**: 스크롤하며 교육 내용, 서지정보 가이드 확인
3. **입력**: 같은 페이지에서 서지정보 폼 작성
4. **제출**: 제출 버튼 클릭 → 즉시 갤러리에 반영
5. **확인**: 아래로 스크롤하여 자신의 도서카드 확인
6. **공유**: 3부 시간에 프로젝터로 전체 갤러리 공유
