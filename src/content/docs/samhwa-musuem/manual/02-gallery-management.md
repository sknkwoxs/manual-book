## 1. 갤러리 개요

갤러리 메뉴에서는 뮤지엄 사이트에 표시될 이미지들을 등록하고 관리할 수 있습니다.

---

## 2. 갤러리 목록

### 목록 확인

1. 좌측 메뉴에서 **갤러리** 클릭 (또는 **미디어** 메뉴 활용)
2. 등록된 갤러리 이미지 목록이 표시됩니다

| 컬럼 | 설명 |
|------|------|
| **제목** | 이미지 제목 |
| **썸네일** | 이미지 미리보기 |
| **설명** | 이미지 설명 |
| **날짜** | 등록일 |

---

## 3. 갤러리 이미지 등록

### 등록 절차

1. **갤러리** > **새로 추가** 클릭
2. 이미지 파일 드래그 또는 **파일 선택** 클릭
3. 다음 항목을 입력합니다:

| 필드 | 설명 | 필수 |
|------|------|------|
| 제목 | 이미지 제목 | ✅ |
| 설명 | 이미지 설명 | - |
| 대표 이미지 | 갤러리 이미지 파일 | ✅ |

4. 업로드 완료 확인

### 다중 업로드

여러 이미지를 한 번에 업로드할 수 있습니다:
1. **새로 추가** 클릭
2. 여러 이미지 파일을 선택하거나 드래그 앤 드롭
3. 각 이미지의 제목/설명 개별 입력

---

## 4. 권장 이미지 규격

### 기본 규격

| 용도 | 권장 크기 | 형식 | 최대 용량 |
|------|----------|------|----------|
| 대표 이미지 | 1200 x 630px | JPG, WebP | 2MB |
| 갤러리 이미지 | 1920 x 1080px | JPG, WebP | 2MB |
| 썸네일 | 400 x 400px | JPG, WebP | 500KB |

### 이미지 형식 권장

| 형식 | 특징 | 권장 용도 |
|------|------|----------|
| **WebP** | 용량 작음, 품질 우수 | 일반 사용 권장 |
| **JPG** | 범용성 높음 | 사진 이미지 |
| **PNG** | 투명 배경 지원 | 로고, 아이콘 |

### 파일명 규칙

- **영문** 사용 권장
- **숫자**, **하이픈(-)** 사용 가능
- **한글**, **공백**, **특수문자** 사용 금지

```
✅ 좋은 예: gallery-image-01.jpg, event-photo-2026.webp
❌ 나쁜 예: 갤러리 이미지.jpg, photo (1).jpg
```

---

## 5. 갤러리 수정

### 수정 절차

1. 갤러리 목록에서 수정할 이미지 클릭
2. 제목/설명 수정
3. **업데이트** 버튼 클릭

### 이미지 교체

기존 이미지를 새 이미지로 교체하려면:
1. 기존 항목 삭제
2. 새 이미지로 다시 등록

> **참고**: 이미지 파일 자체를 수정하는 것은 불가능합니다. 새로 업로드해야 합니다.

---

## 6. 갤러리 삭제

### 삭제 절차

1. 갤러리 목록에서 삭제할 이미지에 마우스 오버
2. **영구 삭제** 클릭

> **주의**: 삭제된 이미지는 복구할 수 없습니다. 삭제 전 반드시 확인하세요.

### 일괄 삭제

여러 이미지를 한 번에 삭제하려면:
1. 삭제할 이미지들의 체크박스 선택
2. 일괄 작업 드롭다운에서 **영구 삭제** 선택
3. **적용** 클릭

---

## 7. 이미지 최적화 팁

### 업로드 전 최적화

| 도구 | 용도 | URL |
|------|------|-----|
| TinyPNG | PNG/JPG 압축 | tinypng.com |
| Squoosh | WebP 변환 | squoosh.app |
| 미리캔버스 | 리사이즈 | miricanvas.com |

### 권장 작업 순서

1. 원본 이미지 준비
2. 적절한 크기로 리사이즈 (1920x1080px 이하)
3. WebP 또는 JPG로 변환
4. 압축 (품질 80% 권장)
5. 파일명 영문으로 변경
6. 업로드

---

## 8. 자주 묻는 질문

### Q: 이미지가 업로드되지 않아요

**A**: 다음을 확인하세요:
- 파일 크기가 2MB 이하인지 확인
- 파일명에 한글이나 특수문자가 없는지 확인
- 지원하는 형식(JPG, PNG, WebP, GIF)인지 확인

### Q: 이미지가 흐리게 보여요

**A**: 업로드한 이미지 해상도가 너무 낮을 수 있습니다. 권장 크기(1920x1080px) 이상의 이미지를 사용하세요.

### Q: 갤러리 순서를 변경하고 싶어요

**A**: 갤러리 목록에서 드래그 앤 드롭으로 순서를 변경할 수 있습니다.

### Q: WebP 형식을 사용해야 하나요?

**A**: WebP 형식을 권장하지만, JPG도 문제없이 사용 가능합니다. WebP는 같은 품질 대비 파일 크기가 작아 페이지 로딩 속도에 유리합니다.
