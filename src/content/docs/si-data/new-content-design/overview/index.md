## 분석 목적

신규 콘텐츠 타입 설계를 위한 기존 시스템 분석:

1. **콘텐츠 타입 분석**
   - 기존 12개 콘텐츠 타입의 필드 구성 파악
   - 공통 요소 추출 및 통합 설계

2. **택소노미 분석**
   - 기존 분류 체계 파악
   - ITEM 서비스/카테고리 구조 이해
