## 1. data_seoul (데이터로 본 서울)

통계 데이터 시각화 콘텐츠를 계층적으로 분류하는 4개의 택소노미를 사용합니다.

### 1.1 택소노미 구조

| 택소노미 ID | 한글명 | 필드명 | 목적 | auto_create |
|------------|--------|--------|------|-------------|
| `category_service` | 간행물 | `field_service` | 데이터 출처가 되는 간행물/발간물 분류 | No |
| `category_series` | 구분(연도) | `field_series` | 연도별 시리즈 구분 | No |
| `category_chapter` | 장 | `field_chapter` | 소제목/장 구분 | **Yes** |
| `category_data` | 분야 | `field_category_data` | 데이터 주제 분야 분류 | No |

### 1.2 분류 체계

```
간행물 (category_service)
  └── 구분/연도 (category_series)
        └── 장 (category_chapter)
              └── 분야 (category_data)
```

## 2. archi (근현대 유산)

서울의 근현대 건축/문화 유산 속성을 분류하는 4개의 택소노미를 사용합니다.

### 2.1 택소노미 구조

| 택소노미 ID | 한글명 | 필드명 | 목적 | auto_create |
|------------|--------|--------|------|-------------|
| `physical` | 물리적형태 | `field_physical` | 건물/구조물의 물리적 형태 분류 | No |
| `owner` | 소유형태 | `field_owner` | 소유 주체 분류 | No |
| `projecttype` | 사업방식 | `field_projecttype` | 보존 사업 방식 분류 | No |
| `conservation` | 보전방식 | `field_conservation` | 보전/활용 방식 분류 | No |

### 2.2 분류 체계

```
근현대 유산 콘텐츠
├── 물리적형태 (physical)      → 대상의 규모/형태
├── 소유형태 (owner)           → 소유 주체
├── 사업방식 (projecttype)     → 보존 사업 유형
└── 보전방식 (conservation)    → 보전 방법
```

### 2.3 택소노미 용어 목록

#### physical (물리적형태) - 5개 용어

| 용어명 | 설명 |
|--------|------|
| 단일 | 단일 건물 |
| 단지 | 복수 건물 단지 |
| 가로 | 가로/거리 단위 |
| 마을 | 마을 단위 |
| 지역 | 지역 단위 |

#### owner (소유형태) - 3개 용어

| 용어명 | 설명 |
|--------|------|
| 공공 | 공공 소유 |
| 민간 | 민간 소유 |
| 공/민 | 공공/민간 혼합 |

#### conservation (보전방식) - 6개 용어

| 용어명 | 설명 |
|--------|------|
| 원형보전 | 원래 형태 그대로 보전 |
| 부분보전 | 일부만 보전 |
| 이미지보전 | 이미지/외관 보전 |
| 행위보전 | 활동/행위 중심 보전 |
| 기록 | 기록으로 보존 |

## 4. 개선 제안사항

### 4.1 data_seoul

1. **중복/유사 용어 정리**
   - `category_chapter`: "산업활동과재정" / "산업활동과 재정" 통합 필요
   - `category_service`: "지도로 본 서울" 시리즈 명명 규칙 통일

2. **계층 구조 재검토**
   - `category_series`에 연도와 편(인구편, 경제편 등)이 혼재됨
   - 연도는 별도 필드로 분리 검토

### 4.2 archi

1. **중복 용어 제거**
   - `projecttype`: "도시재생" 중복 등록 정리

2. **용어 분류 체계화**
   - `projecttype`의 23개 용어를 상위 카테고리로 그룹화 검토
