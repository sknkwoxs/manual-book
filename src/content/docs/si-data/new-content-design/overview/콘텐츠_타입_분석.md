## 2. 핵심 데이터 콘텐츠

### 2.1 data_seoul (데이터로 본 서울 - 콘텐츠)

통계 데이터 시각화의 핵심 콘텐츠 타입입니다.

**설정 파일:** `config/sync/node.type.data_seoul.yml`

#### 필드 구성 (17개)

| 필드명 | 필드 타입 | 목적 | 참조 대상 |
|--------|----------|------|-----------|
| `body` | text_with_summary | 본문 | - |
| `field_service` | entity_reference | 간행물 분류 | taxonomy: `category_service` |
| `field_series` | entity_reference | 연도 구분 | taxonomy: `category_series` |
| `field_chapter` | entity_reference | 장 구분 | taxonomy: `category_chapter` |
| `field_category_data` | entity_reference | 분야 분류 | taxonomy: `category_data` |
| `field_content` | entity_reference_revisions | 콘텐츠 블록 | paragraph: `chart`, `html_text`, `pdf` |
| `field_related_data` | entity_reference_revisions | 연관 콘텐츠 | paragraph: `data_seoul` |
| `field_data_year` | string | 데이터 연도 | - |
| `field_date` | datetime | 날짜 | - |
| `field_html_file` | file | HTML 파일 | - |
| `field_linkurl` | link | 링크 URL | - |
| `field_attached_file` | file | 첨부 파일 | - |
| `field_data_format` | string | 데이터 포맷 | - |
| `field_es` | string | Elasticsearch 색인용 | - |
| `field_issueinfo` | string | 발행 정보 | - |
| `field_keyword` | string | 키워드 | - |
| `field_thumbnail` | image | 썸네일 | - |

#### 택소노미 참조

```
data_seoul
├── field_service      → category_service (간행물)
├── field_series       → category_series (구분/연도)
├── field_chapter      → category_chapter (장)
└── field_category_data → category_data (분야)
```

## 8. Paragraph 타입

콘텐츠 내 재사용 가능한 블록 구성요소입니다.

| Paragraph ID | 한글명 | 사용처 | 설명 |
|--------------|--------|--------|------|
| `chart` | 데이터 차트 | data_seoul, front_page | 차트 임베딩 |
| `html_text` | 설명 | data_seoul, data_collection | 텍스트 설명 |
| `pdf` | PDF | data_seoul, insight_report | PDF 파일 첨부 |
| `iframe` | iframe | insight_report | iframe 임베딩 |
| `data_seoul` | 데이터로 본 서울 | data_collection, field_related_data | data_seoul 노드 참조 |
| `image` | 이미지 | front_page | 이미지 표시 |
| `photo_seoul` | 사진 | front_page | 사진 표시 |
| `subtitle` | 소제목 | front_page | 섹션 구분 |
| `attached_file` | 첨부파일 | data_collection | 파일 첨부 |
| `test` | 테스트 | - | 테스트용 |

### Paragraph 사용 관계

```
data_seoul.field_content
├── chart (데이터 차트)
├── html_text (설명)
└── pdf (PDF)

data_seoul.field_related_data
└── data_seoul (연관 콘텐츠)

data_collection.field_data_seoul
├── data_seoul
├── html_text
└── attached_file

insight_report.field_paragraph
├── iframe
└── pdf

front_page.field_data
├── subtitle
```

## 10. 새 콘텐츠 타입 생성 가이드

### 10.1 콘텐츠 타입 정의 파일

```yaml
# config/sync/node.type.{machine_name}.yml
uuid: {auto-generated}
langcode: ko
status: true
dependencies:
  module:
    - menu_ui
third_party_settings:
  menu_ui:
    available_menus:
      - main
    parent: 'main:'
name: '한글 이름'
type: machine_name
description: '설명'
help: null
new_revision: true
preview_mode: 1
display_submitted: true
```

### 10.2 필드 추가 절차

1. **Field Storage 생성** (재사용 가능한 필드 정의)
   - `config/sync/field.storage.node.field_{name}.yml`

2. **Field Instance 생성** (콘텐츠 타입에 필드 연결)
   - `config/sync/field.field.node.{content_type}.field_{name}.yml`

3. **Form Display 설정** (편집 폼 설정)
   - `config/sync/core.entity_form_display.node.{content_type}.default.yml`

4. **View Display 설정** (표시 설정)
   - `config/sync/core.entity_view_display.node.{content_type}.default.yml`

### 10.3 택소노미 참조 필드 예시

```yaml
# field.field.node.{content_type}.field_category.yml
uuid: {auto-generated}
langcode: ko
status: true
dependencies:
  config:
    - field.storage.node.field_category
    - node.type.{content_type}
    - taxonomy.vocabulary.{vocabulary_id}
id: node.{content_type}.field_category
field_name: field_category
entity_type: node
bundle: {content_type}
label: '분류'
description: ''
required: false
translatable: false
default_value: {}
default_value_callback: ''
settings:
  handler: 'default:taxonomy_term'
  handler_settings:
    target_bundles:
      {vocabulary_id}: {vocabulary_id}
    sort:
      field: name
      direction: asc
    auto_create: false
    auto_create_bundle: ''
field_type: entity_reference
```

### 10.4 Paragraph 참조 필드 예시

```yaml
# field.field.node.{content_type}.field_content.yml
settings:
  handler: 'default:paragraph'
  handler_settings:
    negate: 0
    target_bundles:
      chart: chart
      html_text: html_text
    target_bundles_drag_drop:
      chart:
        enabled: true
        weight: 1
      html_text:
        enabled: true
        weight: 2
field_type: entity_reference_revisions
```

### 10.5 권장 사항

1. **기존 택소노미 재사용**
   - `category_data` (분야)는 다중 콘텐츠에서 공유 가능
   - 새 택소노미 생성 전 기존 것 검토

2. **Elasticsearch 색인**
   - 검색 대상 콘텐츠는 `field_es` 필드 추가

3. **필드 네이밍 규칙**
   - 택소노미 참조: `field_{taxonomy_id}` 또는 의미있는 이름
   - 파일/이미지: `field_{purpose}_file`, `field_{purpose}_image`

4. **Paragraph 활용**
   - 복잡한 콘텐츠 구조는 Paragraph 타입 활용
   - 기존 Paragraph 재사용 권장
