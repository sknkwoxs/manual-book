## 개요

콘텐츠의 **주제별 분류**를 위한 택소노미입니다.

| 속성 | 값 |
|------|-----|
| 택소노미 ID | `category_topic` |
| 연결 필드 | `field_topic` |
| 용도 | 콘텐츠 주제별 분류 |
| 중복선택 | 가능 |

---

## 용어 목록 (18개)
