## 개요

콘텐츠의 **시기별 분류**를 위한 택소노미입니다.

| 속성 | 값 |
|------|-----|
| 택소노미 ID | `category_decade` |
| 연결 필드 | `field_decade` |
| 용도 | 콘텐츠 시기별 분류 (데이터 기준 연도) |
| 중복선택 | 가능 |

---

## 용어 목록 (4개)

| # | 용어명 | 설명 |
|---|--------|------|
| 1 | 1990년대 이전 | ~1999년 |
| 2 | 2000년대 | 2000~2009년 |
| 3 | 2010년대 | 2010~2019년 |
| 4 | 2020년대 | 2020~2029년 |

> **참고**: 발간연도가 아닌 **데이터 기준 연도**로 분류합니다.
