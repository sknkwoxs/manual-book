## 1. 개요

HTML 콘텐츠는 HTML 기반 콘텐츠를 위한 콘텐츠 타입입니다.

현재 기존 CMS에 해당 콘텐츠 타입이 존재하지 않으며, 신규 생성 여부를 고객과 협의 중입니다. 확정 시 공통요소 필드 적용 범위도 함께 결정될 예정입니다.

공통요소 필드는 [SI-DATA 콘텐츠 공통요소 설계 문서](../design-overview/#21-공통요소-8개-필드)를 참조하세요.
