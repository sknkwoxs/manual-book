## 공통 사항

모든 콘텐츠 타입은 동일한 **공통요소(group_common)** 필드 그룹을 공유합니다.

공통 필드 구성은 [SI-DATA 신규 콘텐츠 설계 문서](../SI-DATA_신규_콘텐츠_설계.md#21-공통요소-group_common)를 참조하세요.
