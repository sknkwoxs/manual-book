## 공통 사항

모든 대상 콘텐츠 타입은 동일한 **8개 공통요소 필드**를 추가합니다.

공통 필드 구성은 [SI-DATA 콘텐츠 공통요소 설계 문서](../design-overview/#21-공통요소-8개-필드)를 참조하세요.
