# GCED Clearinghouse

세계시민교육(GCED) 클리어링하우스 웹사이트 관리자 시스템입니다.

## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **프로젝트명** | 세계시민교육 클리어링하우스 웹사이트 리뉴얼 |
| **리뉴얼 시기** | 2025년 11월 |
| **고객사** | 유네스코 아시아태평양 국제이해교육원 (APCEIU) |
| **플랫폼** | Drupal 11 |

## 리뉴얼 주요 내용

- 전반적 디자인 개선을 통해 향상된 사용자 경험 제공
- 데이터 및 인프라 이관으로 안정적이고 지속 가능한 운영 확보

## 주요 기능

- 사용자 중심 UI/UX 개선
- 자료 검색 기능 고도화
- 다국어(7개 언어) 출력 기능
- 자료 관리, 번역 관리 등 관리 편의성 제고
