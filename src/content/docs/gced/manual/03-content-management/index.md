# 콘텐츠 관리

클리어링하우스의 주요 콘텐츠 타입을 관리하는 방법입니다.

---

## 콘텐츠 타입

클리어링하우스에서 관리하는 콘텐츠 타입은 4가지입니다.

| 콘텐츠 타입 | 위치 | 접근 권한 | 설명 |
|------------|------|----------|------|
| [Resources](./01-resources) | Board > Resources | 전체 관리자 | 세계시민교육 관련 자료 |
| [Events](./02-events) | Board > Events | Administrator | 행사/이벤트 |
| [News](./03-news) | Board > News | Administrator | 뉴스 |
| [Useful Links](./04-useful-links) | Board > Useful Links | Administrator | 외부 링크 |
| [파일 관리](./05-files) | Content > Files | Administrator | 업로드된 파일 관리 |

---

## 콘텐츠 목록 화면 공통 안내

각 콘텐츠 타입의 목록 화면은 공통적으로 다음 기능을 제공합니다.

| 기능 | 설명 |
|------|------|
| Front Page | 사용자 화면(프론트)에서 해당 콘텐츠 열람 |
| Add | 새 콘텐츠 추가 |
| Edit | 기존 콘텐츠 수정 (Operations 드롭다운) |
| Translate | 번역 추가 (Operations 드롭다운) |

---

## 공개/비공개 규칙

:::note
Published가 아닌 상태의 콘텐츠는 모두 비공개 처리됩니다. Published 상태의 콘텐츠만 웹사이트에 노출되며, 번역 작업이 가능합니다.
:::

- Resources는 워크플로우(Draft → Published → Archived)로 공개 상태를 관리합니다
- Events, News, Useful Links는 Published 체크박스로 공개/비공개를 설정합니다

---
