본 별지 서식은 제안서 제출 및 계약 체결 시 활용하는 표준 양식임. 발주처((주)좋은생각) 검토 후 일부 변경될 수 있음. 모든 서식은 흑색 인쇄 원본 1부와 사본 N부로 제출함.

- 발주처: (주)좋은생각 (대표 정용철)
- 제안사가 작성하는 서식의 회사명·대표자·인장은 제안사 정보로 기입함
- 발주처 정보가 명시된 항목은 사전 기입되어 있음

## 제11호 서식: 보안 서약서 (제안사)

| 항목 | 내용 |
| :--- | :--- |
| 발주처 | (주)좋은생각 |
| 사업명 | __________ |
| 회사명 | __________ |
| 대표자 | __________ |

본 제안사는 (주)좋은생각이 발주한 상기 사업 수행과 관련하여 다음과 같이 보안 의무를 준수할 것을 서약합니다.

1. 사업 수행 중 취득한 발주처의 모든 정보 및 자료를 외부에 누설하지 않음
2. 사업 종료 후에도 발주처의 사전 서면 동의 없이 관련 정보를 제3자에게 제공하거나 공개하지 않음
3. 사업 수행 중 취득한 자료는 사업 목적 외에 사용하지 않으며, 사업 종료 시 즉시 반환하거나 파기함
4. 보안 의무 위반 시 발생하는 모든 민·형사상 책임을 부담하며, 발주처가 청구하는 손해배상 및 위약금을 지체 없이 지급함

- 서약일자: __________
- 회사명: __________
- 대표자: __________ (인)

## 제13호 서식: 청렴 계약 이행 서약서 (제안사)

| 항목 | 내용 |
| :--- | :--- |

| 회사명 | __________ |
| 대표자 | __________ |

본 제안사는 (주)좋은생각이 발주한 상기 사업과 관련하여 다음과 같이 청렴 계약을 이행할 것을 서약합니다.

1. 입찰 및 계약 체결 과정에서 발주처 임직원에게 금품, 향응, 편의 등 어떠한 형태의 부정한 이익도 제공하지 않음
2. 입찰 담합, 서류 위조, 허위 사실 기재 등 부정한 방법으로 입찰에 참가하지 않음
3. 사업 수행 중 발주처 임직원으로부터 금품, 향응 요구를 받을 경우 즉시 발주처에 신고함
4. 본 서약을 위반할 경우 계약 해지, 입찰 참가 자격 제한, 손해배상 등 모든 불이익을 감수함

- 회사명: __________
- 대표자: __________ (인)
