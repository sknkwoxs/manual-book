## 1.3. 사업 배경 및 목적

### 1.3.1. 배경 — 현행 시스템(AS-IS)의 한계

좋은생각 정기구독 운영을 지원하는 현행 CS 시스템은 다음과 같은 구조적 한계 보유.

**(1) 기술적 한계**
- ActiveX 기반 C/S 프로그램(`cs.positive.co.kr`) — **Windows + Internet Explorer 전용**
- 사내 내부망 또는 내부 VPN(MikroTik PPTP) 접속 필수 — 사무실 PC 외 접근 불가
- WAS: Tomcat 7.0 (Windows Server 2012, EOL)
- DB: MSSQL Server 2008 (EOL) — 보안 패치 중단 상태
- 웹(자사몰·CMS·관리시스템) ↔ 현행 CS DB 간 범용 API 연동 부재

**(2) 데이터 단절**
- 채널별(자사몰·외부몰·후원) 데이터가 별도 DB에 고립
- 외부몰(네이버·쿠팡) 구독 주문이 현행 CS에 자동 반영되지 않음 — Playauto에서 Excel 다운로드 후 수동 업로드
- 담당자 Excel 수기 취합·업로드가 채널 통합의 유일한 수단

**(3) 업무 프로세스 비효율**
- 결제 발생 → CMS 콘텐츠 열람 권한 부여까지 수작업 지연 (최대 1영업일)
- 매출 등록·통장 내역 대조·CMS 권한 부여 등 수작업 의존
- 담당자 부재 시 업무 마비, 휴먼 에러 상존

### 1.3.2. 사업 목적

| 목적 | 세부 내용 |
|------|----------|
| **(1) 기술적 현대화** | 레거시 C/S 시스템을 100% 웹 기반 시스템으로 전환, 클라우드 환경에서의 안정 운영 기반 마련 |
| **(2) 데이터 통합** | 자사몰·외부몰·CMS·CS 시스템 간 고객·주문·구독 데이터 통합, API/Webhook 기반 실시간 동기화 |
| **(3) 프로세스 자동화** | 매출 등록·권한 부여·통장 대조 등 수작업 업무의 시스템화·표준화 |
| **(4) 운영 안정성** | 가용성·보안·확장성 확보를 통한 운영 리스크 최소화 |

### 1.3.3. CEO 비전

> 디지털 효율화를 통해 직원들이 CS 수동 작업에서 벗어나 **아날로그 감성의 창작 활동에 집중**할 수 있도록 한다. AI 시대에도 좋은생각의 아날로그 미디어 정체성은 보존하되, 백오피스는 디지털화한다.
