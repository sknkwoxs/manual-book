## 1.2 추진 배경

가. (주)좋은생각은 1993년 창립 이래 월간 《좋은생각》 발행, 단행본 출판, 아트상품 기획·판매 사업을 영위하고 있으며, 정기구독 기반의 안정적 사업 모델을 운영하고 있음.

나. 현행 CS 시스템은 ActiveX 기반 C/S 프로그램(Windows + Internet Explorer 전용)으로 구축되어 있으며, 다음과 같은 구조적 한계를 보유하고 있음.

  - (1) Windows Server 2012 + Tomcat 7.0 + MSSQL Server 2008 등 EOL(End of Life) 도달 기술 스택 사용
  - (2) 사내 내부망 또는 VPN(MikroTik PPTP) 접속 필수로 사무실 PC 외 접근 불가
  - (3) 보안 패치 중단으로 인한 정보보호 위험 상존
  - (4) 웹(자사몰·CMS·관리시스템) ↔ 현행 CS DB 간 범용 API 연동 부재

다. 채널별(자사몰·외부몰·후원) 데이터가 별도 데이터베이스에 고립되어 있으며, 외부몰(네이버 스마트스토어·쿠팡) 구독 주문이 현행 CS에 자동 반영되지 않아 담당자가 Excel 다운로드 후 수동 업로드를 수행하고 있음.

라. 결제 발생 시점부터 CMS 콘텐츠 열람 권한 부여까지 최대 1영업일이 소요되며, 매출 등록·통장 내역 대조·CMS 권한 부여 등 핵심 업무가 수작업에 의존하여 담당자 부재 시 업무 마비 및 휴먼 에러 발생 위험이 있음.

마. 디지털 효율화를 통해 직원이 CS 수동 작업에서 벗어나 아날로그 감성의 창작 활동에 집중할 수 있도록 백오피스를 디지털화할 필요성이 제기됨.

## 1.3 추진 목적

가. **기술적 현대화**: 레거시 C/S 시스템을 100% 웹 기반 시스템으로 전환하여 클라우드 환경에서의 안정 운영 기반을 마련함.

나. **데이터 통합**: 자사몰·외부몰·CMS·CS 시스템 간 고객·주문·구독 데이터를 통합하고, API/Webhook 기반의 실시간 동기화 체계를 구축함.

다. **프로세스 자동화**: 매출 등록·권한 부여·통장 대조 등 수작업 업무를 시스템화·표준화하여 업무 효율을 제고함.

라. **운영 안정성 확보**: 가용성·보안·확장성 확보를 통해 운영 리스크를 최소화함.

마. **차세대 기반 마련**: 향후 AI 검색·추천, 디지털 아카이브 등 차세대 시스템 도입을 위한 데이터 인프라 기반을 마련함.

## 1.4 사업 범위

### 1.4.1 시스템 구축 범위

가. **신규 개발**: 웹 기반 CS 관리 시스템 신규 구축 (10개 도메인, 79건 기능 요구사항)

  - (1) 대시보드 (DB 도메인): 5건
  - (2) 고객 관리 (CM 도메인): 9건
  - (3) 구독 관리 (SB 도메인): 11건
  - (4) 주문 관리 (OM 도메인): 5건
  - (5) 배송 관리 (DL 도메인): 9건
  - (6) 결제·정산 관리 (FN 도메인): 16건
  - (7) CS 상담 관리 (CS 도메인): 10건
  - (8) 선물 관리 (GF 도메인): 4건
  - (9) 재고/도서 관리 (BK 도메인): 3건
  - (10) 시스템 관리 (AD 도메인): 7건

나. **데이터 연동**: 자사몰, 외부몰(네이버 스마트스토어, 쿠팡 등), CMS, ERP(위하고), PG(나이스페이), CTI, 외부 콜센터(더아이앤오) 시스템과의 연동 인터페이스 구축

다. **데이터 이관**: 기존 MSSQL Server 2008 기반 CS 데이터의 신규 데이터베이스 이관

라. **인프라 구축**: 클라우드 기반 인프라 설계·구축·운영 환경 셋업 (클라우드 사업자 및 구체 서비스명은 제안사 자유 선정)

마. **교육 및 매뉴얼**: 사용자 교육 시행 및 운영자/관리자 매뉴얼 작성

## 1.6 사업 예산

가. **총 사업 예산**: __________ 원 (부가가치세 별도/포함 여부: __________)

나. 본 사업의 예산은 발주처 내부 예산 승인 절차를 거쳐 확정되며, 제안서 가격은 본 예산을 초과할 수 없음.

라. ISP 단계 추정 참고치

  - (2) 1년차 운영·유지보수비: 약 56,114,000원 (인프라 운영비 + 유지보수 + 긴급 장애 대응 예비)
  - (3) 1년차 총 비용: 약 320,114,000원
  - (4) 본 추정치는 SI 시장 평균 단가 및 클라우드 운영 일반 사양 기준이며, 실제 예산은 발주처 예산 승인 결과에 따라 확정됨
