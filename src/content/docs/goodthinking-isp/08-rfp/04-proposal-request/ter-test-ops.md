---
title: 4.3.5 테스트 및 운영 요구사항 (TER)
---

테스트 및 운영 요구사항(TER, Test & Operations Requirements)은 시스템 구축 후 안정적인 서비스 전환과 지속적인 운영을 보장하기 위한 검증·안정화·모니터링 활동을 정의합니다. 통합 테스트, 사용자 인수 테스트(UAT), 성능·부하 테스트를 통해 시스템 품질을 검증하고, Go-Live 후 하이퍼케어 운영, 장애 대응 체계, 모니터링 정책을 수립하여 운영 리스크를 최소화합니다.

본 절에서는 외부 연동 포함 E2E 통합 테스트, 발주처 참여 UAT, 성능 기준 충족 검증, 안정화 기간 운영, 장애 복구 절차, 모니터링 항목 및 알람 정책 등 6개 요구사항을 제시합니다.

### TER-001
| 항목 | 내용 |
|:---|:---|
| 요구사항 분류 | 테스트·운영 |
| 요구사항 고유번호 | TER-001 |
| 요구사항 상세설명 | 외부 연동(Playauto/PG/택배/WEHAGO) 포함 E2E 시나리오(주문→결제→구독→CMS권한→송장→배송추적) 검증, Mock 기반 및 실 환경 회귀 테스트, 복구·재시도 동작 확인 |
| 산출정보 | 통합 테스트 계획서, 통합 테스트 결과서, 테스트 케이스 목록 |

### TER-002
| 항목 | 내용 |
|:---|:---|
| 요구사항 분류 | 테스트·운영 |
| 요구사항 고유번호 | TER-002 |
| 요구사항 상세설명 | 발주처(운영팀) 참여 UAT 시나리오(팀별 핵심 프로세스), 결함 등급별 조치 계획, 인수 기준(통과/보류) 정의 |
| 산출정보 | UAT 시나리오 및 결과서, 이슈·결함 리스트, UAT 승인서 |

### TER-003
| 항목 | 내용 |
|:---|:---|
| 요구사항 분류 | 테스트·운영 |
| 요구사항 고유번호 | TER-003 |
| 요구사항 상세설명 | 일반 화면 3초 이내, 고객조회 2초 이내, CTI 팝업 1초 이내(동시 20명 이상), 대량 발송·이관 부하 테스트(월 5만건 시나리오) 수행 및 기준 충족 검증 |
| 산출정보 | 성능 테스트 계획·스크립트, 성능 테스트 결과서, 병목 개선 권고서 |

### TER-004
| 항목 | 내용 |
|:---|:---|
| 요구사항 분류 | 테스트·운영 |
| 요구사항 고유번호 | TER-004 |
| 요구사항 상세설명 | Go-Live 후 1개월 이상 하이퍼케어 운영, 핫라인(전화/메신저) 및 일일 리포트 제공, 초기 2주 집중 모니터링 |
| 산출정보 | 하이퍼케어 운영계획서, 일일 리포트 템플릿, SLA 문서 |

### TER-005
| 항목 | 내용 |
|:---|:---|
| 요구사항 분류 | 테스트·운영 |
| 요구사항 고유번호 | TER-005 |
| 요구사항 상세설명 | 장애 분류·에스컬레이션 절차, 연락망 R&R, 데이터 롤백·서비스 페일오버 체크리스트, 정기 복구 연습 수행 |
| 산출정보 | 장애 대응 Runbook, 장애 로그·조치 기록 템플릿, 복구 연습 리포트 |

### TER-006
| 항목 | 내용 |
|:---|:---|
| 요구사항 분류 | 테스트·운영 |
| 요구사항 고유번호 | TER-006 |

| 산출정보 | 모니터링 항목·임계값 문서, 대시보드 스냅샷, 알람 룰셋 |
