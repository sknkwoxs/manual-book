# 제안요청서 (RFP) — 안

본 문서는 **「좋은생각 CS 시스템 웹 전환 및 데이터 통합 구축 사업」** 의 제안요청서(RFP) 초안입니다.

본 RFP는 좋은생각의 정보화 전략 계획(ISP) 결과를 토대로 작성되었으며, **사업 발주 시점에 발주처(좋은생각)가 행정 정보 및 확정 수치를 채워 최종본으로 공고**할 것을 전제로 합니다.

> **빈칸(`__________`) 표기 항목**은 ISP 단계만으로 확정할 수 없는 항목입니다. 사업 공고 전 발주처에서 확정 후 기재하시기 바랍니다.

---

## 본 RFP의 자기완결성

본 RFP는 별도 첨부 자료 없이 **이 문서(8장)만으로** 입찰 참여 의사결정·제안서 작성·평가를 수행할 수 있도록 작성되었습니다. 모든 기능 요구사항·비기능 요구사항·현행 시스템 정보는 본문 또는 부록(8.8)에 직접 기재되어 있습니다.

## 사용 안내

1. 본 8장 전체를 출력하여 **하나의 RFP 문서**로 사용할 수 있습니다.
2. 각 절(8.2 \~ 8.8)은 RFP 본문의 각 장(章)에 대응합니다.
3. 빈칸(`__________`) 항목은 발주처에서 확정 후 채워주시기 바랍니다.
4. 부록(8.8)에는 79건 기능 요구사항과 14건 비기능 요구사항의 **전체 명세**가 직접 기재되어 있어, 본 RFP 외 별도 문서 없이도 입찰 참여가 가능합니다.
