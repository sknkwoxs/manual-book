# 발주 지원 (RFP)

ISP 완료 후 구축 사업 발주를 위한 제안요청서(RFP) 작성 가이드입니다.

ISP 산출물이 RFP의 기반이 됩니다.

```

│                         ISP 산출물 → RFP 연계                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ISP 산출물                              RFP 반영 항목                      │
│   ─────────────                          ─────────────                       │
│   • 현행 시스템 분석서        ───────►   • 현황 및 문제점                    │
│   • AS-IS 아키텍처                       • 현행 시스템 현황                  │
│     (system-diagnosis.md)                  (§2.1)                           │
│                                                                             │
│   • 요구사항 정의서           ───────►   • 기능/비기능 요구사항              │
│   • 품질 속성 시나리오                   • 요구기능정의서                    │

│   • 자동화 프로세스 설계                 • 연동 요구사항                     │

### RFP 작성 전 확인 사항

| 확인 항목 | ISP 산출물 | 상태 |
|----------|-----------|:----:|
| 현행 시스템 분석 완료 | 시스템 정밀진단 (80%), AS-IS 아키텍처 (80%) | 🔲 |
| 요구사항 정의 완료 | 요구사항 정의서 (60%), 품질 속성 시나리오 (90%) | 🔲 |
| 목표 아키텍처 정의 완료 | TO-BE 아키텍처 (80%), 데이터 통합 (70%) | 🔲 |
| 업무 프로세스 설계 완료 | 자동화 프로세스 (85%), 업무 분석 (55%) | 🔲 |
| 데이터 이관 계획 완료 | 이관 계획 (75%) | 🔲 |
| 예산/일정 승인 완료 | 본 문서에서 산정 | ⬜ |

> 🔲 = ISP 분석 진행 중 (인터뷰 후 확정 필요), ⬜ = 미시작

## 사업 개요

### 사업명
좋은생각사람들 통합 웹 관리 시스템 구축

### 사업 배경

| 구분 | 현황 | 문제점 |
|------|------|--------|
| 관리 시스템 | XPlatform C/S (Tobesoft, 윈도우 전용) | 유지보수 불가 (개발사 폐업), 사내 PC에서만 접근 |
| 데이터 | On-Prem MSSQL (75t) + AWS MSSQL (63t + 13t CMS) | DB 이원화, 수동 Excel 이관, 실시간 연동 없음 |
| 외부 주문 | Playauto → 네이버/쿠팡 → 수동 입력 | 외부몰 주문 → C/S 수동 전사, 오류·지연 발생 |
| 네트워크 | MikroTik VPN (PPTP) | 취약 프로토콜, 외부/재택 근무 불가 |
| 외부 콜센터 | 더아이앤오 (4명) | C/S 접근 불가, 별도 시스템 사용, 상담 이력 단절 |

### 사업 목적
1. 로컬 설치형(C/S) 관리 시스템의 **웹 브라우저 기반 전환** (장소·OS 무관 접근)
2. On-Prem + AWS **분산 데이터베이스 통합** (151t → ~100t 단일 스키마)
3. 수동 Excel 이관 → **API 기반 자동 연동** (외부몰, PG, 배송, ERP)
4. **업무 프로세스 자동화** (월간지 발송, 지로 관리, 이연수익 계산 등)

### 사업 범위

```
┌─ 사업 범위 ────────────────────────────────────────────────────────────────┐

:::
