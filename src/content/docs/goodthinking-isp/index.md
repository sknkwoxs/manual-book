# 좋은생각 CS 시스템 웹 전환 및 데이터 통합 ISP

## 사업 개요

| 항목 | 내용 |
|------|------|
| **사업명** | 좋은생각 CS 시스템 개선 및 데이터 통합을 위한 정보화 전략 계획(ISP) 수립 |
| **기간** | 착수일로부터 8주 |
| **목적** | 로컬 설치형(C/S) 시스템의 기술적 한계 극복, 파편화된 고객 데이터 통합, **웹 기반 차세대 통합 시스템** 구축을 위한 상세 요건(RFP) 정의 |

---

## 핵심 전환 방향

| 구분 | 현황 (AS-IS) | 개선방향 (TO-BE) |
|:---|:---|:---|
| **아키텍처** | PC 설치형 프로그램 (C/S) 방식 | 100% 웹 기반 (Web-based) 시스템 전환 |
| **데이터** | 채널별 데이터 고립, Excel 수기 취합 | 고객/주문 데이터 통합 DB 일원화 |
| **프로세스** | 수작업 의존, 휴먼 에러 상존 | 시스템 주도의 표준화된 자동 처리 |

## 추진 일정 요약

| 단계 | 기간 | 주요 활동 |
|:---|:---:|:---|
| **1. 분석** | 1~3주 | 로컬 프로그램 로직 역분석, 데이터 단절 구간 파악 |
