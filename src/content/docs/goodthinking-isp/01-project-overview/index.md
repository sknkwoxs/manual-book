---

## 프로젝트 핵심 정보

| 항목 | 내용 |
|------|------|
| **사업명** | 좋은생각 CS 시스템 개선 및 데이터 통합을 위한 정보화 전략 계획(ISP) 수립 |
| **기간** | 2026년 3월 3일(화) \~ 5월 1일(금) (8주+α) |
| **목적** | 웹 기반 차세대 통합 시스템 구축을 위한 상세 요건(RFP) 정의 |

## 핵심 키워드

- **C/S → Web 전환**: 로컬 설치형에서 웹 기반 시스템으로
- **데이터 통합**: 파편화된 고객 데이터의 일원화
- **자동화**: 수작업 프로세스의 시스템화
