## 추진 배경

### 현행 시스템의 한계

1. **기술적 한계**
   - PC 설치형 프로그램(C/S) 방식으로 운영
   - 웹(CMS/쇼핑몰)과 기술적 연동(API) 불가
   - 특정 PC에서만 접근 가능한 제약

2. **데이터 관리의 문제**
   - 채널별(자사몰, 외부몰, 후원) 데이터 고립
   - 담당자의 Excel 수기 취합 및 업로드 필수
   - 데이터 정합성 유지의 어려움

3. **업무 프로세스의 비효율**
   - 데이터 단절로 인한 결제-권한 부여 지연
   - 수작업 의존으로 휴먼 에러 상존
   - 중복 업무 및 병목 현상 발생

## 사업 목적

### 1. 기술적 현대화
- 레거시 C/S 시스템을 웹 기반 시스템으로 전환
- 클라우드 환경에서의 안정적 운영 기반 마련

### 2. 데이터 통합
- 분산된 고객/주문 데이터를 단일 DB로 통합
- 실시간 데이터 동기화 체계 구축

### 3. 프로세스 자동화
- 수작업 업무의 시스템화
- 표준화된 업무 프로세스 정립
