# 이행 계획 (Implementation Plan)

ISP 3단계(7\~8주)에서 수행하는 이행 계획 수립 문서입니다.

## 계획 영역

### [마이그레이션 계획](./migration-plan)
로컬 DB 데이터를 웹 기반 신규 DB로 구조 변경 및 이관하는 전략 수립

- 데이터 이관 전략
- 검증 방안
- 롤백 계획

### [발주 지원 (RFP)](./rfp-preparation)
구축비용/일정 산출 및 제안요청서(RFP), 요구기능정의서(웹 표준 준수) 작성

- RFP 작성
- 요구기능정의서
- 평가 기준

### [비용 산정](./cost-estimation)
시스템 구축 비용 산출 (인력, 인프라, 라이선스, 유지보수)

## 핵심 산출물

| 산출물 | 설명 | 상태 |
|--------|------|:----:|
| 데이터 이관 계획서 | 마이그레이션 상세 계획 | 완료 ([마이그레이션 계획](./migration-plan)) |
| 구축 이행 계획서 | 구축 단계별 계획 | 완료 (본 문서 §구축 이행 로드맵 (안)) |
| 제안요청서 (RFP) | 입찰용 RFP 문서 | 완료 ([발주 지원 (RFP)](./rfp-preparation) — 목차/평가기준/체크리스트) |
| 요구기능정의서 | 상세 기능 명세 | 완료 (사이드바 **3. 기능요건 도출** 카테고리 — 기능 79건 상세 정의) |

## 구축 이행 로드맵 (안)

![구축 이행 로드맵 (안)](/diagrams/goodthinking-isp/05-implementation/index-L44.svg)

### 단계별 일정 (안)

| 단계 | 기간 | 주요 활동 |
|:---:|:---:|----------|
| 1. 발주/계약 | 1개월 | RFP 공고, 제안 평가, 계약 |
| 2. 착수 | 2주 | 킥오프, 상세 설계 |
| 3. 개발 | 3개월 | 시스템 개발, 연동 개발 |
| 4. 테스트 | 1개월 | 통합 테스트, UAT |
| 5. 이관 | 2주 | 데이터 이관, 전환 |
| 6. 안정화 | 1개월 | 병행 운영, 안정화 |
