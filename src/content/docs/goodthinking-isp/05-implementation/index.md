# 이행 계획 (Implementation Plan)

ISP 3단계(7\~8주+α)에서 수행하는 이행 계획 수립 문서입니다.

## 계획 영역

### [마이그레이션 계획](./migration-plan)
로컬 DB 데이터를 웹 기반 신규 DB로 구조 변경 및 이관하는 전략 수립

- 데이터 이관 전략
- 검증 방안
- 롤백 계획

### [발주 지원 (RFP)](./rfp-preparation)
구축비용/일정 산출 및 제안요청서(RFP), 요구기능정의서(웹 표준 준수) 작성

- RFP 작성
- 요구기능정의서
- 평가 기준
