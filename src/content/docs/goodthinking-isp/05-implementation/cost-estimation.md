# 비용 산정서

좋은생각 CS 시스템 웹 전환 및 데이터 통합 구축 사업의 비용 산정서입니다.

---

## 비용 산정 개요

### 산정 목적
- ISP 완료 후 구축 사업 예산 수립 근거 제공
- 발주 단계(RFP) 예산 범위 설정
- 운영 비용 사전 검토

### 산정 기준
- 기준일: 2026년 4월
- 환율: 1 USD = 1,400 KRW
- AWS 리전: ap-northeast-2 (서울)
- 인건비: 시장 평균 단가 기준

### 전제조건
- 소규모 B2B/B2C 시스템 (동시접속 10~30명 추정)
- AWS Lightsail + Cloudflare 기반 인프라 구성
- 기술 스택: Headless CMS + SSR 프론트엔드 + MariaDB (Lightsail DB) + Cloudflare Workers
- 개발 기간: 5개월 (분석 1개월 + 설계 1개월 + 개발 2개월 + 테스트·이관 0.5개월 + 안정화 0.5개월)
- 기능 요구사항: 79건
- 데이터 이관: 현행 MSSQL → MariaDB (Lightsail DB)

### 전제조건

1. **환율**: 1 USD = 1,400 KRW (2026년 4월 기준, 변동 시 재산정 필요)
2. **AWS 리전**: ap-northeast-2 (서울) — 리전 변경 시 비용 변동 가능
3. **예약 인스턴스**: Lightsail 일반 온디맨드 요금 기준 (1년 예약 시 30~40% 절감 가능)
4. **인건비**: SI 시장 평균 단가 기준 (벤더별 편차 있음)
5. **데이터 이관**: 현행 MSSQL → MariaDB (Lightsail DB) — 스키마 변환 포함
6. **외부 연동**: Excel 템플릿 기반 (API 연동 없음)

### 비용 변동 요인

| 요인 | 변동 가능성 | 대응 방안 |
|------|-----------|----------|
| 트래픽 증가 | 동시접속 10~30명 → 100명 이상 | Auto Scaling, 인스턴스 확장 |
| 데이터 증가 | 100GB → 500GB | Lightsail 스토리지 확장, R2 계층화 |

| 환율 변동 | USD 환율 ±10% | 쿠션 예산 10% 확보 |

### 제약 사항

1. **추정치임을 명시**
   - 본 산정서는 ISP 단계의 추정치이며, **실제 견적은 구축 사업자 제안 시 확정**됩니다.

3. **외부 연동 비용 제외**

4. **하자보수 기간**
