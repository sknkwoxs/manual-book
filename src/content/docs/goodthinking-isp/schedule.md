## 주차별 상세 일정

### 1단계: 분석 (1\~3주, 3/3 \~ 3/20)

#### 1주차 — 착수 및 현황 파악

**주간 목표**
- 업무분석가: 프로젝트 착수 완료, 정기구독팀 초기 면담으로 업무 전체상 파악
- IT컨설턴트: 분석 환경 구축 완료, DB 스키마 추출 착수
- 연구원: 킥오프 동석, 인터뷰 질문지 초안 작성 보조

| 역할 | To-Do |
|------|-------|
| **업무분석가** | 킥오프 미팅 참석 및 사업 범위 확인 |
| | 인터뷰 대상자 리스트업, 질문지 작성 |
| | 정기구독팀 리더 초기 인터뷰 (전체 업무 흐름 파악) |
| | 주요 화면 스크린샷 수집, 기능 매핑 시작 |
| | 인터뷰 결과 정리, 2주차 인터뷰 일정 확정 |
| **IT컨설턴트** | 킥오프 미팅 참석 및 기술 환경 확인 |
| | 분석 환경 구축, DB 접근 권한 요청 |
| | 현행 CS 프로그램 설치 및 구동 환경 파악 |
| | DB 접속 환경 구축, 스키마 추출 시작 |
| | 테이블 목록 작성, 레코드 수 확인 |

- IT컨설턴트: DB 구조 분석 70% 완료, 데이터 흐름 추정
- 연구원: 인터뷰 동석·기록, 화면 시연 청취 데이터 정리

| 역할 | To-Do |
|------|-------|

| | 화면 시연 인터뷰 — CS 상담/구독 관리 업무 청취 |
| | 운영팀/마케팅팀 인터뷰 — 데이터 활용 현황 |

| | Stored Procedure 목록 추출 및 로직 분석 |
| | 데이터 흐름 추정 (주문→고객→구독→CMS) |
| | 외부 연동 분석 (Playauto, CMS, 외부몰) |

**산출물**: 인터뷰 기록, 업무 관찰 기록, 현행 업무흐름도(초안), AS-IS ERD(초안)
