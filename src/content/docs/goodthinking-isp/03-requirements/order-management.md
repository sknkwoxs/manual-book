주문 관리는 자사 홈페이지뿐만 아니라 네이버, 쿠팡 등 외부 쇼핑몰에서 발생하는 모든 주문 데이터를 하나로 통합하여 처리하는 모듈입니다. 현재 플레이오토를 통해 수동으로 엑셀을 내려받아 업로드하던 과정을 데이터 템플릿 기능으로 최소화하여 업무 지연을 방지하고 주문 처리 속도를 향상합니다. 채널별로 흩어진 주문 상태와 결제 현황을 통합 관리하여 고객에게 정확한 배송 정보를 제공하고 운영의 투명성을 확보합니다.

### OM-01: 다채널 주문 자동 수집

| 항목 | 내용 |
|------|------|
| **번호** | OM-01 |
| **제목** | 다채널 주문 자동 수집 |
| **목표** | 다양한 판매 채널의 주문 데이터를 데이터 템플릿 기능을 통해 효율적으로 수집하고 통합하는 기능을 구축합니다. |
| **배경** | 매일 반복되던 엑셀 다운로드와 수동 업로드 과정을 최소화하여 데이터 입력 시 발생할 수 있는 휴먼 에러를 줄입니다. 다양한 채널별 엑셀 형식에 대응하는 템플릿을 생성·수정할 수 있어 주문 확인 시간을 단축하고 즉각적인 출고 준비가 가능한 환경을 조성하여 물류 효율성을 높입니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | 미지원. Playauto에서 네이버/쿠팡 주문 수집 후 수동 Excel 다운로드 → C/S 입력 |

### OM-02: 주문 상태 실시간 조회

| 항목 | 내용 |
|------|------|
| **번호** | OM-02 |
| **제목** | 주문 상태 실시간 조회 |
| **목표** | 주문 접수부터 결제, 상품 준비, 배송 중, 완료에 이르는 전 과정을 통합 화면에서 실시간으로 추적할 수 있는 조회 기능을 제공합니다. |
| **배경** | 기존에 채널별로 별도의 어드민 페이지를 확인해야 했던 번거로움을 해결하여 상담원이 한곳에서 모든 정보를 파악할 수 있게 합니다. 일관된 주문 상태 관리를 통해 고객 문의에 더욱 정확하고 빠르게 응대할 수 있는 토대를 마련합니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | 부분 지원. C/S에서 PT_SendHistory로 발송 이력 조회 가능. 홈페이지 주문(PTM_Orders)은 별도 Admin |

### OM-03: 결제 확인 효율화

| 항목 | 내용 |
|------|------|
| **번호** | OM-03 |
| **제목** | 결제 확인 효율화 |
| **목표** | 신용카드 결제는 PG 연동을 유지하고, 가상계좌나 지로 입금 내역은 데이터 업로드 및 반자동 매칭을 통해 효율적으로 확인하고 주문 상태를 업데이트합니다. |
| **배경** | 수동 대조 업무를 최소화하여 결제 확인 누락을 방지하고 빠른 발송 처리를 지원합니다. 특히 수기 결제로 처리되던 문화누리카드 등의 특수 결제 수단도 시스템 내에서 관리할 수 있는 방안을 마련하여 결제 프로세스의 완전성을 높입니다. (**인터뷰 N2**) |
| **우선순위** | 필수 |
| **현행지원 여부** | 부분 지원. 나이스페이 PG 연동(PT_NicepayCreditcardIncome, PT_NicepayVirtualAccount) 존재하나, 가상계좌/지로는 수동 확인. 문화누리카드는 물리 단말기 수기 결제 — 온라인 결제 연동 검토 필요 |

### OM-04: 배송 연동 (송장 등록 효율화)

| 항목 | 내용 |
|------|------|
| **번호** | OM-04 |
| **제목** | 배송 연동 (송장 등록 효율화) |
| **목표** | 택배사에서 발급된 송장 데이터를 엑셀 업로드를 통해 효율적으로 등록하고 주문 정보와 매핑하는 환경을 구축합니다. |
| **배경** | 수동으로 송장 번호를 복사하여 입력하던 절차를 엑셀 일괄 업로드로 개선하여 오기입 문제를 해결합니다. 송장 번호 등록과 동시에 주문 상태를 업데이트하여 고객이 웹사이트에서 배송 상태를 확인할 수 있게 합니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | 부분 지원. sp_PT_SendBookData로 발송 처리. CJ대한통운 연동은 홈페이지 Admin에서만 가능, C/S 미연동 |

### OM-05: 환불/취소 처리

| 항목 | 내용 |
|------|------|
| **번호** | OM-05 |
| **제목** | 환불/취소 처리 |
| **목표** | 고객의 주문 취소나 환불 요청을 접수하고, 실제 결제 취소 및 재고 환원까지 연계되는 통합 워크플로우를 제공합니다. |
| **배경** | 온/오프라인 채널 구분 없이 동일한 정책과 인터페이스로 환불 프로세스를 처리하여 관리의 일관성을 유지합니다. 정확한 환불 로직을 통해 정산 오류를 방지하고 신속한 환불 처리를 지원하여 서비스에 대한 고객 신뢰를 구축합니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | C/S 지원 (PT_SalesCancel, PT_RefundRequest, sp_PT_FinanceRefund). 홈페이지 환불은 별도 처리 |
