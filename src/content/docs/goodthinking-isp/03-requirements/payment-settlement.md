결제 및 정산 관리는 서비스 운영의 핵심인 수익 흐름을 투명하게 관리하는 영역입니다. 나이스페이(Nicepay)를 통한 온라인 결제부터 지로, 무통장 입금 등 다양한 결제 수단을 통합 관리하며, 특히 더존 위하고(WEHAGO) ERP와의 연동을 통해 기존의 방대한 엑셀 수작업을 자동화하는 데 중점을 둡니다. 잡지 구독 모델 특유의 이연수익 계산과 인세 관리 기능을 포함하여 경영지원팀의 업무 효율성을 극대화합니다.

### FN-01: 나이스페이 결제 관리 (정산 Excel 기반)

| 항목 | 내용 |
|------|------|
| **번호** | FN-01 |
| **제목** | 나이스페이 결제 관리 (정산 Excel 기반) |
| **목표** | 나이스페이 Admin에서 다운로드한 정산 Excel을 시스템에 업로드하여 자동 파싱/매칭하고, 결제 데이터를 통합 관리합니다. 나이스페이 API 직접 연동은 현행 업무에서 사용하지 않으므로 Excel 기반으로 처리합니다. |
| **배경** | 기존의 수동 입금 확인 절차를 Excel 자동 파싱으로 간소화하여 결제 완료와 동시에 구독권 부여가 이루어지도록 프로세스를 개선하여 고객의 대기 시간을 줄이고 결제 데이터의 누락 없는 정확한 관리가 가능해집니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | 부분 지원. PT_NicepayCreditcardIncome(카드), PT_NicepayVirtualAccount(가상계좌). 가상계좌 입금 확인은 수동 |

| **현행지원 여부** | 미지원. 더존 위하고(WEHAGO) ERP에 수동 전표 입력. API 연동 없음. CS 시스템과 위하고 투트랙 관리로 엑셀 재가공 수작업 발생 (경영지원팀 인터뷰 확인) |
