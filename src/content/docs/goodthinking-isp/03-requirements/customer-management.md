고객 관리는 파편화되어 관리되던 C/S 데이터, 홈페이지 회원 정보 및 외부 쇼핑몰의 구매 이력을 하나의 뷰로 통합하는 핵심 모듈입니다. 현재 각 채널별로 고객 정보가 분산되어 있어 정확한 고객 프로필 파악이 어렵고 상담 효율이 떨어지는 문제를 해결합니다. 웹 전환을 통해 고객의 전체 구매 여정을 한눈에 파악하고 더욱 정교한 고객 지원 및 상담 환경을 구축하는 것을 목표로 합니다.

### FR-CM-001: 고객 정보 통합 조회

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-001 |
| **제목** | 고객 정보 통합 조회 |
| **목표** | 기존 C/S 시스템 내의 고객 정보와 홈페이지 가입 회원의 정보를 실시간으로 통합하여 한 화면에서 조회할 수 있는 환경을 구축합니다. |
| **배경** | 분산된 고객 DB를 연동하여 중복 데이터 발생을 방지하고 통합된 고객 마스터를 통해 상담의 정확성과 속도를 높입니다. C/S만 지원하며 웹 홈페이지 회원(PTM_Members)과는 미연동 상태로 통합 조회가 불가능합니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | C/S만 지원 (PT_Customer 48 cols). 웹 홈페이지 회원(PTM_Members)과 미연동, 통합 조회 불가 |

### FR-CM-002: 구독 이력 조회

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-002 |
| **제목** | 구독 이력 조회 |
| **목표** | 고객이 과거에 신청했거나 현재 유지 중인 모든 정기구독 내역을 통합하여 보여줍니다. |
| **배경** | 오프라인과 웹 홈페이지 신청 정보를 합산하여 구독 주기를 정확히 파악하고 만료 전 갱신 안내나 상담 시 근거 자료로 활용합니다. 현재 C/S와 웹 정기구독(PTM_Regular_Orders) 데이터가 별도로 관리되고 있습니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | C/S 지원 (PT_Subscribe + PT_Receiver). 웹 정기구독(PTM_Regular_Orders)과 별도 관리 |

### FR-CM-003: 채널별 구매 이력 통합

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-003 |
| **제목** | 채널별 구매 이력 통합 |
| **목표** | 자체 채널 및 네이버, 쿠팡 등 외부 쇼핑몰을 통한 구매 내역을 모두 취합하여 고객별 구매 히스토리를 제공합니다. |
| **배경** | 엑셀을 이용한 수작업 취합 과정을 제거하고 시스템 내에서 자동으로 거래 데이터를 동기화하여 VIP 관리 및 타겟 마케팅의 정합성을 확보합니다. 현재 C/S, 홈페이지, 외부몰(Playauto) 데이터가 분리되어 수동 Excel 취합이 필요합니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | 미지원. C/S(PT_Finance) ↔ 홈페이지(PTM_Orders) ↔ 외부몰(Playauto) 각각 분리, 수동 Excel 취합 |

### FR-CM-004: 고객 등급 관리

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-004 |
| **제목** | 고객 등급 관리 |
| **목표** | 구매 횟수, 총 매출액, 구독 기간 등을 기준으로 고객의 등급을 분류하고 관리할 수 있는 체계를 도입합니다. |
| **배경** | 단순 그룹 관리를 넘어 등급별 차별화된 혜택이나 상담 응대를 지원하고 우수 고객 식별을 위한 기반 데이터를 생성합니다. 현재 PT_Customer에 등급 필드가 없으며 PT_Group으로만 관리 중입니다. |
| **우선순위** | 선택 |
| **현행지원 여부** | 미지원. PT_Customer에 등급 필드 없음, PT_Group으로 그룹 관리만 존재 |

### FR-CM-005: 고객 메모/태그 기능

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-005 |
| **제목** | 고객 메모/태그 기능 |
| **목표** | 고객의 특이사항을 기록할 수 있는 메모 기능과 검색 용이성을 높여주는 태그 시스템을 구축합니다. |
| **배경** | 정형화되지 않은 세세한 요구사항을 기록·공유하여 상담원 변경 시에도 업무 연속성을 보장하고 개인화된 고객 응대를 제공합니다. 현재 PT_Councel_History에 메모 기록은 가능하나 태그 기능은 없습니다. |
| **우선순위** | 선택 |
| **현행지원 여부** | 부분 지원. PT_Councel_History에 상담 메모 기록 가능, 태그 기능 없음 |

### ✅ FR-CM-006: 회원 통폐합/중복 식별

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-006 |
| **제목** | 회원 통폐합/중복 식별 |
| **목표** | 동일 인물이 여러 채널을 통해 가입하거나 구매하여 중복 생성된 회원 정보를 식별하고 하나로 병합합니다. |
| **배경** | 전화번호와 이메일을 기준으로 중복을 자동 감지하여 불필요한 리소스 낭비를 차단하고 데이터 무결성을 확보합니다. 동일인이 여러 회원번호를 보유하거나 외부몰 구매자와 자사 계정이 미연동된 문제를 해결해야 합니다 (정기구독팀 N10, R6 + 콜센터 인터뷰). |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. 동일인이 여러 회원번호 보유, 외부몰 구매자↔자사 계정 미연동. 전화번호/이메일 기반 중복 감지 + 계정 병합 필요 (**정기구독팀 N10, R6 + 콜센터 인터뷰 교차 확인**) |

### ✅ FR-CM-007: 메인 키 중심 통합 조회 (최근 입력 키값 기준)

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-007 |
| **제목** | 메인 키 중심 통합 조회 (최근 입력 키값 기준) |
| **목표** | 상담 빈도가 높거나 최근에 처리한 고객을 우선 노출하고 주요 상태를 직관적으로 확인하는 검색 환경을 개선합니다. |
| **배경** | 유연한 주소 검색과 메뉴 통합을 통해 상담원이 정보를 찾는 시간을 단축하고 상담 피로도를 낮춥니다. 최근 회원번호 정렬, 구독 중 시각적 표시, 메뉴 통합 및 유연한 주소 검색 기능이 필요합니다 (콜센터 인터뷰 R1). |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. 최근 사용된 회원번호 상단 정렬, 구독 중 회원정보 시각적 표시, 정기구독 접수·도서 재발송 메뉴 통합, 유연한 주소 검색(띄어쓰기·명칭 약어 무관) (**콜센터 인터뷰 R1**) |

### ✅ FR-CM-008: 거래처 관리 기능 (목록 관리 + 코드 통합 + 필터링)

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-008 |
| **제목** | 거래처 관리 기능 (목록 관리 + 코드 통합 + 필터링) |
| **목표** | 기관이나 서점 등 B2B 거래처 목록을 체계적으로 관리하고 외부 ERP 위하고(WEHAGO)와의 코드 매핑 기능을 강화합니다. |
| **배경** | 미등록 거래처로 인한 영업 병목을 해소하고 코드 정합성을 유지하며 품절/절판 필터링으로 현장 활용도를 높입니다. 대부분의 B2B 거래처가 미등록 상태이며 위하고 코드와 CS 코드 매핑이 필요합니다 (영업추진팀 인터뷰 R5, 병목 ㉑). |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. CS 시스템 내 거래처 목록 등록·정리 + 위하고 거래처 코드와 CS 시스템 코드 매핑·정합성 확보 + 품절/절판 거래처 검색 필터링(체크박스) 기능 필요. 대부분의 B2B 거래처가 CS 시스템에 미등록 상태 (**영업추진팀 인터뷰 R5**, 병목 ㉑) |

### 🟢 FR-CM-009: 회원 주소변경 내역 조회

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-009 |
| **제목** | 회원 주소변경 내역 조회 |
| **목표** | 홈페이지 등에서 고객이 직접 수정한 주소 내역을 월 단위로 추출하여 확인하며 도서 오발송을 방지합니다. |
| **배경** | 정기구독팀이 월간 발송 전 주소 정합성을 확인하기 위해 정기적으로 사용하는 검증 도구로, 현재 안정적으로 운영 중인 핵심 기능의 계승이 필요합니다. 현행 존치 대상이며 월 1회 정기적으로 사용 중입니다 (메뉴 인벤토리 구독접수 #6). |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원. **[현행 존치]** 웹에서 변경된 주소 내역을 월별 확인하는 기능으로, 발송 시 주소 검증 용도로 정기구독팀이 **월 1회** 정기적으로 사용 중. 현행 시스템에서 안정적으로 운영 중이며, 웹 전환 시 동등 기능 보장 필수 (메뉴 인벤토리 구독접수 #6) |

### 🟢 FR-CM-010: 장기구독자 명단 조회

| 항목 | 내용 |
|------|------|
| **번호** | FR-CM-010 |
| **제목** | 장기구독자 명단 조회 |
| **목표** | 장기간 구독을 유지 중인 충성 고객을 추출하여 연말 정산 및 사은품 증정 대상자를 선정합니다. |
| **배경** | 대량의 데이터를 기준으로 고객 등급과 유지 기간을 분석하는 중요한 업무 기준을 제공하며 연말 업무 집중 시기에 차질 없는 처리를 지원합니다. 현행 존치 대상이며 정기구독팀이 연 1~2회 필수적으로 사용 중입니다 (메뉴 인벤토리 관리자업무 #9). |

| **현행지원 여부** | C/S 지원. **[현행 존치]** 장기 구매신청자 기준 선정 및 연말 정산용 명단 조회 기능. 정기구독팀이 **연 1~2회** 사용 중인 저빈도 기능이나, 연말 업무 정리 시 필수 (메뉴 인벤토리 관리자업무 #9) |
