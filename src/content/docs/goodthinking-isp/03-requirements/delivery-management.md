배송 관리는 매월 발생하는 잡지 대량 발송 업무를 중심으로 DM 및 이벤트 선물 발송, 택배사 송장 연동, 그리고 미납이나 주소 불명으로 인한 반송 처리를 체계적으로 관리합니다. 기존 시스템의 안정적인 발송 로직을 계승하면서도 택배사 API 연동을 통해 수작업을 최소화하고 배송 상태 추적의 정확성을 높이는 데 집중합니다.

### DL-01: 월간지 대량 발송 (우편/택배)

| 항목 | 내용 |
|------|------|
| **번호** | DL-01 |
| **제목** | 월간지 대량 발송 (우편/택배) |
| **목표** | 매월 정기적으로 발생하는 수만 건의 잡지 발송 데이터를 생성하고 우편 또는 택배 포맷에 맞춰 분류하는 기능을 구축합니다. |
| **배경** | 대량의 데이터를 안정적으로 처리하여 발송 누락을 방지하고 물류 현장에서 즉시 사용할 수 있는 정확한 명단을 제공하는 것이 목적입니다. 시스템 전환 시 기존의 복잡한 발송 로직을 완벽하게 이관하여 매달 반복되는 핵심 비즈니스 사이클의 연속성을 보장합니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | C/S 지원 (`PT_RegularSend_Info`, `sp_PT_SendBookData`). 월 1회 대량 발송 데이터 생성 |

### DL-02: DM/기타 발송 관리

| 항목 | 내용 |
|------|------|
| **번호** | DL-02 |
| **제목** | DM/기타 발송 관리 |
| **목표** | 정기 잡지 외에 홍보물(DM), 이벤트 경품, 별도 구매 도서 등 다양한 비정형 발송 건을 등록하고 관리하는 기능을 제공합니다. |
| **배경** | 발송 목적에 따라 대상을 추출하고 이력을 별도로 관리함으로써 고객별 수령 현황을 정확히 파악할 수 있게 돕습니다. 마케팅 활동의 효과를 측정하고 고객 응대 시 정확한 배송 정보를 안내할 수 있는 기반을 마련합니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원 (`PT_DMSend_Info` 등). 선물/이벤트 발송 별도 처리 |

### DL-03: CJ대한통운 송장 연동 (효율화)

| 항목 | 내용 |
|------|------|
| **번호** | DL-03 |
| **제목** | CJ대한통운 송장 연동 (효율화) |
| **목표** | C/S 시스템에서 택배사 송장 데이터를 엑셀 업로드를 통해 효율적으로 처리하고 배송 정보를 관리하는 기능을 구축합니다. |
| **배경** | 주문 및 발송 정보를 엑셀 일괄 업로드로 처리하여 데이터 입력 오류를 최소화합니다. 수동 개별 입력 단계가 생략되어 물류 처리 속도가 향상되며 고객에게도 더 빠른 배송 정보 제공이 가능해집니다. |
| **우선순위** | 필수 |
| **현행지원 여부** | 부분 지원. 홈페이지 어드민에서만 CJ 연동, C/S는 수동 업로드 |

### DL-04: 반송/주소 변경 처리

| 항목 | 내용 |
|------|------|
| **번호** | DL-04 |
| **제목** | 반송/주소 변경 처리 |
| **목표** | 주소 불명이나 수취 거부로 돌아온 반송 건을 기록하고 고객의 최신 주소 정보를 즉시 업데이트하는 프로세스를 구현합니다. |
| **배경** | 반송 사유를 체계적으로 관리하여 반복적인 발송 실패를 방지하고 오배송으로 인한 비용 낭비를 줄이는 데 기여합니다. 주소 변경 이력을 통합 관리함으로써 향후 발송 시 정확도를 높이고 고객 서비스의 신뢰도를 확보할 수 있습니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원 (`PT_SendHistory` 반송 기록). 주소 변경 시 `PT_Receiver` 수동 수정 |

### DL-05: 송장 번호 자동 연동

| 항목 | 내용 |
|------|------|
| **번호** | DL-05 |
| **유형** | 신규 요건 (인터뷰 도출) |
| **제목** | 송장 번호 자동 연동 |
| **목표** | 택배사에서 발행된 송장 번호를 별도의 엑셀 가공 없이 시스템으로 즉시 가져와 주문 정보와 매칭하는 기능을 구축합니다. |
| **배경** | 정기구독팀 인터뷰를 통해 식별된 반복적인 엑셀 재가공 수작업을 자동화하여 업무 효율을 극대화하는 것을 목적으로 합니다. 실시간 송장 번호 업데이트를 통해 고객이 웹사이트에서 본인의 배송 상태를 즉각 확인하게 함으로써 상담 문의를 줄이는 효과를 기대할 수 있습니다. (**인터뷰 N8**) |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. 현재 택배사 송장 Excel → 포맷 재가공 → CS 시스템 업로드. 택배사 API 직접 연동으로 수동 가공 제거 필요 |

### DL-06: 신규/재발송 작업 처리 및 발송 종류·수량 확인

| 항목 | 내용 |
|------|------|
| **번호** | DL-06 |
| **유형** | 현행 존치 |
| **제목** | 신규/재발송 작업 처리 및 발송 종류·수량 확인 |
| **목표** | 매일 발생하는 신규 구독자와 재발송 요청 건을 취합하여 실제 발송 작업을 생성하고 물류팀에 전달할 수량을 최종 확인하는 기능을 제공합니다. |
| **배경** | 현행 시스템에서 가장 안정적으로 운영되고 있는 핵심 로직 중 하나로, ERP 판매 데이터 입력까지 연계되는 중요한 접점입니다. 웹 기반 전환 시에도 이 업무 흐름의 안정성을 그대로 유지하여 물류 현장과의 협업에 차질이 없도록 보장합니다. 정기구독팀이 주 1~2회 사용 중인 안정 기능입니다. (메뉴 인벤토리 발송업무 #6, #10, #11) |
| **우선순위** | 필수 |
| **현행지원 여부** | C/S 지원 (`sp_PT_SendBookData`). **[현행 존치]** 일일발송용 신규·재발송 작업 처리, 발송 도서 종류·수량 확인, ERP 판매입력 자료 출력을 포함하는 발송업무 핵심 메뉴. |

| 항목 | 내용 |
|------|------|
| **번호** | DL-07 |
| **유형** | 현행 존치 |
| **제목** | 구독자라벨 출력(DM) |
| **목표** | 월간지 대량 발송 시 봉투에 부착할 고객 주소 라벨을 규격에 맞춰 출력하는 기능을 제공합니다. |
| **배경** | 현행 시스템에서 이미 검증된 출력 형식을 유지하여 별도의 장비 교체나 서식 수정 없이 업무를 지속할 수 있도록 합니다. 대량 출력 시의 안정성을 확보하여 발송 준비 시간을 단축하고 물류 작업의 편의성을 제공합니다. 정기구독팀이 월 1~2회 사용 중인 안정 기능입니다. (메뉴 인벤토리 발송업무 #7) |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원. **[현행 존치]** 월간 정규발송용 간행물 라벨·봉투 출력 기능. |

| 항목 | 내용 |
|------|------|
| **번호** | DL-08 |

| **목표** | 분실이나 파손 등으로 인한 재발송 이력을 관리하고 반송된 건들을 통합적으로 처리하는 메뉴를 구축합니다. |
| **배경** | 기존에 분산되어 있던 반송 및 재발송 관리 기능을 회원 현황 화면으로 통합하여 상담원이 고객 상담 중에 즉시 이력을 확인하고 조치할 수 있도록 개선합니다. 재발송 사유 다중 선택 등 실제 업무 환경에서의 요구사항을 반영하여 편의성을 높입니다. 정기구독팀이 주 2회 사용 중인 적극 활용 기능입니다. (메뉴 인벤토리 관리자업무 #4, #21, #22) |
| **우선순위** | 필수 |
| **현행지원 여부** | C/S 지원. **[현행 존치/통합]** 간행물·선물 재발송 내역 조회(존치) + 반송관리·도서재발송관리(회원현황 화면에 통합). |
