구독 신청 시 제공되는 사은품과 각종 이벤트를 통해 발송되는 선물들의 전 과정을 체계적으로 관리하여 물류 비용을 최적화합니다.

### GF-01: 선물 재고 관리

| 항목 | 내용 |
|------|------|
| **번호** | GF-01 |
| **제목** | 선물 재고 관리 |
| **목표** | 선물의 입출고 및 현재고를 실시간으로 관리하고, 재고 부족 시 담당자 알림 및 시각화된 이력 조회 기능을 제공합니다. |
| **배경** | 기존 C/S 시스템의 Trigger 기반 자동 재고 차감 로직(PT_GiftStock, TG_PT_GiftStock)을 계승해야 합니다. 사은품 배송 지연 방지와 재고 흐름 파악을 위한 강화된 관리 체계가 필요합니다. |
| **우선순위** | 중간 |
| **현행지원 여부** | C/S 지원 (PT_GiftStock, TG_PT_GiftStock). Trigger로 재고 자동 차감 |

### GF-02: 선물 발송 처리

| 항목 | 내용 |
|------|------|
| **번호** | GF-02 |
| **제목** | 선물 발송 처리 |
| **목표** | 구독 신청 및 개별 요청에 따른 선물 발송을 처리하고, 택배사 송장 Excel 업로드를 통해 발송 현황 추적 기능을 구현합니다. |
| **배경** | 기존 PT_GiftSend 테이블을 통한 이력 관리 기능을 유지하면서 고객별 통합 조회가 가능하도록 개선해야 합니다. 중복 발송 방지와 정확한 CS 대응을 위한 데이터 통합이 요구됩니다. |
| **우선순위** | 중간 |
| **현행지원 여부** | C/S 지원 (PT_GiftSend). 선물 발송 이력 관리 |

### GF-03: 쿠폰 관리

| 항목 | 내용 |
|------|------|
| **번호** | GF-03 |
| **제목** | 쿠폰 관리 |
| **목표** | 이벤트 및 마케팅용 쿠폰의 생성, 발급, 사용 여부를 관리하며 프로모션 효과 분석을 위한 통계 데이터를 제공합니다. |
| **배경** | 기존의 안정적인 쿠폰 관리 저장 프로시저(sp_PT_CouponInsert 등)를 웹 인터페이스와 연결하여 관리자 편의성을 높여야 합니다. 유연한 정책 설정과 데이터 기반 마케팅 분석 환경 마련이 필요합니다. |
| **우선순위** | 중간 |
| **현행지원 여부** | C/S 지원 (PT_Coupon, sp_PT_CouponInsert, sp_PT_CouponUpdate). 쿠폰 발급/사용 |

### GF-04: 선물 발송현황 조회 및 선물 재발송 관리

| 항목 | 내용 |
|------|------|
| **번호** | GF-04 |
| **유형** | 현행 존치 |
| **제목** | 선물 발송현황 조회 및 선물 재발송 관리 |
| **목표** | 구독 증정품과 장기구독 선물의 발송 현황 조회 및 미발송 건 재발송 기능을 회원현황 화면으로 통합하여 제공합니다. |
| **배경** | 현행 시스템에서 주 2회 이상 빈번하게 사용되는 핵심 기능(PT_GiftSend 기반)으로, 기존에 분산되어 있던 메뉴들을 통합하여 업무 동선을 단축해야 합니다. 웹 전환 시 안정적인 운영 보장과 사용성 개선이 주요 목적입니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원 (PT_GiftSend). **[현행 존치/통합]** 구독 증정품·장기구독 선물 발송현황 조회(존치, 주 2회 사용) + 미발송 선물 재발송 관리(현재 회원현황에서 대체 사용 → 통합) |
