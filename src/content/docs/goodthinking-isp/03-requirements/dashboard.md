대시보드는 CS 운영 팀이 비즈니스 KPI, 업무 알림 및 보고서를 준실시간으로 파악할 수 있는 통합 뷰를 제공합니다. 현재 C/S 시스템에는 대시보드 기능이 전무하여 데이터 확인을 위해 개별 메뉴를 일일이 조회해야 하는 불편함이 큽니다. 웹 기반 시스템으로 전환하며 도입되는 대시보드는 준실시간 지표 공유(5분 주기 갱신)를 통해 업무 효율성을 극대화하고 의사결정 속도를 높이는 핵심 역할을 수행합니다.

### DB-01: 준실시간 KPI 대시보드 (오늘 매출, 신규 구독, 주문 현황 등)

| 항목 | 내용 |
|------|------|
| **번호** | DB-01 |
| **제목** | 준실시간 KPI 대시보드 (오늘 매출, 신규 구독, 주문 현황 등) |
| **목표** | 당일 매출, 신규 구독자 수, 주문 현황 등 핵심 운영 지표를 한눈에 볼 수 있는 시각화 화면을 구축합니다. 5분 주기로 데이터를 갱신하여 준실시간 모니터링을 지원합니다. |
| **배경** | 기존 시스템에서 여러 메뉴를 오가며 수동으로 확인하던 지표들을 준실시간으로 집계하여 보여줌으로써 운영 현황을 파악하고 변동에 대응할 수 있게 합니다. 현행 C/S에 대시보드 없음. |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. 현행 C/S에 대시보드 없음. 각 화면에서 개별 조회만 가능 |

### DB-02: 알림 현황 (결제 대기, 배송 지연, CS 미처리 등)

| 항목 | 내용 |
|------|------|
| **번호** | DB-02 |
| **제목** | 알림 현황 (결제 대기, 배송 지연, CS 미처리 등) |
| **목표** | 결제 대기 건, 배송 지연 발생, 미처리 CS 문의 등 즉각적인 조치가 필요한 업무를 알림 형태로 제공합니다. |
| **배경** | 시스템 로그 중심의 기존 모니터링을 넘어 담당자가 처리해야 할 실제 업무를 시각적으로 강조하여 업무 누락을 방지하고 서비스 품질을 안정적으로 유지합니다. PT_DataMonitoringLog로 시스템 모니터링만 가능하며 업무 알림은 없음. |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. PT_DataMonitoringLog로 시스템 모니터링만 가능, 업무 알림 없음 |

### DB-03: 보고서 연동 및 대시보드 (주간/월간 매출 보고서)

| 항목 | 내용 |
|------|------|
| **번호** | DB-03 |
| **유형** | 신규 요건 (인터뷰 도출) |
| **제목** | 보고서 연동 및 대시보드 (주간/월간 매출 보고서) |
| **목표** | 영업추진팀에서 작성하는 엑셀 기반 매출 보고서를 시스템에 업로드하면 자동으로 시각화 대시보드를 생성합니다. 일간/주간/월간 통계(구독·매출·CS 추이)를 포함합니다. |
| **배경** | 주간/월간 회의를 위한 보고서 작성 시간을 단축하고 위하고 ERP 표준 양식을 지원하여 기존 업무 흐름과의 연속성을 보장합니다. 전월 대비 증감 현황 등 엑셀 기반 통계를 시스템에 업로드하여 자동 대시보드화하는 연동 기능 필요 (영업추진팀 인터뷰 R3). 경영지원팀이 Excel로 수동 취합하던 통계 작업도 포함. |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. 주간/월간 회의 시 전월 대비 증감 현황, 채널별 상세 매출 등 엑셀 기반 통계 보고서를 CS 시스템에 업로드하여 자동 대시보드화하는 연동 기능 필요. 위하고 표준 양식 포함 (**영업추진팀 인터뷰 R3**) |

### DB-04: 단행본 재고 공유 대시보드

| 항목 | 내용 |
|------|------|
| **번호** | DB-04 |
| **유형** | 신규 요건 (인터뷰 도출) |
| **제목** | 단행본 재고 공유 대시보드 |
| **목표** | 외부 물류 시스템의 재고 데이터를 통합하여 전 직원이 실시간으로 단행본 재고 현황을 조회할 수 있는 대시보드를 제공합니다. |
| **배경** | 물류사에 개별적으로 문의하거나 별도 시스템에 접속해야 했던 번거로움을 제거하여 업무 속도를 개선하고 정확한 고객 상담을 지원합니다. 고려출판물류 시스템의 재고 데이터를 엑셀로 다운받아 업로드하여 공유하는 기능 필요 (영업추진팀 인터뷰 R4). |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. 고려출판물류 시스템의 재고 데이터를 엑셀로 다운받아 CS 시스템에 업로드하면 전 직원이 실시간 재고를 쉽게 공유할 수 있는 기능. 현재 재고 현황을 알려면 고려출판물류에 개별 문의 필요 (**영업추진팀 인터뷰 R4**) |

### DB-05: 일일실적관리보고서

| 항목 | 내용 |
|------|------|
| **번호** | DB-05 |
| **유형** | 현행 존치 |
| **제목** | 일일실적관리보고서 |
| **목표** | 일일 업무 실적 현황을 종합적으로 조회하며 정기구독팀의 매일 성과를 측정하고 관리하는 기준점을 제공합니다. |
| **배경** | 정기구독팀이 매일 사용하는 가장 중요한 관리 메뉴로, 현재 시스템에서 안정적으로 운영 중인 핵심 기능을 웹 전환 시에도 로직 누락 없이 그대로 보존해야 합니다. 현행 존치 대상 (메뉴 인벤토리 관리자업무 #17). |
| **우선순위** | 필수 |
| **현행지원 여부** | C/S 지원. **[현행 존치]** 일일 업무 실적 현황을 조회하는 핵심 보고서로, 정기구독팀이 **매일** 사용하는 가장 중요한 관리 메뉴. 현행 시스템에서 안정적으로 운영 중이며, 웹 전환 시 동등 기능 보장 필수 (메뉴 인벤토리 관리자업무 #17) |
