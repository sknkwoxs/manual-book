도서 상품의 라이프사이클을 관리하고, 외부 ERP 시스템 및 실제 물류 창고와의 재고 정합성을 확보하여 판매 안정성을 높입니다.

### BK-01: 도서 관리 (월간지/단행본/기타)

| 항목 | 내용 |
|------|------|
| **번호** | BK-01 |
| **제목** | 도서 관리 (월간지/단행본/기타) |
| **목표** | 월간지, 단행본 및 기타 상품의 기본 정보, 판매 상태, 가격 정보를 웹 환경에서 조회하고 수정할 수 있도록 합니다. |
| **배경** | 기존 C/S 시스템의 PT_Book 테이블 기능을 웹으로 전환합니다. 홈페이지 상품 정보(PTM_Products)와의 자동 정합성 확보는 1차 범위에서 제외하고 추후 검토합니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원 (PT_Book). 홈페이지 상품(PTM_Products 16t)은 별도 |

### BK-02: 번들/세트 관리

| 항목 | 내용 |
|------|------|
| **번호** | BK-02 |
| **제목** | 번들/세트 관리 |
| **목표** | 여러 권의 도서를 묶은 번들 및 세트 상품을 웹 환경에서 조회, 등록, 수정할 수 있도록 합니다. |
| **배경** | 기존 PT_Bundle의 구성 관리 기능을 웹으로 전환합니다. 개별 상품 조합에 따른 자동 재고 차감 로직은 1차 범위에서 제외하고 추후 검토합니다. |
| **우선순위** | 중간 |
| **현행지원 여부** | C/S 지원 (PT_Bundle). 번들 상품 구성 관리 |

### BK-03: 재고 데이터 연동 효율화 (WEHAGO/CS/창고)

| 항목 | 내용 |
|------|------|
| **번호** | BK-03 |
| **유형** | 신규 요건 (인터뷰 도출) |
| **제목** | 재고 데이터 연동 효율화 (WEHAGO/CS/창고) |
| **목표** | WEHAGO ERP, CS 시스템, 외부 물류 창고의 재고 데이터를 표준 템플릿을 통해 업로드/다운로드하고, 데이터 검증 기능으로 오류를 사전에 방지하여 재고 현황 업데이트를 손쉽게 합니다. |
| **배경** | 현재 각각 별도 관리되어 월말 수작업 대조가 발생하는 소모적인 업무 구조를 개선해야 합니다. 실시간 자동 연동은 1차 범위에서 제외하고, 템플릿 기반 데이터 교환 및 검증 기능을 우선 도입합니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. WEHAGO ERP·CS 시스템·실제 창고 재고가 각각 별도 관리, 월말 수작업 대조 |
