Inventory and book management handles magazine/book catalog, stock in/out tracking, and bundle product configuration. 
도서 상품의 라이프사이클을 관리하고, 외부 ERP 시스템 및 실제 물류 창고와의 재고 정합성을 확보하여 판매 안정성을 높입니다.

### FR-BK-001: 도서 관리 (월간지/단행본/기타)

| 항목 | 내용 |
|------|------|
| **번호** | FR-BK-001 |
| **제목** | 도서 관리 (월간지/단행본/기타) |
| **목표** | 월간지, 단행본 및 기타 상품의 기본 정보, 판매 상태, 가격 정보를 웹 환경에서 통합 관리하고 홈페이지 상품 정보와의 정합성을 확보합니다. |
| **배경** | 기존 C/S 시스템의 PT_Book 테이블과 분산된 상품 정보를 통합하여 데이터 정확성을 보장해야 합니다. 웹 전환 시 상품 마스터 기능을 강화하여 일관된 관리가 필요합니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원 (PT_Book). 홈페이지 상품(PTM_Products 16t)은 별도 |

### FR-BK-002: 재고 관리 (입출고)

| 항목 | 내용 |
|------|------|
| **번호** | FR-BK-002 |
| **제목** | 재고 관리 (입출고) |
| **목표** | 도서의 입출고 내역을 기록하고 현재고 현황을 파악하며, 실제 물류 흐름을 반영하는 실용적인 인터페이스를 제공합니다. |
| **배경** | 기존 PT_Stock 기반이나 근태/재고 관리 화면이 미사용되는 등 실효성이 낮아 개선이 시급합니다. 실사용 범위 인터뷰를 통해 프로세스를 간소화하고 실시간 재고 추적 기능을 강화해야 합니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | C/S 지원 (PT_Stock). 근태관리·재고관리 화면 미사용 확인됨 — 실사용 범위 인터뷰 필요 |

### FR-BK-003: 번들/세트 관리

| 항목 | 내용 |
|------|------|
| **번호** | FR-BK-003 |
| **제목** | 번들/세트 관리 |
| **목표** | 여러 권의 도서를 묶은 번들 및 세트 상품을 구성하고, 개별 상품 조합에 따른 정확한 재고 차감 로직을 구현합니다. |
| **배경** | 기존 PT_Bundle의 구성을 유지하면서 마케팅 전략에 따른 다양한 상품 조합을 유연하게 지원해야 합니다. 세트 상품 판매 시의 재고 정합성 확보가 요구됩니다. |
| **우선순위** | 중간 |
| **현행지원 여부** | C/S 지원 (PT_Bundle). 번들 상품 구성 관리 |

### ✅ FR-BK-004: 재고 실시간 연동 (WEHAGO/CS/창고)

| 항목 | 내용 |
|------|------|
| **번호** | FR-BK-004 |
| **제목** | 재고 실시간 연동 (WEHAGO/CS/창고) |
| **목표** | WEHAGO ERP, CS 시스템, 외부 물류 창고의 재고 데이터를 실시간으로 동기화하여 자동 대조 및 불일치 알림 기능을 구현합니다. |
| **배경** | 현재 각각 별도 관리되어 월말 수작업 대조가 발생하는 소모적인 업무 구조를 개선해야 합니다. 인터뷰에서 확인된 핵심 불편 사항으로 전사적인 재고 가시성 확보가 필수적입니다. |
| **우선순위** | 높음 |
| **현행지원 여부** | 미지원. WEHAGO ERP·CS 시스템·실제 창고 재고가 각각 별도 관리, 월말 수작업 대조 |

## 요약
- 도서 마스터 정보와 재고 관리 기능을 통합하여 데이터 일관성을 유지합니다.
- ERP 및 외부 물류 창고와의 실시간 데이터 연동을 통해 전사적 재고 정합성을 확보합니다.
- 복잡한 세트 상품 구성을 지원하여 비즈니스 유연성을 강화합니다.
