## 6. 산정 근거 및 가정

### 6.1 적용 표준 및 가이드

- **ISO/IEC 14143**: 기능점수 측정 국제 표준
- **IFPUG CPM 4.3.1**: 국제기능점수사용자그룹 측정 매뉴얼
- **KOSA SW사업 대가산정 가이드 (2025년판)**: 한국SW산업협회 발표
- **소프트웨어진흥법 시행령 제20조**: SW사업 대가 기준

### 6.2 보정계수 적용 근거

응용 SW 유형 보정계수 1.20은 본 시스템이 다음 유형의 혼합 특성을 가지기 때문입니다:

| 유형 | 가중치 | 비중 | 적용값 |
|---|---:|---:|---:|
| 거래처리 (주문·결제·상담) | 1.0 | 70% | 0.70 |
| 시스템 (인증·권한·로그) | 1.4 | 30% | 0.42 |
| **가중 평균 보정계수** | | | **1.12** |

> 보수적 산정을 위해 가중평균 1.12를 1.20으로 상향 적용하였습니다 (데이터 이관 복잡도 반영).

### 6.3 FP 단가 산정 근거

| 항목 | 값 |
|---|---:|
| KOSA 2025년판 표준 단가 | 553,114원 / FP |
| 본 견적 적용 단가 | 335,000원 / FP |
| 표준 단가 대비 | 60.6% |

### 6.4 가정 사항

1. **본 사업 기간 중 개발·스테이징 클라우드 환경 임대료**는 직접경비에 포함되며, 발주처 명의 AWS 계정으로 수행사가 대행 운영합니다.
2. **운영 환경 클라우드 인프라 사용료**는 본 견적과 별도이며, 발주처 명의 계정으로 직접 계약합니다.
3. **하자보수 기간 6개월** 무상 (본 사업 종료 후), 이후 별도 유지보수 계약.
4. **데이터 이관 공수**는 원천 DB 분석 후 ±20% 변동 가능. 변동 시 발주처와 별도 합의.
5. **사업 기간**: 계약 체결일로부터 5개월 (분석 1개월 + 설계 1개월 + 개발 2개월 + 테스트·이관 0.5개월 + 안정화 0.5개월).
6. **결제 조건**: 계약 시 30% / 설계 완료 30% / 개발 완료 20% / 검수 완료 20%.
