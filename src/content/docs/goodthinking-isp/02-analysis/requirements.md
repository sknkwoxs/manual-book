## 요구사항 우선순위 매트릭스

```
                  중요도
           높음         낮음
        ┌─────────┬─────────┐
  긴    │  Must   │  Nice   │
  급    │  Have   │  to     │
  도    │ (필수)  │  Have   │
        ├─────────┼─────────┤
  낮    │ Should  │  Won't  │
  음    │  Have   │  Have   │
        │ (권장)  │ (제외)  │
        └─────────┴─────────┘
```

### Must Have (필수)
- 다채널 주문 통합
- CMS 자동 연동
- 고객 데이터 통합
- 웹 기반 접근

### Should Have (권장)
- 대시보드
- 고급 검색
- 알림 기능

### Nice to Have (선택)
- 고객 등급 관리
- CS 통계/리포트
- 응대 템플릿
