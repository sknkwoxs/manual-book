# 요구사항 분석

웹 기반 전환 시 필요한 현업의 필수 기능 및 UI/UX 개선 요구사항 도출

---

## 요구사항 수집 방법

| 방법 | 대상 | 목적 |
|------|------|------|
| 인터뷰 | 실무자, 관리자 | 업무 요구사항 파악 |

## 기능 요구사항

:::note[현행 지원 분석 기준]
아래 "현행 지원" 항목은 DB 정의서 분석(C/S 75t, 홈페이지 63t, CMS 13t) 결과를 기반으로 작성되었습니다. 
실제 운영 현황은 인터뷰 및 현장 확인 후 보정이 필요합니다. (2026-03-03 기준)
:::

### 1. 고객 관리

| ID | 요구사항 | 우선순위 | 현행 지원 |
|----|----------|:--------:|----------|
| FR-CM-001 | 고객 정보 통합 조회 | 필수 | C/S만 지원 (PT_Customer 48 cols). 웹 홈페이지 회원(PTM_Members)과 미연동, 통합 조회 불가 |
| FR-CM-002 | 구독 이력 조회 | 필수 | C/S 지원 (PT_Subscribe + PT_Receiver). 웹 정기구독(PTM_Regular_Orders)과 별도 관리 |
| FR-CM-003 | 채널별 구매 이력 통합 | 필수 | 미지원. C/S(PT_Finance) ↔ 홈페이지(PTM_Orders) ↔ 외부몰(Playauto) 각각 분리, 수동 Excel 취합 |
| FR-CM-004 | 고객 등급 관리 | 선택 | 미지원. PT_Customer에 등급 필드 없음, PT_Group으로 그룹 관리만 존재 |
| FR-CM-005 | 고객 메모/태그 기능 | 선택 | 부분 지원. PT_Councel_History에 상담 메모 기록 가능, 태그 기능 없음 |

### 2. 주문 관리

| ID | 요구사항 | 우선순위 | 현행 지원 |
|----|----------|:--------:|----------|
| FR-OM-001 | 다채널 주문 자동 수집 | 필수 | 미지원. Playauto에서 네이버/쿠팡 주문 수집 후 수동 Excel 다운로드 → C/S 입력 |
| FR-OM-002 | 주문 상태 실시간 조회 | 필수 | 부분 지원. C/S에서 PT_SendHistory로 발송 이력 조회 가능. 홈페이지 주문(PTM_Orders)은 별도 Admin |
| FR-OM-003 | 결제 확인 자동화 | 필수 | 부분 지원. 나이스페이 PG 연동(PT_NicepayCreditcardIncome, PT_NicepayVirtualAccount) 존재하나, 가상계좌/지로는 수동 확인 |
| FR-OM-004 | 배송 연동 | 필수 | 부분 지원. sp_PT_SendBookData로 발송 처리. CJ대한통운 연동은 홈페이지 Admin에서만 가능, C/S 미연동 |
| FR-OM-005 | 환불/취소 처리 | 필수 | C/S 지원 (PT_SalesCancel, PT_RefundRequest, sp_PT_FinanceRefund). 홈페이지 환불은 별도 처리 |

### 3. CS 처리

| ID | 요구사항 | 우선순위 | 현행 지원 |
|----|----------|:--------:|----------|
| FR-CS-001 | 고객 문의 접수 | 필수 | C/S 지원 (PT_Councel_History). CTI(서울정보시스템) 연동으로 전화 인입 시 고객 팝업. 외부콜센터(더아이앤오)는 별도 |
| FR-CS-002 | 처리 이력 관리 | 필수 | C/S 지원 (PT_Councel_History). 상담 유형/내용/처리결과 기록 |
| FR-CS-003 | 담당자 배정 | 선택 | 미지원. 상담 건별 담당자 자동 배정 기능 없음, 수동 처리 |
| FR-CS-004 | 응대 템플릿 | 선택 | 미지원. PT_SMSText에 SMS 템플릿만 존재, 상담 응대 템플릿 기능 없음 |
| FR-CS-005 | CS 통계/리포트 | 선택 | 미지원. PT_DataMonitoringLog로 시스템 모니터링만 가능, CS 통계 리포트 기능 없음 |

### 4. CMS 연동

| ID | 요구사항 | 우선순위 | 현행 지원 |
|----|----------|:--------:|----------|
| FR-IN-001 | 결제 완료 시 자동 권한 부여 | 필수 | 미지원. C/S 결제 확인(PT_Finance) → CMS 열람 권한(ptcms_member) 수동 처리. API 연동 없음 |
| FR-IN-002 | 구독 만료 자동 처리 | 필수 | 부분 지원. sp_PT_SubscribeCancel로 구독 해지 처리하나, CMS 권한 자동 회수 미연동 |
| FR-IN-003 | 실시간 상태 동기화 | 필수 | 미지원. C/S MSSQL(On-Prem) ↔ CMS MSSQL(AWS) 간 API/실시간 동기화 없음 |

### 5. 관리/운영

| ID | 요구사항 | 우선순위 | 현행 지원 |
|----|----------|:--------:|----------|
| FR-AD-001 | 사용자 권한 관리 | 필수 | C/S 지원 (PT_Auth, PT_Menu, PT_MENU_authority, PT_Button_authority). 메뉴/버튼 단위 권한 관리 |
| FR-AD-002 | 활동 로그 조회 | 필수 | 부분 지원. PT_DataMonitoringLog, PT_LogLockKill로 시스템 로그 관리. 사용자 활동 로그는 제한적 |
| FR-AD-003 | 대시보드 | 선택 | 미지원. 현행 C/S에 대시보드 기능 없음. 현황은 각 화면에서 개별 조회 |
| FR-AD-004 | 데이터 내보내기 | 필수 | C/S 지원. XPlatform 기반 Excel 내보내기 가능. 단, 웹 시스템 데이터는 별도 Admin에서만 |

## 요구사항 우선순위 매트릭스

```
                  중요도
           높음         낮음
        ┌─────────┬─────────┐
  긴    │  Must   │  Nice   │
  급    │  Have   │  to     │
  도    │ (필수)  │  Have   │
        ├─────────┼─────────┤
  낮    │ Should  │  Won't  │
  음    │  Have   │  Have   │
        │ (권장)  │ (제외)  │
        └─────────┴─────────┘
```

### Must Have (필수)
- 다채널 주문 통합
- CMS 자동 연동
- 고객 데이터 통합
- 웹 기반 접근

### Should Have (권장)
- 대시보드
- 고급 검색
- 알림 기능

### Nice to Have (선택)
- 고객 등급 관리
- CS 통계/리포트
- 응대 템플릿
