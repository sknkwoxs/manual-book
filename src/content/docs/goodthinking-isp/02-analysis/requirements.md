# 요구사항 분석

웹 기반 전환 시 필요한 현업의 필수 기능 및 UI/UX 개선 요구사항 도출

## 요구사항 수집 방법

| 방법 | 대상 | 목적 | 상태 |
|------|------|------|:----:|
| 현행 분석 | DB 정의서 3건, 151t 전수 분석 | 필수 기능 이관 범위 확정 | ✅ 완료 |
| 업무 플로우 분석 | 업무플로우 PDF 4건, 수작업 27건 식별 | 자동화 대상 도출 | ✅ 완료 |
| 인터뷰 | 실무자 5명 + 외부개발자 1명 | 업무 요구사항, Pain Point 파악 | 🔄 진행중 (정기구독팀 ✅) |
| 벤치마킹 | 유사 구독관리 SaaS | 개선 아이디어 도출 | ⬜ 미수행 |

:::note[분석 기준]
아래 기능 요구사항은 DB 정의서 분석(C/S 75t, 홈페이지 63t, CMS 13t) + 업무 플로우 분석(4개 팀) + 인터뷰 결과를 기반으로 작성되었습니다.
- **현행 지원**: 현재 시스템에서 해당 기능이 어떻게 지원되는지 DB/로직 근거 기반 기술
- **우선순위**: DB 분석, 병목 분석, 인터뷰 결과 기반 배정. 미인터뷰 팀 관련 항목은 잠정 배정.
- 🔶 = 추정 (인터뷰 후 검증 필요)
- ✅ = 인터뷰 확인 완료

(2026-03-23 기준, 정기구독팀 인터뷰 반영)
:::
