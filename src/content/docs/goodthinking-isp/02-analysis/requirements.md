| 방법 | 대상 | 목적 | 상태 |
|------|------|------|:----:|
| 현행 분석 | DB 정의서 3건, 151t 전수 분석 | 필수 기능 이관 범위 확정 | ✅ 완료 |
| 업무 플로우 분석 | 업무플로우 PDF 4건, 수작업 49건 식별 | 자동화 대상 도출 | ✅ 완료 |

아래 기능 요구사항은 DB 정의서 분석(C/S 75t, 홈페이지 63t, CMS 13t) + 업무 플로우 분석(5개 팀) + 인터뷰 결과를 기반으로 작성되었습니다.
- **현행 지원**: 현재 시스템에서 해당 기능이 어떻게 지원되는지 DB/로직 근거 기반 기술
- **우선순위**: DB 분석, 병목 분석, 인터뷰 결과 기반 배정.
- 🔶 = 추정 (인터뷰 후 검증 필요)
- ✅ = 인터뷰 확인 완료

(2026-03-30 기준, 정기구독팀/편집팀/경영지원팀/콜센터 인터뷰 반영)
:::
