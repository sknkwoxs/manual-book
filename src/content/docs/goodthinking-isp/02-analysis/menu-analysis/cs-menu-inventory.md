# CS 시스템 메뉴 인벤토리

현행 CS 시스템(Tobesoft 기반)의 전체 메뉴를 대분류별로 정리하고, **4개 부서의 사용 현황을 교차 분석**하여 웹 전환 시 존치·통합·폐기 판정을 제시합니다.

## 판정 기준

| 판정 | 기호 | 기준 |
|------|:----:|------|
| 존치 | 🟢 | 1개 부서 이상에서 주 1회 이상 정기적으로 사용하는 메뉴 |
| 존치 (저빈도) | 🔵 | 사용하되 월 1~2회 이하로 빈도가 낮은 메뉴 — 존치하되 UI 통합 검토 |
| 통합 | 🟡 | 동일/유사 기능이 다른 메뉴에서 제공되어 하나로 합칠 수 있는 메뉴 |
| 폐기 후보 | 🔴 | 모든 부서에서 미사용이거나, 사업 종료 등으로 더 이상 필요 없는 메뉴 |
