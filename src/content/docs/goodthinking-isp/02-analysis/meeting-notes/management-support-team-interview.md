## 인터뷰 목적

다양한 채널(자사몰, 외부몰, 전화 등)에서 발생하는 매출 데이터를 하나로 합치고, 실제 입금액(PG사 정산금)과 대조하는 **수기 정산 과정을 분석**하며, CS 시스템의 데이터와 더존 위하고(ERP)에 다시 입력하는 **이중 작업의 규모를 파악**하여 최소한의 방식을 검토합니다.

1. **매출 관리** — CS 프로그램에서 매출 집계 및 수동 조회
2. **정산 처리** — Excel 수동 취합, 나이스페이 정산 확인
3. **세금계산서 발행** — 더존 위하고(WEHAGO) ERP 이중 입력
4. **기안/결재** — 더존 위하고 기안 작성 및 전자결재
5. **월결산** — 더존 위하고 월 마감 및 보고서 작성

:::note[업무 분석 연계]
본 인터뷰 안건은 [업무 분석](/goodthinking-isp/02-analysis/business-analysis/) 문서의 수작업 #9(매출 데이터 취합), #10(ERP 이중 입력), 병목 ③(매출 데이터 취합 → ERP 입력)과 연계된 검증 질문을 포함합니다.
:::

#### 1-1. 계좌 입금 확인 및 담당자 배분

**입금 확인 프로세스** (송윤경 팀장):
- 매일 아침 전일 기준 모든 은행 계좌의 입금 내역을 **'신한 인사이트 뱅크'**를 통해 통합 조회 후 엑셀로 다운로드
- 다운로드한 내역을 **구글 드라이브 시트에 공유**하여 각 매출 담당자(정기구독, 스마트스토어, 다량 특판 등)가 자기 건을 확인하도록 배분
- 이후 각 담당자들이 입금 내역을 위하고(WEHAGO)에 수금 등록하여 **미수 관리**를 진행
- 입금되는 종류가 정기구독 현금/카드, 다량 특판, 온라인 몰 정산 등 매우 다양하며 **입금 시점도 제각각**

- [x] 정기구독 매출 관리 방식 확인

**정기구독 매출 관리** (송윤경 팀장):
- CS 시스템에서 관리하며, 세무법인에 전달할 때는 별도의 엑셀 자료(선수수익 현황표 등)를 추출한 후 **서식을 정리하여 전달**
- 세무법인이 좋은생각으로부터 전달받은 월별 총 매출 엑셀파일을 위하고에 업로드하며, 정기구독 월별 총 매출을 확인할 수 있음

**정황규 매니저**:
- 가상계좌는 자동으로 입금처리되나 일반계좌는 해당 업무를 통해 **수작업으로 처리** 중
- 위하고에 정기구독 관련된 엑셀파일을 따로 업로드하지 않음

*(CS 시스템에서 수금관리 업무를 시연 — [사진 4] ~ [사진 5] 참고)*

**정기구독 외 매출 관리** (송윤경 팀장):
- 다량 특판 등은 **위하고 ERP에 직접 등록**을 하며, 담당자가 위하고 양식에 맞춰 엑셀을 업로드

**정황규 매니저**:
- 이전에 단행본 등의 정기구독 외 데이터를 CS 시스템에서 관리하였으나, 세무법인과의 업무 소통의 편의상 같은 ERP 시스템인 **위하고를 사용** 중

*(위하고 ERP 수금등록시 엑셀 업로드 화면을 보여줌 — [사진 6] 참고)*

#### 1-4. 위하고(WEHAGO) ERP 위주의 경영지원 업무

- [x] 경영지원팀의 시스템 사용 범위 확인

**시스템 사용 현황** (송윤경 팀장):
- 경영지원팀은 어드민, CMS, CS 시스템을 **거의 사용하지 않으며**, 대부분의 업무는 **위하고 ERP**로 진행
- 경영지원팀 김나현 매니저가 담당하는 업무 중 통장입금내역, 정기구독 관련 검증 자료, 선수수익 현황표 확인 등을 위해 **CS시스템에 접속하여 참고**하는 경우도 있음

:::caution[투트랙 매출 관리 이슈]

## 인터뷰 결과 요약

### 핵심 발견 사항

1. **투트랙 매출 관리**: 정기구독 매출은 CS 시스템, 그 외 매출(다량 특판 등)은 위하고 ERP로 나뉘어 관리되어 작업간 번거로움 발생
2. **이중 입력 및 수작업 재가공**: 동일한 데이터를 CS 시스템과 위하고 양쪽에 각각 입력하거나, 위하고 양식에 맞추기 위해 엑셀을 수작업으로 재가공하는 과정에서 실수 발생
3. **위하고 ERP 커스터마이징 불가**: 출판사 전용 프로그램이 아니어서 물류와 회계가 완전히 연동되지 않으며, 업체별 기능 커스터마이징 요청이 사실상 불가능
4. **매출 원가 관리 시스템 부재**: 개별 도서별 투입 비용과 매출을 한눈에 비교할 수 없어 수익성 판단(BEP 산출)이 어려움
5. **인세 관리 수작업**: 판매 건수 및 인세 계산을 수기로 작성하여 위하고에 업로드. 유상 판매분에 대한 세부 작업은 전부 수작업

### 신규 발견 수작업·병목
