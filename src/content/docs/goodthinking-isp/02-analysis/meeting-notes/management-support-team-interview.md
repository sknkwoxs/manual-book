## 인터뷰 목적

경영지원팀이 담당하는 **다섯 가지 핵심 업무 영역**을 파악하고, 각 업무의 현행 프로세스·수작업·병목을 검증합니다.

1. **매출 관리** — CS 프로그램에서 매출 집계 및 수동 조회
2. **정산 처리** — Excel 수동 취합, 나이스페이 정산 확인
3. **세금계산서 발행** — 더존 위하고(WEHAGO) ERP 이중 입력
4. **기안/결재** — 더존 위하고 기안 작성 및 전자결재
5. **월결산** — 더존 위하고 월 마감 및 보고서 작성

:::note[업무 분석 연계]
본 인터뷰 안건은 [업무 분석](/goodthinking-isp/02-analysis/business-analysis/) 문서의 수작업 #9(매출 데이터 취합), #10(ERP 이중 입력), 병목 ③(매출 데이터 취합 → ERP 입력)과 연계된 검증 질문을 포함합니다.
:::

## 안건 1. 매출 관리 (CS 프로그램 → Excel)

**목표**: CS 프로그램에서 매출 데이터를 집계·조회하는 과정을 파악하고, 수작업 부담 및 데이터 정합성 이슈를 검증

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| M1 | CS 프로그램에서 매출 데이터 조회 시 사용하는 메뉴 및 조회 조건 | 매출 조회 프로세스 파악 |
| M2 | 조회한 매출 데이터를 Excel로 다운로드하는 과정 및 소요 시간 | 수작업 #9 매출 데이터 취합 정량 |
| M3 | 매출 집계 시 채널별(자사몰/외부몰/후원/전화) 데이터를 어떻게 통합하는지 | 데이터 취합 방식 확인 |
| M4 | 매출 데이터의 일간/주간/월간 집계 주기 및 담당자 | 집계 주기 및 R&R 확인 |
| M5 | 가장 불편한 부분 / 시간 소요 구간 | 핵심 Pain Point 도출 |

### 확인 사항 (인터뷰 중 메모)

- [ ] CS 프로그램 로그인 → 매출 조회 → Excel 다운로드 흐름 화면 시연 요청
- [ ] 일일 매출 집계 소요 시간: ___분
- [ ] 매출 조회 시 필터 조건: 기간별 / 채널별 / 결제수단별 / 기타 ___
- [ ] 채널별 매출 데이터 통합 방식: Excel 복사·붙여넣기 / 피벗 / 수작업 합산 / 기타 ___
- [ ] 매출 집계 주기: 일간 / 주간 / 월간, 담당자: ___

## 안건 2. 정산 처리 (나이스페이 + Excel)

**목표**: 나이스페이 PG 정산 확인 및 Excel 수동 취합 과정을 파악하고, 정산 오류 및 대조 소요를 검증

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| P1 | 나이스페이 정산 내역 확인 과정 — 로그인 → 조회 → 다운로드 | 정산 확인 프로세스 |
| P2 | 나이스페이 정산 데이터와 CS 프로그램 매출 데이터 대조 방식 | 데이터 대조 수작업 |
| P3 | 정산 불일치 시 원인 파악 및 처리 프로세스 | 예외 처리 워크플로 |
| P4 | 월간 정산 처리 건수 및 총 소요 시간 | 정산 업무량 정량 |
| P5 | 지로 입금, 가상계좌 입금 정산 처리 방식 — CS와의 업무 분담 | 수작업 #6 관련 |

### 확인 사항 (인터뷰 중 메모)

- [ ] 나이스페이 관리자 로그인 → 정산 내역 조회 화면 시연 요청
- [ ] 정산 확인 주기: 일간 / 주간 / 월간
- [ ] 월간 정산 건수: ___건, 소요 시간: ___시간
- [ ] 정산 불일치 발생 빈도: 월 ___건
- [ ] 불일치 시 원인 Top 3: ___
- [ ] 지로 입금 정산: 경영지원팀 담당 / 정기구독팀 담당 / 공동 처리
- [ ] 가상계좌 입금 확인 담당: ___

## 안건 3. 세금계산서 및 ERP 이중 입력

**목표**: CS 프로그램 매출 데이터를 더존 위하고(WEHAGO)에 별도 입력하는 과정을 파악하고, 이중 입력 부담 및 데이터 불일치 리스크를 검증

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| E1 | 더존 위하고 입력 대상 데이터 — 매출/매입/비용 등 항목 구분 | ERP 입력 범위 |
| E2 | CS 프로그램 데이터 → 위하고 입력까지의 단계 및 건당 소요 시간 | 수작업 #10 정량 |
| E3 | 이중 입력으로 인한 데이터 불일치 사례 유무 | 오류 리스크 확인 |
| E4 | 세금계산서 발행 프로세스 — 요청 접수 → 발행 → 전달 | 세금계산서 워크플로 |
| E5 | 현금영수증 발행 처리 — 자동 vs 수동 | 현금영수증 자동화 수준 |

### 확인 사항 (인터뷰 중 메모)

- [ ] 더존 위하고 로그인 → 매출 전표 입력 화면 시연 요청
- [ ] ERP 입력 건당 소요 시간: ___분
- [ ] 일일 ERP 입력 건수: ___건
- [ ] 이중 입력 불일치 발생 빈도: 월 ___건
- [ ] 불일치 발견 시점: 입력 직후 / 월말 정산 시 / 외부 감사 시
- [ ] 세금계산서 발행 요청 경로: 이메일 / 전화 / 시스템 요청
- [ ] 월간 세금계산서 발행 건수: ___건
- [ ] 현금영수증 자동 발행: 예 / 아니오, 미발행 수동 처리: 월 ___건
