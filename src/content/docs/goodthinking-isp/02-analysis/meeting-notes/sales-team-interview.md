## 인터뷰 목적

영업추진팀의 실제 업무 범위와 타 팀과의 업무 협업 현황을 확인하고, 고유 프로세스의 애로사항을 청취합니다.

1. **업무 개요** — 하루 업무 흐름, 고유 주문 접수 경로, 정기구독팀과의 업무 분담 실태 확인
2. **신간 영업 준비 및 총판·서점 관리** — 편집팀 협업부터 총판 공급·서점 매대 확보까지의 유통 프로세스 파악
3. **다량 납품 및 특판 영업** — 도서관·기관·기업 대상 B2B 영업 흐름과 비도서 채널 특판 프로세스 확인
4. **반품·재고 관리** — 위탁 판매에 따른 반품 처리, 재고 현황 파악, 정기구독팀과의 재고 공유 구조 확인
5. **출고·배송·정산 및 영업 실적 관리** — 출고 지시~배송~정산·수금, 경영지원팀과의 데이터 전달·확인 프로세스, 영업 실적 분석 도구 파악
6. **CS 시스템 메뉴 사용 현황** — 영업추진팀 소관 CS 시스템 메뉴(17개)의 실제 사용 여부·빈도 확인, 웹 전환 시 존치·폐기 판단 근거 확보

:::note[업무 분석 연계]
본 인터뷰 안건은 [업무 분석](/goodthinking-isp/02-analysis/business-analysis/) 문서의 영업추진팀 7단계 워크플로 **추정**과 연계된 검증 질문을 포함합니다. 정기구독팀 인터뷰(2026-03-17)에서 Playauto 주문 수집~CS 등록까지의 프로세스를 정기구독팀이 전담하고 있음이 확인되었으므로, 업무 분석의 전제를 검증하는 것이 우선 과제입니다. 또한, 영업팀 업무플로우 문서(총판·다량·특판·오프라인 서점)를 참고하여, 출판 유통 영업 관점의 질문을 보강하였습니다. 상세 질문지는 [인터뷰 질문지 — 유형 B](/goodthinking-isp/02-analysis/interview/#유형-b-영업추진팀--이성수관리-권지은실무)를 참조하세요.
:::

## 안건 1. 업무 개요

**목표**: 영업추진팀의 하루 업무 흐름과 고유 주문 접수 경로를 파악하고, 정기구독팀과의 업무 분담 현황을 확인

:::note[정기구독팀 인터뷰 교차 검증]
정기구독팀 인터뷰(2026-03-17)에서 Playauto를 통한 외부몰 주문 수집~CS 시스템 등록은 **정기구독팀(정황규 매니저)이 전담**하고 있음이 확인되었습니다. 따라서 영업추진팀은 Playauto 파이프라인과 별도의 고유 주문 접수 경로(총판 발주, 서점 주문, 기관·기업 직접 주문 등)를 운영하는 것으로 전제하고, 해당 경로의 구체적인 흐름을 파악합니다.
:::

- [ ] 총판(한국출판협동조합, 북센 등)으로부터 **발주를 접수하는 방식** — 시스템, 전화, 이메일, FAX 중 어떤 경로인지
- [ ] 오프라인 서점(교보문고, 영풍문고 등)의 **주문이 들어오는 경로** — 총판 경유인지, 서점 직접 주문인지
- [ ] 도서관·기관·기업 등 **B2B 주문 접수 방식** — 입찰/계약 후 발주인지, 직접 연락인지
- [ ] 각 경로의 **일/주 평균 주문 건수** 체감량

##### 추가 확인 (시간 여유 시)

- [ ] **단행본 주문 전반**(온라인/오프라인 포함)이 모두 영업추진팀에서 처리되는지 — 채널에 따라 담당 팀이 달라지는지

#### 1-3. 정기구독팀과의 업무 경계

- [ ] 정기구독팀(정황규, 어은진)과의 **일상적인 협업 사항** — 데이터 전달, 재고 공유, CS 이관 등
- [ ] 외부몰(네이버 스마트스토어, 쿠팡 등) 관련 업무에서 **영업추진팀이 담당하는 영역** — 정기구독팀과 각각 어떤 부분을 중점적으로 처리하는지
- [ ] 두 팀 간 업무에서 **모호하거나 개선이 필요한 부분**이 있는지

## 안건 2. 신간 영업 준비 및 총판·서점 관리

**목표**: 신간 출간 전 영업 준비부터 총판 공급, 오프라인 서점 영업까지의 유통 프로세스를 파악하고, 편집팀·경영지원팀과의 협업 구간 및 시스템 사용 현황을 확인

:::note[업무플로우 참고]
영업팀 업무플로우 문서의 1~3단계(신간 영업 준비 → 총판 영업 → 오프라인 서점 영업)와 연계됩니다.
:::

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| B3 | 신간 출간 전 영업 준비 과정 — 편집팀 협업, 총판·서점 사전 영업 흐름 | 1단계 프로세스 검증 |
| B4 | 총판 공급 관리 — 업체 현황, 공급률, 배본, 계약서 관리 | 2단계 프로세스 검증 |

### 상세 질문

#### 2-1. 신간 영업 준비 (1단계)

- [ ] 편집팀으로부터 **신간 정보를 수령하는 시점과 방식** — 출간 몇 주 전인지, 어떤 형태로 전달받는지
- [ ] 신간별 **영업 전략 수립 과정** — 목표 부수, 주력 채널 등을 어떻게 결정하는지
- [ ] 총판·서점에 **사전 주문 협의 및 견본 도서 발송** 시 시스템을 사용하는지, 전화/이메일 기반인지
- [ ] 신간 영업 준비 과정에서 **가장 시간이 많이 걸리거나 불편한 부분**은 무엇인지

##### 추가 확인 (시간 여유 시)

- [ ] 단행본 제작 완료 후 **입고 통보 경로**(시스템/전화/메일) 및 배분일 협의 과정

#### 2-2. 총판 영업 및 관리 (2단계)

- [ ] 총판에 **신간 입고 및 배본하는 프로세스** — 주요 거래 총판(한국출판협동조합, 북센 등)별로 CS 시스템에서 처리하는지, 별도 시스템인지
- [ ] 총판 **공급률 협의 및 계약서 관리 체계** — 공급률(통상 60~65%) 협의 시 경영지원팀(송윤경)과의 협업 방식, 채널별 계약서(공급 계약, 납품 계약, 입점 계약 등)의 보관 방식·갱신·만료 추적 방법·사용 도구(종이/파일서버/시스템)
- [ ] 총판 **재고 현황 파악 방법** — 총판에서 데이터를 받는지, 직접 조회하는지 *(상세는 안건 4-2에서 확인)*
- [ ] 총판 **정산 내역 확인 및 수금 관리** *(상세는 안건 5-2에서 확인)*

#### 2-3. 오프라인 서점 영업 (3단계)

- [ ] 주요 거래 서점(교보문고, 영풍문고, 독립서점 등)별 **판매 동향 파악 방법** — 서점에서 데이터를 제공받는지, 자체 집계인지, 매대 확보·기획전 참여 등 협의 시 활용하는 도구나 시스템이 있는지
- [ ] **독립서점 신규 거래처 발굴** 활동 현황 — 월/연간 신규 거래처가 얼마나 확보되는지

- [ ] 반품 처리 시 **CS 시스템 반영 방식** — 자동인지, 수동 입력인지, WEHAGO와 연동되는지
- [ ] 반품 도서의 **재고 복원 과정** — 물류 창고와의 커뮤니케이션 방식

#### 4-2. 재고 관리

- [ ] 재고 확인에 사용하는 **시스템** — CS System, WEHAGO, 물류 창고 직접 문의 중 어디를 기준으로 삼는지

## 안건 5. 출고·배송·정산 및 영업 실적 관리

**목표**: 주문 접수 후 출고 지시부터 배송·정산·수금까지의 실무 프로세스와, 경영지원팀·정기구독팀·물류 창고와의 데이터 공유 체계, 영업 실적 분석에 사용하는 도구·데이터를 확인

:::note[업무플로우 참고]
영업팀 업무플로우 문서의 7단계(영업 실적 분석 및 전략 수립)와, 각 단계에 걸쳐 있는 출고·배송·정산 업무를 통합하여 확인합니다.
:::

### 핵심 질문 요약

### 상세 질문

#### 5-1. 출고 지시 및 배송

- [ ] 총판/서점/다량/특판 각 채널별 **출고 지시 방식** — CS System에서 처리하는지, 별도 절차인지
- [ ] **배송 업체 현황** — CJ대한통운, 우체국 등 채널별로 다른지
- [ ] **송장 번호 관리 및 공유** — 시스템 자동 연동인지, Excel/수동 입력인지, 물류 창고·정기구독팀과 송장 데이터를 어떻게 공유하는지 (한 곳에서 등록하면 공유되는지, 각 팀이 별도 등록하는지)
- [ ] 배송 추적 정보를 **거래처에 전달하는 방식** — 시스템, 메일, 전화 중 어떤 경로인지

:::note[정기구독팀 인터뷰 교차 검증]
정기구독팀에서는 물류 창고로부터 택배 운송장 파일을 수령 → CS 시스템 업로드 양식에 맞게 **엑셀 재가공** 후 일괄 등록하는 방식이 확인됨. 송장 번호가 CS 시스템에 등록되어야 콜센터에서 실시간 배송 조회가 가능. 영업추진팀도 동일 프로세스를 거치는지, 또는 공유 구조가 있는지 확인.
:::

#### 5-2. 정산 및 수금

- [ ] 채널별(총판/서점/다량/특판) **정산 주기와 방식** — 월별, 분기별, 사용 시스템
- [ ] 경영지원팀(송윤경)과의 **정산 데이터 전달·확인 프로세스** — 영업추진팀이 정산 데이터를 어떤 형태(엑셀/시스템/구글 시트)로 전달하는지, 경영지원팀과 서로 대조·검증하는 단계가 있는지
- [ ] **미수금 관리 현황** — 미수금 발생 빈도, 추적 방법, 사용 도구
- [ ] 나이스페이 등 **결제 시스템과의 관계** — 총판/서점/다량/특판 건도 나이스페이를 사용하는지, 별도 결제 경로인지

:::note[경영지원팀 인터뷰 교차 검증]
경영지원팀 인터뷰(2026-03-19)에서 확인된 정산 프로세스: 송윤경 팀장이 매일 아침 **신한 인사이트 뱅크에서 입금 내역 다운로드 → 구글 드라이브 시트에 공유 → 각 매출 담당자(정기구독, 다량 특판 등)가 자기 건을 확인 → 위하고에 수금 등록**. 영업추진팀이 이 프로세스에 어떻게 참여하는지 확인 필요.
:::

:::note[정기구독팀 인터뷰 교차 검증]
정기구독팀에서 확인된 **나이스페이 4~5개 계정 분산** 문제가 영업추진팀에서도 동일하게 발생하는지 확인 필요. 영업추진팀이 사용하는 나이스페이 계정이 정기구독팀과 동일한 계정인지, 별도 계정인지 확인.
:::

#### 5-3. 영업 실적 분석 및 전략 수립 (7단계)

- [ ] 채널별 **월간/분기별 판매 실적 집계 방법** — CS System에서 추출하는지, Excel 수동 집계인지
- [ ] 총판 **판매 분석 보고서 생산 과정** — 판매 데이터를 어디서 확보하여, 어떤 도구·양식으로 작성하는지, 작성 주기는 어떻게 되는지
- [ ] 도서별 **판매 분석**(베스트/스테디/부진 도서) 여부와 사용 도구
- [ ] 채널별 **수익성 분석 여부** — 총판·서점·다량·특판 간 수익성 비교를 하는지, 사용 도구는 무엇인지
- [ ] 차기 영업 전략 수립 시 **데이터 기반 의사결정**이 가능한지, 현재 데이터가 충분한지
- [ ] 실적 분석·전략 수립 과정에서 **가장 불편하거나 개선이 필요한 부분**은 무엇인지

## 안건 6. CS 시스템 메뉴 사용 현황 확인

**목표**: CS 시스템 내 영업추진팀 소관으로 추정되는 메뉴의 **실제 사용 여부, 사용 빈도, 용도**를 확인하고, 웹 전환 시 존치·통합·폐기 판단의 근거 자료로 활용

:::note[정기구독팀 인터뷰 교차 검증]
정기구독팀 인터뷰(2026-03-17)에서 CS 시스템 전체 메뉴(5개 대분류, 77개)의 사용 현황을 확인하였습니다. 정기구독팀에서 미사용하거나 "영업팀용 메뉴"로 언급된 항목을 중심으로, 영업추진팀의 실제 사용 현황을 확인합니다.

- **"영업관리" 탭**은 정기구독팀에서 미사용하는 메뉴입니다.
- **파트별 총입금액** 메뉴는 정기구독팀에서 "한화/교보. 영업팀용 메뉴"로 확인되었습니다.
:::

**확인 방법**: 인터뷰 중 CS 시스템 메뉴 트리를 함께 보며, 각 메뉴에 대해 아래 3가지를 확인:

1. **사용 여부** — ✅ 사용 중 / ❌ 미사용 / ❓ 모름
2. **사용 빈도** — 매일 / 주 N회 / 월 N회 / 거의 안 씀
3. **비고** — 실제 어떤 업무에서 쓰는지, 미사용이면 폐기 가능한지 간단 메모
