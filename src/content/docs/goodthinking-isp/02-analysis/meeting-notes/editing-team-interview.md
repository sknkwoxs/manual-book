## 안건 1. 원고 응모 관리 (웹사이트 어드민)

**목표**: 웹사이트 어드민에서의 원고 접수·분류·처리 프로세스를 파악하고, 공모전 대량 원고 처리의 수작업 부담을 검증

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| D1 | 신규 원고 확인·다운로드 과정 및 소요 시간 | 원고 접수 처리 흐름 정량 파악 |
| D2 | 상시 모집 vs 공모전 원고 구분 방식 | 원고 유형별 분류 체계, 수작업 #16 |
| D3 | 원고 상태 변경 단계 및 작성자 통보 방식 | 상태 관리 워크플로 + 알림 자동화 수준 |
| D4 | 공모전 대량 원고 배분 기준·방식 | 수작업 #16 공모전 원고 관리 정량 |
| D5 | 가장 불편한 부분 / 시간 소요 구간 | 핵심 Pain Point 도출 |

### 확인 사항 (인터뷰 중 메모)

- [ ] 어드민 로그인 → 원고 목록 → 다운로드 흐름 화면 시연 요청
- [ ] 상시 모집 / 공모전별 접수 화면이 분리되는지 확인
- [ ] 공모전별 접수 규모: 생활문예대상 ___편, 청년이야기대상 ___편, 보험사 협업 ___편
- [ ] 원고 상태값 목록: ___________________________
- [ ] 상태 변경 시 작성자 통보 방식: 자동 / 수동 / 없음

## 안건 2. 기 발행 원고 관리 (CMS)

**목표**: CMS에 축적된 33년간 원고의 업로드 프로세스, 검색 실효성, 중복 확인 방식을 파악

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| D6 | 3개월마다 잡지 원고 업로드 건수 및 소요 시간 | 수작업 #13 디지털 업로드 정량 |
| D7 | 키워드 검색 정확도 및 미검출 사례 | CMS 검색 기능 실효성 |
| D8 | CMS 등록 원고 총 건수 및 누락 기간 | 디지털 아카이브 규모 + 데이터 이관 범위 |
| D9 | 메타데이터(카테고리·태그·저자) 체계 | CMS 분류 체계 현황 |
| D10 | CMS 외 중복 확인 보완 수단 | CMS 의존도 파악 |

### 확인 사항 (인터뷰 중 메모)

- [ ] CMS 접속 → 키워드 검색 → 결과 확인 화면 시연 요청
- [ ] CMS 등록 원고 총 건수: 약 ___건
- [ ] 업로드 누락 기간: ___년 ~ ___년
- [ ] 3개월 업로드 1회 처리 건수: ___건 / 소요 시간: ___시간
- [ ] 검색 필터 종류: 기간별 / 카테고리별 / 저자별 / 키워드 (가용 여부 확인)
- [ ] CMS 외 보완 수단: Excel 목록 / 기억 / 선배 확인 / 기타 ___
