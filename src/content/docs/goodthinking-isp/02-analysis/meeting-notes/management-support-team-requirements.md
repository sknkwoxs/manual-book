## 기능요건 상세

### MGT-001

| 항목 | 내용 |
|------|------|
| **번호** | MGT-001 |
| **제목** | 엑셀 서식 표준화 및 자동 변환 |
| **내용** | CS 시스템에서 추출되는 엑셀 서식을 **위하고 및 세무법인 업로드 양식에 맞게 자동 변환**하는 기능을 구현한다. ① 출력 양식 프리셋 관리 (위하고용, 세무법인용 등), ② 자동 매핑·변환 규칙 설정, ③ 수작업 편집 단계 최소화를 목표로 한다. 엑셀 완전 폐지가 아닌 **작업 단계 최소화**가 핵심. |
| **배경** | 동일한 데이터를 CS 시스템과 위하고 양쪽에 각각 입력하거나, 위하고 양식에 맞추기 위해 엑셀을 **수작업으로 재가공(복사/붙여넣기)**하는 과정에서 실수 발생. 경영지원팀이 가장 개선되었으면 하는 부분으로 직접 언급. (R1, N2) |
| **관련 시스템** | CS 시스템, 위하고(WEHAGO) |
| **관련 메뉴** | CS 시스템 > 데이터 추출 전체 |
| **관련 부서** | 경영지원팀, 정기구독팀 |

:::tip[핵심 원칙]
경영지원팀은 "엑셀 사용을 완전히 없앨 수는 없으므로, **현재 진행 중인 작업 단계를 최소화**하는 것이 목표"라고 명확히 밝혔습니다.
:::

### MGT-002

| 항목 | 내용 |
|------|------|
| **번호** | MGT-002 |
| **제목** | 인세 관리 자동화 |
| **내용** | 출고 수량(유상 판매분)에 따른 **인세를 자동으로 계산**하는 기능을 구현한다. ① 도서별 인세율 관리, ② 출고·판매 데이터 기반 자동 산출, ③ 위하고 업로드용 데이터 자동 생성, ④ 인세 지급 이력 관리를 포함한다. |
| **배경** | 판매 건수 및 인세 계산을 **수기로 작성하여 위하고에 업로드**. 유상 판매분에 대한 세부 작업은 전부 수작업. 위하고에서는 판매된 수량까지만 알 수 있고, 인세 계산을 위한 세부 분류는 시스템 미지원. (R2, N4) |
| **관련 시스템** | CS 시스템, 위하고(WEHAGO) |
| **관련 메뉴** | 신규 메뉴 필요 |
| **관련 부서** | 경영지원팀, 편집팀, 단행본팀 |

---

### MGT-003

| 항목 | 내용 |
|------|------|
| **번호** | MGT-003 |
| **제목** | 매출 원가 관리 모듈 |
| **내용** | 개별 도서·프로젝트별 **투입 비용(인쇄비, 종이값, 인건비 등)과 매출을 한눈에 비교**할 수 있는 원가 관리 기능을 구현한다. ① 지출결의서·견적서 데이터 연동, ② 프로젝트별 BEP(손익분기점) 자동 산출, ③ 은행 이체와 동시에 비용 업로드하여 실시간 원가 파악을 목표로 한다. |
| **배경** | 특정 도서를 제작할 때 투입된 비용과 매출을 한눈에 비교할 수 있는 **시스템이 없음**. 세무법인·위하고에서는 전체 매출 기준으로만 관리하므로, 개별 도서별 수익성 판단(추가 인쇄 여부 등)이 어려움. 원 데이터(지출결의서·견적서)의 정확성 확인이 선행되어야 함. (R2) |
| **관련 시스템** | 위하고(WEHAGO), CS 시스템 |
| **관련 메뉴** | 신규 메뉴 필요 |
| **관련 부서** | 경영지원팀, 편집팀, 단행본팀 |

:::caution[구현 전제조건]
원가 관리 기능 도입 시 **지출결의서 및 견적서 등의 원 데이터 정확성 확인이 필수적**입니다. 경영지원팀이 인터뷰에서 직접 언급한 전제조건입니다.
:::

### MGT-004

| 항목 | 내용 |
|------|------|
| **번호** | MGT-004 |
| **제목** | 입금 내역 자동 배분 및 수금 등록 |
| **내용** | 신한 인사이트뱅크 입금 내역을 **자동으로 수신하여 담당자별 배분 및 위하고 수금 등록**까지 연계 처리하는 기능을 구현한다. ① 입금 내역 자동 수신(API/파일 연동), ② 거래 유형별 자동 분류·배분, ③ 위하고 수금 등록 데이터 자동 생성을 포함한다. |
| **배경** | 매일 아침 신한 인사이트뱅크에서 통합 조회 → 엑셀 다운로드 → 구글 드라이브 공유 → 담당자별 배분 → 위하고 수금 등록의 다단계 수작업 발생. (N1) |
| **관련 시스템** | CS 시스템, 은행 시스템(신한 인사이트뱅크), 위하고(WEHAGO) |
| **관련 메뉴** | 입금관리 > 입금현황 |
| **관련 부서** | 경영지원팀, 정기구독팀 |

---

### MGT-005

| 항목 | 내용 |
|------|------|
| **번호** | MGT-005 |
| **제목** | 선수수익 현황표 자동 생성 |
| **내용** | CS 시스템에서 **선수수익 현황표를 세무법인 전달 양식에 맞춰 자동 생성**하는 기능을 구현한다. ① 월결산 시 자동 추출, ② 세무법인 양식 자동 변환, ③ 위하고 업로드용 데이터 동시 생성을 포함한다. |
| **배경** | 월결산 시 CS 시스템에서 선수수익 현황표를 추출한 뒤 서식을 수동으로 정리하여 세무법인에 전달. 세무법인이 이를 위하고에 업로드하는 다단계 프로세스. (N3) |
| **관련 시스템** | CS 시스템, 위하고(WEHAGO) |
| **관련 메뉴** | 관리자업무 > 정산 관련 |
| **관련 부서** | 경영지원팀 |

---

### MGT-006

| 항목 | 내용 |
|------|------|
| **번호** | MGT-006 |
| **제목** | 일반계좌 입금 자동 처리 |
| **내용** | 가상계좌 외 일반계좌로 입금된 건을 **입금자명·금액 기반으로 자동 매칭**하고 처리하는 기능을 구현한다. 가상계좌와 동일 수준의 자동 입금 처리를 목표로 한다. |
| **배경** | 가상계좌는 자동 입금처리되나 일반계좌는 수작업으로 처리 중. 정기구독팀(정황규 매니저)이 수시로 수동 매칭하는 업무와 연계. (N5) |
| **관련 시스템** | CS 시스템, 은행 시스템(신한 인사이트뱅크) |
| **관련 메뉴** | 입금관리 > 입금현황 |
| **관련 부서** | 경영지원팀, 정기구독팀 |

:::note[SUB-012와 연관]
이 기능요건은 정기구독팀의 [SUB-012 (일반계좌 입금 자동 매칭)](/goodthinking-isp/02-analysis/meeting-notes/subscription-team-requirements/#sub-012)과 동일 영역입니다. 경영지원팀 관점의 **배분·수금 등록 자동화**에 초점을 둡니다.
:::
