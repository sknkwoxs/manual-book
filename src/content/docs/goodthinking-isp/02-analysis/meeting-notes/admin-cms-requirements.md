# 기능요건 — 어드민/CMS

:::note[문서 기준]
본 문서는 [편집팀 인터뷰 결과(2026.03.12)](/goodthinking-isp/02-analysis/meeting-notes/editing-team-interview/)에서 도출한 **어드민·CMS 관련 기능요건 11건**을 정리한 것입니다.

참고: 좋은생각의 CMS는 **월간지 발행 콘텐츠를 보관·검색하는 아카이브 용도**로만 활용되며, CS/구독 관련 정보는 취급하지 않습니다.
:::

:::note[중점 논의 사항]
어드민/CMS 영역에서는 파편화된 원고 관리 프로세스를 통합하고, 향후 메타데이터 및 검색기능 강화, 편집 심사 워크플로우 개선 등 **전문적인 원고 응모 플랫폼**으로 확장하기 위한 기반을 마련하는 데 집중하였습니다.
- **CMS 내 원고 자산화:** 좋은생각의 원고관리 플랫폼을 강화하여 내부용 CMS를 넘어, 장기적으로 외부에서도 검색 가능한 **디지털 원고 아카이브**로의 확장 가능성을 검토했습니다.
- **사용자 권한 및 운영 유연성:** 배너, 팝업, 이벤트 페이지 등을 개발자의 도움 없이 능동적으로 움직일 수 있는 환경을 구축하는 것을 논의하였습니다.
- **단계적 추진 (2nd Phase)**: 현 프로젝트에서는 정기 구독 관리를 위한 클라우드 CS 시스템을 공고히 구축하는 데 집중합니다. 어드민/CMS 기능 개선은  **'세컨드 페이즈(Second Phase)'** 과제로 분류하여 추진할 필요성을 제시하였습니다.
:::

### EDT-001

| 항목 | 내용 |
|------|------|
| **번호** | EDT-001 |
| **제목** | 클라우드 기반 시스템 통합 구축 |
| **내용** | 기존 어드민·CMS·NAS에 분산된 데이터를 **보안성과 안정성이 확립된 클라우드 환경으로 통합 이관**한다. 데이터 중앙 집중 관리, 접근 로그 기록, 자동 백업, 재해 복구(DR) 체계를 포함한다. |
| **배경** | 편집팀의 실무 파일이 어드민·CMS·NAS에 분산 저장되어 있으며, NAS에 부주의로 인한 데이터 삭제 리스크가 존재. 프로덕트 데이터의 백업이 NAS에만 의존하는 불안정한 구조. ([R1](/goodthinking-isp/02-analysis/meeting-notes/editing-team-interview/#시스템-기능-개선-요구사항)) |
| **관련 시스템** | 어드민, CMS, NAS |
| **관련 메뉴** | - |
| **관련 부서** | 편집팀, 전체 부서 |

:::caution[데이터 안정성]
현재 NAS 기반 백업에만 의존하고 있어 **데이터 유실 시 복구가 불가능**합니다. 클라우드 이관은 시스템 구축의 기반이 되는 **최우선 과제**입니다.
:::

:::note[논의 사항]
- **인프라 비용 효율화**: 회의에서는 클라우드 기반 인프라로 전환하거나 개선할 경우, 현재 운영되고 있는 인프라 비용에서 일정 비율을 절감할 수 있다는 점이 강조되었습니다.
:::

### EDT-002

| 항목 | 내용 |
|------|------|
| **번호** | EDT-002 |
| **제목** | 어드민-CMS 원고 자동 이관 |
| **내용** | 어드민에서 채택된 원고를 CMS에 **자동으로 이관**하는 기능을 구현한다. ① 원고 채택 시 CMS 전송 워크플로우, ② 이관 시 메타데이터 자동 매핑, ③ 이관 상태 추적(대기/완료/실패), ④ 이미지 등 첨부파일 동시 이관을 포함한다. |
| **배경** | 어드민(응모 원고)과 CMS(발행 원고)가 연동되지 않아, 채택된 원고를 CMS에 **일일이 복사·붙여넣기**하는 수작업 발생. 두 시스템 간 데이터 흐름이 완전히 단절. ([R2](/goodthinking-isp/02-analysis/meeting-notes/editing-team-interview/#시스템-기능-개선-요구사항), [N1](/goodthinking-isp/02-analysis/meeting-notes/editing-team-interview/#신규-발견-수작업병목)) |
| **관련 시스템** | 어드민, CMS |
| **관련 메뉴** | 어드민 > 응모 관리, CMS > 원고 관리 |
| **관련 부서** | 편집팀 |

:::note[논의 사항]
- **편집팀 업무 경감**: 편집팀이 원고를 관리하고 찾는 데 너무 많은 시간을 쓰고 있다는 점을 지적하며, 이관 자동화가 편집 업무의 생산성을 높이는 핵심이라고 보았습니다.
- **데이터 구조 확인**: 장기적으로는 어드민과 CMS의 DB를 통합하거나, 클라우드 상에서 유기적으로 연결하여 데이터가 흐르는 구조를 만들어야 함을 고려했습니다.
:::

- **플랫폼 내 통합 심사**: 원고 파일을 개별적으로 내려받아 확인하는 기존 방식 대신, 시스템 안에서 PDF, 워드, 한글 파일을 즉시 열람하고 심사평과 점수를 남기는 통합 심사 환경 구축이 필요하다는 의견이 제시되었습니다.
:::

### EDT-004

| 항목         | 내용                                                                                                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **번호**     | EDT-004                                                                                                                                                                     |
| **제목**     | 메타데이터 관리 및 검색 강화                                                                                                                                                            |
| **내용**     | 업로드 원고에 **메타데이터를 부여 및 관리**하여 검색 정확도를 향상시킨다. 주제어 외 저자, 발행일, 코너, 태그 등 다차원 검색 지원. 메타데이터를 활용한 **자체 콘텐츠 생산** 가능성을 고려한다.                                                          |
| **배경**     | CMS 검색 시 주제어로만 검색 가능하며, 메타데이터가 없어 중복 콘텐츠 검증이 불충분. 검색 정확도가 낮아 필요한 원고를 찾는 데 시간 소요. ([R4](/goodthinking-isp/02-analysis/meeting-notes/editing-team-interview/#시스템-기능-개선-요구사항)) |
| **관련 시스템** | CMS                                                                                                                                                                         |
| **관련 메뉴**  | CMS > 검색, CMS > 원고 관리                                                                                                                                                       |
| **관련 부서**  | 편집팀                                                                                                                                                                         |

:::note[논의 사항]
- **AI를 활용한 업무 부하 경감:** 매달 들어오는 수천 건의 원고에 대해 편집자가 일일이 메타데이터를 입력하는 것은 불가능하므로, AI가 내용을 읽고 요약 글을 만들거나 핵심 키워드를 자동으로 도출하는 기능을 제안했습니다.
- **자산화 및 서비스화**: 잘 정리된 메타데이터를 기반으로 내부 인원뿐만 아니라 외부 사용자(한화 등 B2B 연계)도 접근 가능한 '디지털 아카이브'를 구축할 수 있는 가능성을 확인했습니다.
- **단계적 적용**: 과거 원고의 경우 AI의 도움을 받아 메타데이터를 소급 적용하고, 향후 접수되는 원고는 등록 단계부터 데이터가 쌓이도록 하는 방향을 제시했습니다.
:::
