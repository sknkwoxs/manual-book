## 기능요건 상세

### EDT-001

| 항목 | 내용 |
|------|------|
| **번호** | EDT-001 |
| **제목** | 클라우드 기반 시스템 통합 구축 |
| **내용** | 기존 어드민·CMS·NAS에 분산된 데이터를 **보안성과 안정성이 확립된 클라우드 환경으로 통합 이관**한다. 데이터 중앙 집중 관리, 접근 로그 기록, 자동 백업, 재해 복구(DR) 체계를 포함한다. |
| **배경** | 편집팀의 실무 파일이 어드민·CMS·NAS에 분산 저장되어 있으며, NAS에 부주의로 인한 데이터 삭제 리스크가 존재. 프로덕트 데이터의 백업이 NAS에만 의존하는 불안정한 구조. (R1) |
| **관련 시스템** | 어드민, CMS, NAS |
| **관련 메뉴** | - |
| **관련 부서** | 편집팀, 전체 부서 |

:::caution[데이터 안정성]
현재 NAS 기반 백업에만 의존하고 있어 **데이터 유실 시 복구가 불가능**합니다. 클라우드 이관은 시스템 구축의 기반이 되는 **최우선 과제**입니다.
:::

### EDT-002

| 항목 | 내용 |
|------|------|
| **번호** | EDT-002 |
| **제목** | 어드민-CMS 원고 자동 이관 |
| **내용** | 어드민에서 채택된 원고를 CMS에 **자동으로 이관**하는 기능을 구현한다. ① 원고 채택 시 CMS 전송 워크플로우, ② 이관 시 메타데이터 자동 매핑, ③ 이관 상태 추적(대기/완료/실패), ④ 이미지 등 첨부파일 동시 이관을 포함한다. |
| **배경** | 어드민(응모 원고)과 CMS(발행 원고)가 연동되지 않아, 채택된 원고를 CMS에 **일일이 복사·붙여넣기**하는 수작업 발생. 두 시스템 간 데이터 흐름이 완전히 단절. (R2, N1) |
| **관련 시스템** | 어드민, CMS |
| **관련 메뉴** | 어드민 > 응모 관리, CMS > 원고 관리 |
| **관련 부서** | 편집팀 |

| **제목** | 메타데이터 관리 및 검색 강화 |

| **관련 시스템** | CMS |
| **관련 메뉴** | CMS > 검색, CMS > 원고 관리 |
