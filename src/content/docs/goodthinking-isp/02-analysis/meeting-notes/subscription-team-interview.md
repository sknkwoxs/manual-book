어은진 매니저는 사이트 내 구독 취소 자동화 기능 도입 시 **"잘 기능할 수 있을지에 대한 두려움"**을 언급함. 현 시스템의 빈번한 돌발 상황(미납 보류 오류, 무단 취소 등)으로 인해 자동화 신뢰도에 대한 우려가 있음.
:::

**정황규 매니저 — 취소/환불 프로세스**:
1. 취소 요청 접수 시 CS 시스템에서 **회원 번호 기준** 조회
2. **"매출 취소"**와 **"구독 취소"**를 각각 별도 처리
3. 계좌이체 건 → WEHAGO에 지출결의서를 올려 **수동 입금**
4. 카드 결제 건 → **나이스페이에 직접 접속**하여 취소

**나이스페이 계정 분산 문제**:
결제 출처에 따라 **4~5개의 개별 나이스페이 계정**을 번갈아 접속해야 함:

| 계정 | 용도 |
|------|------|
| 1번 | 담당자가 직접 입력한 카드 건 |
| 2번 | 홈페이지로 접수된 카드 및 계좌이체 건 |
| 3번 | 담당자들이 직접 입력한 계좌이체 건 |
| 4번 | 예비 계정 |
| 5번 | 다양한 기관 상대 카드 및 계좌이체 건 |

#### 1-4. 도서 발송 및 송장 처리

- [x] 월간지 발송 처리: CS System → 우체국/CJ 데이터 업로드 방식 확인
- [x] 발송 데이터 생성 → 배송사 업로드 소요 시간 확인

**정기 발송 데이터 생성**:
- 매월 신간 발송을 위해 **약 3~4만 건의 라벨 자료**를 서버에서 추출
- 단기간 처리가 어려워 **발송작업 전날 배치 작업을 예약**하여 추출
- 라벨 추출 시 최신 호수 업데이트 필수

**송장 번호(운송장) 업데이트**:
- 배송 창고에서 우체국/CJ 등 **택배 운송장 파일 업로드** → 송장 번호 엑셀을 CS 시스템 업로드 양식에 맞게 **재가공** 후 일괄 등록
- 택배 운송장 번호를 CS에 업로드해야 **콜센터 실시간 배송 조회 가능**

**신규/재발송 처리**:
- 정기 구독 외에 매일 발생하는 **신규 가입자 및 파손/미수령 건**에 대한 재발송 명단 관리
- 개인 택배 건수는 많지 않으며 대부분 **우체국 일괄 발송**

#### 1-5. 특수 결제 수동 처리

**문화누리카드**:
- 온라인 결제 불가 → 고객에게 전화로 카드 번호와 유효기간을 불러달라고 한 뒤 **사내 실물 단말기로 수기 결제**

*(어드민 수기 카드 결제 관리 탭 시연 [사진 46])*

#### 1-6. 선물 선발송 처리 프로세스

- 좋은생각 정기구독 1년 신청 시 선물 지급
- 구독 시작월이 미도래한 고객 중 **선물만 먼저 받고 싶은 경우** 별도 선발송 처리 필요
- 시스템에서는 구독 시작월에만 선물이 발송되므로 **수동 선발송 프로세스** 진행:
  1. 회원현황에서 선발송 희망 회원 검색
  2. 선물재발송관리에서 재발송 처리 후 저장 → 발송 자료 생성
  3. 구독 시작월에 이중 발송을 방지하기 위해 **기존 정상 발송 기록을 수동 삭제**
- **'정상 구독 데이터 생성 → 선발송 복제 생성 → 기존 정상 데이터 삭제'**라는 3~4단계의 불필요하고 복잡한 절차

*(선발송 프로세스 시연 [사진 47]~[사진 50])*

#### 1-7. 특수 구독(새벽햇살) 처리

- 교정기관 기부 상품인 **'새벽햇살'**은 구독 접수 시 **수령처가 미정** 상태로 입금
- 한 달간 가상계좌 입금 등을 확인하여 모아둔 뒤, **수동으로 기부처를 매칭**하고 편집팀에 명단 전달

*(CS 시스템 내 새벽햇살 구독 현황 확인 [사진 51])*

#### 1-8. 입금 확인 및 수금 등록

**미결 입금 처리**:
- 통장으로 들어온 현금 입금 내역 중 **신원 확인이 필요한 건**(예: 방송대 대구경북 등)을 조회하여 시스템에 수금 등록

**가상계좌 관리**:
- 자동으로 들어오는 가상계좌 외에 **일반 계좌로 입금된 정기 구독 건**들을 수동으로 매칭하여 처리

## 안건 3. CS 시스템 메뉴 사용 현황 확인

:::

#### 4-5. CTI(전화-고객정보 연동) 시스템 중단

- [x] CTI 연동 현황 및 중단 사유 확인

**CTI 연동이란?**:
- 고객이 전화를 걸면 발신 번호를 기반으로 **CS 시스템에서 해당 고객 정보를 자동으로 팝업** 표시하는 기능
- 상담 시작 전 고객 이름·구독 상태·최근 문의 이력 등을 즉시 확인 → 응대 효율 향상

**현재 상태: 중단**
- **변경 전**: KT 통신사 + CTI 연동(서울정보시스템) → 전화 인입 시 고객 정보 자동 팝업
- **변경 후**: 요금 부담으로 **KT → LG 통신사 전환** → CTI 연동이 끊김
- **결과**: 콜센터·정기구독팀 모두 전화 수신 시 **고객 핸드폰 번호를 구두 확인 → CS 시스템에서 회원 현황 수동 검색**

**영향**:
- 상담 1건당 고객 식별에 **추가 30초\~1분 소요** (이름/전화번호 구두 확인 + 수동 검색)
- 월간 전화 CS 건수 대비 누적 시간 손실 (정확한 건수는 더아이앤오 교차 인터뷰 시 확인 필요)
- 고객 경험 저하: 매번 본인 확인 절차 반복, 상담 시작까지 대기 시간 증가

**복구 방안**:
- 차세대 시스템 구축 시 **웹 기반 CTI 연동** 복구 필요 (통신사 무관하게 SIP/WebRTC 방식)
- → 개선 요구사항 R7 (CTI 시스템 복구)

## 인터뷰 결과 요약

### 핵심 발견 사항

1. **과도한 수작업 및 엑셀 의존도**: 매일 오전 3~4시간을 10개 이상 채널의 상이한 엑셀 양식 표준화에 소비. 콤마 누락·띄어쓰기 오류 하나만 있어도 업로드 차단되어 업무 피로도 극심
2. **나이스페이 계정 분산**: 결제 출처별 4~5개의 개별 나이스페이 계정을 번갈아 접속해야 하며, 카드 취소 시 해당 계정을 찾아 직접 처리해야 하는 비효율
3. **개인정보 자동 파기 기능 부재**: 5년 경과 개인정보의 자동 삭제 기능이 없어 **가장 급한 법적 리스크**로 인식. 매월 수동 대조·삭제 진행 중
4. **3개 시스템 간 재고 불일치**: 위하고/CS 시스템/물류 창고 간 재고가 실시간 연동되지 않아 매월 강제 수동 보정
5. **선발송 프로세스의 비합리적 복잡성**: 정상 데이터 생성 → 재발송 복제 → 정상 데이터 삭제의 3~4단계 불필요 절차
6. **CTI 연동 중단**: 통신사 변경(KT→LG) 후 고객 정보 자동 팝업 기능 상실, 콜센터 업무 효율 저하
7. **외주 콜센터 권한 미분화**: 실적 조작 리스크 존재, 세분화된 권한 관리 필요
8. **어드민-CS 시스템 기능 혼재**: 주문/구독 업로드 관리 등 CS 시스템에 있어야 할 기능이 어드민에 위치하고, 반대 현상도 혼재
9. **회원 식별 및 중복 문제**: 동일인 다중 계정, 외부몰-자사 계정 미연동으로 "내 구매 내역이 보이지 않는다"는 CS 문의 빈번
10. **현 시스템의 돌발 오류**: 입금 완료인데 미납 보류 처리, 미취소인데 자동 취소 등 예측 불가 시스템 오류 다수

## 경영지원팀 인터뷰 시 추가 확인 예정 사항 (2026-03-19)

:::note[교차 검증]
정기구독팀 인터뷰에서 파악된 아래 업무들은 경영지원팀과의 교차 확인이 필요합니다.
:::

### 1. 주문 수집 및 데이터 가공 (오전 주 업무)

- **다채널 주문 통합**: 매일 오전 플레이오토를 통해 스마트스토어·쿠팡 등의 주문을 수집하며, 연동되지 않는 외부 몰(나이스북 등)은 직접 개별 접속하여 다운로드
- **엑셀 데이터 표준화**: 수집된 각기 다른 양식의 엑셀 파일들을 자사 CS 시스템 업로드 규격에 맞게 수작업으로 가공
- **시스템 등록 및 검수**: 가공된 데이터를 시스템에 일괄 업로드한 후, 누락된 값을 육안으로 대조하며 최종 등록

### 2. 정기 및 수시 발송 관리

- **라벨 출력 데이터 생성**: 신간 발행 시 약 3~4만 건의 구독자 데이터를 추출하기 위해 서버 배치 작업 예약 관리
- **송장 번호(운송장) 업데이트**: 배송 창고에서 전달받은 송장 번호 엑셀을 시스템 양식에 맞게 재가공하여 업로드
- **신규/재발송 처리**: 정기 구독 외에 매일 발생하는 신규 가입자 및 파손/미수령 건에 대한 재발송 명단 관리

### 3. 입금 확인 및 수금 등록

- **미결 입금 처리**: 통장 현금 입금 중 신원 확인 필요 건을 조회하여 시스템 수금 등록
- **가상계좌 관리**: 자동 입금 외 일반 계좌 입금 정기 구독 건 수동 매칭
- **특수 구독 관리**: '새벽햇살(기부 상품)' 입금 건 수동 기부처 매칭 후 편집팀 전달

### 4. 취소·환불 및 재고 관리

- **취소 프로세스**: CS 시스템 내 '매출 취소'와 '구독 취소' 각각 처리
- **환불 행정**: 계좌이체 → WEHAGO 지출결의서 / 카드 → 나이스페이 직접 승인 취소
- **재고 수치 조정**: 위하고/CS 시스템 간 재고 오차 확인 및 강제 보정
