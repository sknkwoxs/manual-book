## 인터뷰 목적

정기구독팀의 **세 가지 핵심 업무 영역**을 파악하고, 각 업무의 현행 프로세스·수작업·병목을 검증합니다.

1. **구독 접수·결제·발송** — 다채널 주문 수집부터 CS System 입력, 결제 확인, 발송 처리까지의 전 과정
2. **CMS 권한 관리 및 구독 라이프사이클** — 결제 확인 후 CMS 콘텐츠 접근 권한 부여·회수, 구독 갱신·해지·환불 처리
3. **데이터 취합·검증** — 채널별 데이터 통합, 지로/가상계좌 입금 대조, 데이터 정합성 확인

## 안건 1. 구독 접수·결제·발송 프로세스

**목표**: 다채널(전화/웹/외부몰) 구독 접수부터 결제 확인, CS System 입력, 발송 처리까지의 전 과정을 파악하고, 수동 입력·매칭 구간의 시간·건수·오류를 검증

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| A1 | 나이스페이 결제 확인 → 구독 정보 수동 매칭 과정 및 소요 시간 | 결제-구독 수동 매칭 병목 ①, 수작업 #5 |
| A3 | CS 처리 시 고객 이력(구독/결제/배송/CS)을 한 화면에서 볼 수 있는지 | 고객 360° 뷰 부재 확인 |
| A4 | 구독 갱신/해지/환불 처리 절차 및 소요 시간 | 구독 라이프사이클 관리 병목 |

### 확인 사항 (인터뷰 중 메모)

- [ ] 구독 접수 채널별(전화/웹/외부몰) 처리 흐름 차이 확인
- [ ] 나이스페이 PG 화면 ↔ CS System 화면 전환 과정 시연 요청
- [ ] 일일 주문 건수: 전화 ___건, 웹 ___건, 외부몰 ___건
- [ ] 건당 CS System 수동 입력 소요 시간: ___분
- [ ] 결제-구독 매칭 시 고객 식별 기준: 이름 / 전화번호 / 주문번호 / 기타 ___
- [ ] 월간지 발송 처리: CS System → 우체국/CJ 데이터 업로드 방식 확인

### 핵심 질문 요약
