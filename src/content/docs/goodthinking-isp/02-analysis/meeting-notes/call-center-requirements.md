## 기능요건 상세

### CC-001

| 항목 | 내용 |
|------|------|
| **번호** | CC-001 |
| **제목** | 메인 키 중심 통합 조회 |
| **내용** | 성명·연락처·주소 등 **최근 입력된 핵심 키값 기준으로 회원 정보를 하나로 묶어 보여주는 통합 조회** 기능을 구현한다. ① 최근 사용된 회원번호 상단 정렬 또는 구독 중인 회원정보에 시각적 표시, ② 정기구독 접수와 도서 (재)발송 메뉴에 흩어져 있는 구독 현황 통합, ③ 과거 상담 이력 즉시 조회를 포함한다. |
| **배경** | 한 명의 고객이 여러 채널을 통해 구독할 경우 회원번호가 각각 생성되어 과거 이력을 통합해서 볼 수 없음. 유통 경로가 아닌 **회원을 중심으로 생성되는 핵심 키 값**이 필요. 정기구독 접수와 도서 (재)발송 메뉴에 구독 현황이 흩어져 있음. (R1) |
| **관련 시스템** | CS 시스템 |
| **관련 메뉴** | 기본업무 > 회원 현황, 구독접수 > 정기구독접수관리, 발송업무 > 도서재발송 |
| **관련 부서** | 콜센터(더아이앤오), 정기구독팀 |

:::tip[SUB-006과 연관]
이 기능요건은 정기구독팀의 [SUB-006 (회원 계정 통폐합)](/goodthinking-isp/02-analysis/meeting-notes/subscription-team-requirements/#sub-006)과 밀접하게 연관됩니다. 회원 계정 통폐합이 선행되어야 통합 조회가 실효적으로 작동합니다.
:::

### CC-002

| 항목 | 내용 |
|------|------|
| **번호** | CC-002 |
| **제목** | 유연한 주소 검색 |
| **내용** | **띄어쓰기·명칭 약어에 무관한 유연한 주소 검색**을 도입한다. ① 도로명/지번 주소 자동 변환, ② '경기도/경기' 등 약어·풀네임 동시 인식, ③ 자동 주소 완성(autocompletion) 기능을 포함한다. |
| **배경** | 도로명/지번 주소 혼용 및 '경기도/경기' 등 입력 방식 불일치로 검색 결과가 다르게 나타나며, 동일 주소를 여러 번 검색해야 하는 비효율 발생. (R1) |
| **관련 시스템** | CS 시스템 |
| **관련 메뉴** | 기본업무 > 회원 현황 (주소 검색 전체) |
| **관련 부서** | 콜센터(더아이앤오), 정기구독팀 |

### CC-003

| 항목 | 내용 |
|------|------|
| **번호** | CC-003 |
| **제목** | CTI 시스템 연동 복구 |
| **내용** | 전화 인입 시 **발신 번호 기반으로 고객 정보·과거 상담 이력을 즉시 팝업**하는 CTI 연동을 복구한다. 통신사 무관한 방식(SIP/WebRTC)으로 구현하여, 안심번호 고객에 대한 대체 식별 방안도 포함한다. |
| **배경** | KT→LG 통신사 변경 후 CTI 연동 불가. 전화 인입 시 고객 정보 팝업이 뜨지 않아 상담원이 **수동으로 번호를 검색**. 안심번호 사용 고객은 식별 자체가 불가능. (R2, N1, N7) |
| **관련 시스템** | CS 시스템, 전화 시스템(LG 유플러스) |
| **관련 메뉴** | 기본업무 > 회원 현황 |
| **관련 부서** | 콜센터(더아이앤오), 정기구독팀 |

:::note[SUB-007과 동일 영역]
이 기능요건은 정기구독팀의 [SUB-007 (CTI 시스템 복구)](/goodthinking-isp/02-analysis/meeting-notes/subscription-team-requirements/#sub-007)과 동일한 영역입니다. 콜센터 관점의 **상담 워크플로우 통합** 및 **안심번호 대응**에 초점을 둡니다.
:::

### CC-006

| 항목 | 내용 |
|------|------|
| **번호** | CC-006 |
| **제목** | 배송일 오안내 방지 |
| **내용** | ① **예상 배송일 필드를 추가**하여 시스템상 배송 완료 표시와 실제 배송일의 차이로 인한 오안내를 방지한다. ② 데이터 배치 작업 예약 시점 이후 접수된 건에 대한 **별도 표시** 기능, ③ 상담원이 정확한 배송 정보를 안내할 수 있도록 **배송 상태 세분화**(접수/집하/배송중/배달완료)를 포함한다. |

| **관련 시스템** | CS 시스템 |
| **관련 메뉴** | 발송업무 > 월간지발송, 발송업무 > 도서발송 |
| **관련 부서** | 콜센터(더아이앤오), 정기구독팀 |

### CC-012

| 항목 | 내용 |
|------|------|
| **번호** | CC-012 |
| **제목** | 카드 결제 즉시 취소 (나이스페이 API) |
| **내용** | 당일 발생한 카드 결제 건을 **본사 이관 없이 CS 시스템에서 즉시 취소 처리**할 수 있도록 나이스페이 API를 연동한다. 취소 권한 등급 설정, 취소 사유 기록, 취소 이력 관리를 포함한다. |
| **배경** | 카드 결제 취소 시 콜센터에서 직접 처리할 수 없어 **본사(정기구독팀)에 이관**. 정기구독팀은 나이스페이 4~5개 계정 중 해당 계정을 찾아 직접 취소 처리. 처리 지연으로 고객 불만 발생. (R4) |
| **관련 시스템** | CS 시스템, 나이스페이 |
| **관련 메뉴** | 입금관리 > 카드결제관리 |
| **관련 부서** | 콜센터(더아이앤오), 정기구독팀 |

:::note[SUB-002와 연관]
이 기능요건은 정기구독팀의 [SUB-002 (결제·회계 시스템 API 연동)](/goodthinking-isp/02-analysis/meeting-notes/subscription-team-requirements/#sub-002)과 동일한 나이스페이 API 연동 영역입니다. 콜센터 관점의 **즉시 취소 권한·워크플로우**에 초점을 둡니다.
:::
