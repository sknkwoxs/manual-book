## 인터뷰 목적

정기구독팀 인터뷰(2026-03-17)에서 외부 콜센터 연계 업무가 핵심 이슈로 부각되었습니다. 본 인터뷰는 **콜센터 측 관점**에서 업무 현황과 불편사항을 직접 파악하고, 정기구독팀 인터뷰 내용과 교차 검증합니다.

1. **CS 업무 현황** — 일일 처리 건수, 문의 유형별 비율, 처리 프로세스
2. **시스템 접근 및 사용성** — CS 시스템 접속 환경, 메뉴 사용 범위, 불편사항
3. **에스컬레이션 현황** — 본사 이관 빈도·사유, 커뮤니케이션 방식
4. **CTI 중단 영향** — 통신사 변경(KT→LG) 후 업무 영향 체감도
5. **실적 관리 및 정산** — 건별 수수료 정산 프로세스, 실적 데이터 관리

본 인터뷰 안건은 [정기구독팀 인터뷰 결과](/goodthinking-isp/02-analysis/meeting-notes/subscription-team-interview/#안건-4-외주-콜센터-연계-업무)의 안건 4(외주 콜센터 연계 업무)에서 도출된 교차 검증 항목 6건을 포함합니다. ## 안건 4. CTI 중단 영향 확인

**목표**: CTI(전화-고객정보 연동) 중단이 콜센터 업무에 미치는 구체적 영향을 파악하고, 복구 우선순위의 근거를 확보

:::note[배경]
정기구독팀 인터뷰에서 통신사 변경(KT→LG) 후 CTI 연동이 끊겨, 전화 인입 시 고객 정보 자동 팝업이 불가한 상태임을 확인했습니다. 콜센터에서 체감하는 영향을 직접 파악합니다.
:::

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| T1 | CTI 연동 당시(KT)와 현재(LG) 업무 흐름 차이 — 고객 식별 과정 비교 | CTI 중단 전후 효율 차이 정량화 |
| T2 | CTI 미연동 상태에서 고객 식별에 추가 소요되는 시간 | 건당 추가 시간 × 월간 건수 = 손실 시간 |
| T3 | CTI 미연동으로 인한 고객 불만 사례 (본인 확인 반복, 대기 시간 등) | 고객 경험 영향 파악 |
| T4 | CTI 복구 시 가장 기대하는 기능 | CTI 복구 요구사항 구체화 |

### 확인 사항 (인터뷰 중 메모)

- [ ] CTI 연동 당시 고객 식별 방식: 자동 팝업 / 기타 ___
- [ ] 현재 고객 식별 방식: 구두 확인(이름/전화) → 시스템 검색
- [ ] CTI 미연동으로 인한 건당 추가 소요: ___초~___분
- [ ] 월간 전화 CS 건수 × 추가 소요 = 월간 손실 시간: ___시간
- [ ] CTI 미연동 관련 고객 불만 사례: ___
- [ ] CTI 복구 시 희망 기능: 고객 팝업 / 이전 상담 이력 표시 / 기타 ___

## 안건 5. 실적 관리 및 정산 프로세스

**목표**: 건별 수수료 기반 정산 프로세스와 실적 데이터 관리 방식을 파악하여, 실적 데이터 무결성 및 권한 관리 이슈를 검증

:::caution[정기구독팀 인터뷰에서 확인된 리스크]
정황규 매니저는 콜센터 직원이 **자신의 실적(접수 건수) 데이터에 접근·수정 가능**한 구조라고 언급했으며, 실적 비례 수수료 방식과 결합되어 **실적 조작 리스크**가 존재한다고 지적했습니다. 본 안건에서 콜센터 측의 실적 관리 프로세스를 직접 확인합니다.
:::

### 핵심 질문 요약

| # | 질문 요약 | 검증 대상 |
|---|----------|----------|
| P1 | 월간 실적(접수 건수) 집계 방식 — CS 시스템 자동 집계 / 수동 집계 | 실적 데이터 생성 프로세스 |
| P2 | 실적 데이터 확인 및 정산 요청 프로세스 — 누가 확인하고 승인하는지 | 정산 워크플로 + 검증 체계 |
| P3 | 실적 데이터에 대한 콜센터 측 수정 권한 유무 | 실적 데이터 무결성 확인 |
| P4 | 정산 주기 및 기준 — 월 정산 / 접수 건 기준 / 상담 건 기준 | 정산 기준 명확화 |
| P5 | 실적 관련 이의 제기 사례 및 처리 방식 | 정산 분쟁 현황 |

### 확인 사항 (인터뷰 중 메모)

- [ ] 실적 집계 방식: CS 시스템 자동 / 별도 집계 / 기타 ___
- [ ] 실적 확인 화면 접근: 가능 / 불가
- [ ] 실적 데이터 수정 권한: 있음 / 없음 / 모름
- [ ] 정산 주기: 월 / 기타 ___
- [ ] 정산 기준: 접수 건수 / 상담 건수 / 처리 완료 건수 / 기타 ___
- [ ] 월 평균 정산 금액 범위: ___ (공유 가능 시)
