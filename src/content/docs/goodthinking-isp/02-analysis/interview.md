# 이해관계자 인터뷰

핵심 업무 담당자 인터뷰를 통한 현행 업무 파악 및 요구사항 수집

---

## 인터뷰 개요

### 목적
1. **현행 업무 파악**: 실제 업무 수행 방식과 흐름 이해
2. **문제점 도출**: 현 시스템/프로세스의 불편사항 및 개선점 파악
3. **요구사항 수집**: 신규 시스템에 필요한 기능 및 개선 요청 취합

### 인터뷰 대상

| 구분 | 역할 | 담당자 | 인터뷰 일자 | 상태 |
|------|------|--------|-----------|:----:|
| 정기구독팀 | 구독/CS 업무 총괄 | 정황규 | | ⬜ |
| 정기구독팀 | 구독/CS 실무 담당 | 어은진 | | ⬜ |
| 영업추진팀 | 주문/배송 관리 (총판/다량/특판) | 이성수 | | ⬜ |
| 영업추진팀 | 주문/배송 실무 | 권지은 | | ⬜ |
| 경영지원팀 | 회계/정산 관리 | 송윤경 | | ⬜ |
| 경영지원팀 | 경영지원 실무 | 김나현 | | ⬜ |
| 콘텐츠부문 | CMS/편집 총괄 (연구소장) | 정다정 | | ⬜ |
| IT/시스템 | 시스템 관리 (외부 개발자) | 김재옥 소장 | | ⬜ |
| 경영/관리 | 전체 총괄 (CEO) | 정용철 | | ⬜ |
| 외부콜센터 | CS 아웃소싱 (~4명) | 더아이앤오 | | ⬜ |

## 인터뷰 질문 가이드

:::note[질문 구성 원칙]
대상자의 **구분/역할**에 맞는 맞춤형 질문으로 구성했습니다.
- **공통 질문 (C1~C3)**: 전 대상자 공통
- **유형별 질문 (A~G)**: 역할에 따라 해당 유형만 질문
  - A: 정기구독팀 (정황규, 어은진) · B: 영업추진팀 (이성수, 권지은) · C: 경영지원팀 (송윤경, 김나현)
  - D: 콘텐츠부문 (정다정) · E: IT/시스템 (김재옥) · F: CEO (정용철) · G: 외부콜센터 (더아이앤오)
- **워크쉐도잉 검증 (W1)**: 실무자(유형 A/B/C)에게 추가 질문
- 총 질문 수: 대상자당 **7개** (공통 2 + 유형별 5)
:::

### 공통 질문 (전 대상자)

| # | 질문 | 의도 |
|---|------|------|
| C1 | 담당하시는 주요 업무와 하루 흐름을 설명해 주세요. 그중 가장 불편하거나 시간이 많이 걸리는 부분은 무엇인가요? | 역할 파악 + 핵심 페인포인트 도출 |
| C2 | 웹으로 시스템이 전환되면 꼭 개선되었으면 하는 점은 무엇인가요? | 요구사항 + 전환 기대/우려 |

### 유형 A: 정기구독팀 — 정황규(총괄), 어은진(실무)

| # | 질문 | 검증 대상 |
|---|------|----------|
| A1 | 구독 접수부터 발송까지 과정에서, 나이스페이 결제 확인과 구독 정보를 **수동으로 매칭**하는 단계가 있나요? 있다면 건당 얼마나 걸리나요? | 결제-구독 수동 매칭 병목 (M-03) |
| A2 | CMS 콘텐츠 접근 권한을 구독자에게 부여할 때, CS System과 CMS에 **각각 따로 접속**해서 처리하시나요? 월 몇 건 정도인가요? | CMS 권한 수동 부여 병목 (M-05) |
| A3 | CS 처리 시 고객 이력(구독/결제/배송/CS)을 한 화면에서 볼 수 있나요, 아니면 여러 화면을 오가며 확인하시나요? | 고객 360° 뷰 부재 확인 |
| A4 | 구독 갱신/해지/환불 처리 시 가장 번거로운 절차는 무엇인가요? 한 건 처리에 몇 단계, 몇 분 정도 걸리나요? | 구독 라이프사이클 관리 병목 |
| A5 | 구독 만료 고객을 어떻게 파악하시나요? 만료 후 CMS 권한 회수도 수동으로 하시나요? 누락되는 경우가 있나요? | 구독 만료→권한 회수 자동화 필요성 (M-06) |

### 유형 B: 영업추진팀 — 이성수(관리), 권지은(실무)

| # | 질문 | 검증 대상 |
|---|------|----------|
| B1 | Playauto에서 주문을 가져올 때, **Excel로 다운받아 CS System에 수동 입력**하는 과정이 맞나요? 하루에 몇 건 정도이고, 한 건당 얼마나 걸리나요? | Playauto→Excel→CS 수동이관 병목 (M-01) |
| B2 | 쿠팡/네이버/카카오 등 **채널별로 관리자 페이지에 따로 로그인**해서 주문/CS를 처리하시나요? 채널 간 데이터 통합은 어떻게 하시나요? | 채널별 분산 관리 병목 (M-02) |
| B3 | 총판/다량/특판 주문은 일반 주문과 처리 흐름이 어떻게 다른가요? 별도 양식(Excel 등)을 사용하시나요? | 특수 주문 프로세스 파악 |
| B4 | 재고 확인은 어떻게 하시나요? CS System에서 실시간으로 확인 가능한가요, 아니면 별도 확인이 필요한가요? | 재고 관리 현황 파악 |
| B5 | 배송 후 반품/교환/환불 처리 시 Playauto와 CS System **양쪽 모두 따로 처리**해야 하나요? 누락이 발생한 적이 있나요? | 반품/환불 이중 처리 병목 |

### 유형 C: 경영지원팀 — 송윤경(회계), 김나현(실무)

| # | 질문 | 검증 대상 |
|---|------|----------|
| C-1 | CS System의 매출 데이터를 이카운트 ERP에 **다시 수동 입력**하는 업무가 있나요? 월 몇 건이고, 총 얼마나 걸리나요? | CS↔ERP 이중입력 병목 (M-04) |
| C-2 | 월말 결산 시 매출 데이터를 **각 팀/채널에서 따로 취합**하시나요? 가장 시간이 많이 걸리는 정산 항목은 무엇인가요? | 매출 취합 수작업 병목 |
| C-3 | 세금계산서 발행이나 기안/결재 과정에서 시스템 간 데이터가 자동으로 연계되는 부분이 있나요, 전부 수작업인가요? | 회계 자동화 수준 파악 |
| C-4 | CS System과 이카운트 ERP에서 **데이터가 불일치**한 경우가 있나요? 발견하면 어떻게 대응하시나요? | 데이터 정합성 이슈 파악 |
| C-5 | 현재 경영진에게 보고하는 **정기 리포트**(매출/정산/구독 현황 등)가 있나요? 어떤 형태로 만드시고, 얼마나 걸리나요? | 리포트 자동화 요구사항 |

### 유형 D: 콘텐츠부문 — 정다정(연구소장)

| # | 질문 | 검증 대상 |
|---|------|----------|
| D1 | 월간지/단행본 콘텐츠를 CMS에 올리는 **편집 워크플로우**는 어떻게 되나요? (기획→원고→교정→발행 과정) | 콘텐츠 제작 프로세스 파악 |
| D2 | CMS에서 콘텐츠를 발행할 때 CS System(구독 관리)과 **어떤 데이터가 오가나요?** 구독자 권한 부여/해제가 자동인가요, 수동인가요? | CMS↔CS 연동 실태 파악 (M-05) |
| D3 | 현재 CMS의 **에디터 기능**(글쓰기, 이미지 삽입, 레이아웃 등)에서 불편하거나 부족한 점이 있나요? | 웹 에디터/AI 에디터 요구사항 |
| D4 | 과거 발행된 콘텐츠를 **검색하거나 재활용**할 때 어떻게 하시나요? 콘텐츠 분류/태깅 체계가 있나요? | 디지털 아카이브 요구사항 |
| D5 | 편집실 인원이 CMS 외에 **다른 시스템**(CS System, 사내 도구 등)을 사용하는 경우가 있나요? 있다면 어떤 용도인가요? | 부서 간 시스템 연계 파악 |

### 유형 E: IT/시스템 — 김재옥 소장(외부 개발자)

| # | 질문 | 검증 대상 |
|---|------|----------|
| E1 | CS System의 핵심 비즈니스 로직(구독 처리, 결제 연동, 정산)이 **Stored Procedure에 집중**되어 있나요? SP가 총 몇 개 정도이고, 가장 복잡한 로직은 어디에 있나요? | 마이그레이션 난이도 파악 |
| E2 | 외부 시스템(Playauto, 나이스페이, CMS 등)과의 연동이 **API인지, 파일 기반인지, 수동인지** 각각 알려주실 수 있나요? | 연동 방식별 전환 전략 수립 |
| E3 | 웹으로 전환할 때 **이 시스템에서 가장 주의해야 할 부분**(데이터 정합성, 숨겨진 로직, 배치 작업 등)이 있다면 무엇인가요? | 마이그레이션 리스크 사전 식별 |
| E4 | 현재 **정기적으로 실행되는 배치 작업이나 스케줄러**가 있나요? (구독 갱신, 만료 처리, 데이터 백업 등) 어떤 주기로 동작하나요? | 배치/스케줄러 전환 범위 파악 |
| E5 | DB 스키마, SP 소스코드, 시스템 구성도 등 **기술 자료 제공**이 가능하신가요? 가능하다면 언제쯤 전달받을 수 있을까요? | 자료 확보 일정 확정 (리스크 R-01 대응) |

### 유형 F: CEO — 정용철

| # | 질문 | 검증 대상 |
|---|------|----------|
| F1 | 웹 전환의 **최우선 목표**는 무엇인가요? (비용 절감 / 업무 효율 / 신규 서비스 / 기술 현대화 등) 1~2년 내 기대하시는 구체적 성과가 있나요? | 사업 비전 및 우선순위 확인 |
| F2 | 현재 경영 보고나 의사결정에 필요한 데이터(매출 현황, 구독자 추이, 채널별 실적 등)를 **얼마나 쉽게 확인**하실 수 있나요? | 경영 대시보드 요구사항 |
| F3 | 현재 시스템 운영/유지보수에 **연간 얼마 정도** 비용이 들고 있나요? 웹 전환 시 예산 범위에 대한 기대치가 있으신가요? | 예산 규모 및 ROI 기대치 |
| F4 | 구독 사업 외에 향후 **신규 사업이나 서비스 확장** 계획이 있으신가요? (예: 앱, 해외, B2B 등) | 시스템 확장성 요구사항 |
| F5 | 웹 전환 과정에서 **가장 우려되는 점**은 무엇인가요? (업무 중단, 직원 적응, 데이터 유실 등) | 전환 리스크 인식 파악 |

### 유형 G: 외부콜센터 — 더아이앤오(~4명)

| # | 질문 | 검증 대상 |
|---|------|----------|
| G1 | VPN으로 CS System에 접속해서 업무를 처리하실 때, **접속 속도나 화면 반응** 문제가 있나요? | 외부 접근성 문제 파악 |
| G2 | 하루 평균 몇 건의 CS를 처리하시고, 가장 많은 **문의 유형** (구독/배송/환불/기타)은 무엇인가요? | CS 업무량 및 유형 분포 파악 |
| G3 | 고객 응대 시 **고객 정보를 조회하는 과정**은 어떻게 되나요? 필요한 정보가 한 화면에 나오나요, 여러 곳을 찾아봐야 하나요? | 고객 정보 조회 효율성 |
| G4 | CS 처리 결과를 **좋은생각사람들 내부 팀에 전달**하는 방식은 무엇인가요? (시스템 내 기록 / 별도 보고 / 유선 등) | 외부↔내부 커뮤니케이션 방식 |
| G5 | 현재 CS System에서 **처리할 수 없어서 내부 직원에게 넘겨야 하는 업무**가 있나요? 어떤 유형이 가장 많나요? | 콜센터 권한 범위 및 에스컬레이션 파악 |

### 워크쉐도잉 검증 질문 (실무자 유형 A/B/C 대상)

| # | 질문 | 의도 |
|---|------|------|
| W1 | 저희가 파악한 업무 흐름을 **실제로 옆에서 지켜보며 확인**하고 싶습니다. 워크쉐도잉이 가능한 시간대와, 가장 바쁜(=가장 대표적인) 업무 시간대는 언제인가요? | 워크쉐도잉 일정 조율 + 핵심 관찰 시간대 확보 |

:::tip[워크쉐도잉 검증 체크리스트]
인터뷰에서 파악한 아래 사항을 워크쉐도잉으로 **현장 검증**합니다:
- [ ] Playauto → Excel → CS System 수동 입력 흐름이 실제 맞는지?
- [ ] 채널별 관리자 로그인 → Excel → 수기 통합 흐름이 실제 맞는지?
- [ ] CMS 권한 별도 접속/수동 처리 흐름이 실제 맞는지?
- [ ] 인터뷰에서 파악하지 못한 숨은 수작업/시스템이 있는지?
- [ ] 각 수작업의 **실제 소요 시간과 건수** 측정 (추정치 검증)
:::

## 인터뷰 진행 시 주의사항

### Do's (해야 할 것)

- **경청하기**: 말을 끊지 않고 끝까지 듣기
- **구체적으로 묻기**: "불편하다"면 → "어떤 상황에서, 어떻게 불편한지" 추가 질문
- **예시 요청하기**: "예를 들어 설명해 주실 수 있나요?"
- **화면 보며 진행**: 가능하면 실제 화면을 보면서 인터뷰
- **녹음/녹화 동의**: 사전에 녹음 동의 받기 (기록 정확성 위해)

### Don'ts (하지 말아야 할 것)

- **유도 질문 피하기**: "이 기능이 필요하시죠?" (X) → "어떤 기능이 필요하신가요?" (O)
- **기술 용어 사용 자제**: 사용자 눈높이에 맞춰 질문
- **한 번에 여러 질문 피하기**: 질문은 하나씩
- **답변 해석하지 않기**: 들은 그대로 기록

### 협조가 어려운 경우 대응

| 상황 | 대응 방법 |
|------|----------|
| 바쁘다고 함 | 15분만이라도 요청, 핵심 질문만 |
| 모른다고 함 | "평소에 어떻게 하시나요?"로 우회 |
| 기존 시스템 옹호 | 공감 후 "더 좋아지면 하는 점" 질문 |
| 부정적 반응 | 변화의 이점 설명, 의견 존중 표현 |
