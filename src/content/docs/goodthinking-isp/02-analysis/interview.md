# 이해관계자 인터뷰

핵심 업무 담당자 인터뷰를 통한 현행 업무 파악 및 요구사항 수집

---

## 인터뷰 개요

### 목적
1. **현행 업무 파악**: 실제 업무 수행 방식과 흐름 이해
2. **문제점 도출**: 현 시스템/프로세스의 불편사항 및 개선점 파악
3. **요구사항 수집**: 신규 시스템에 필요한 기능 및 개선 요청 취합

### 인터뷰 대상

| 구분 | 역할 | 담당자 | 인터뷰 일자 | 상태 |
|------|------|--------|-----------|:----:|
| 정기구독팀 | 구독/CS 업무 총괄 | 정황규 | | ⬜ |
| 정기구독팀 | 구독/CS 실무 담당 | 어은진 | | ⬜ |
| 영업추진팀 | 주문/배송 관리 (총판/다량/특판) | 이성수 | | ⬜ |
| 영업추진팀 | 주문/배송 실무 | 권지은 | | ⬜ |
| 경영지원팀 | 회계/정산 관리 | 송윤경 | | ⬜ |
| 경영지원팀 | 경영지원 실무 | 김나현 | | ⬜ |
| 콘텐츠부문 | CMS/편집 총괄 (연구소장) | 정다정 | | ⬜ |
| IT/시스템 | 시스템 관리 (외부 개발자) | 김재옥 소장 | | ⬜ |
| 경영/관리 | 전체 총괄 (CEO) | 정용철 | | ⬜ |
| 외부콜센터 | CS 아웃소싱 (~4명) | 더아이앤오 | | ⬜ |

## 인터뷰 질문 가이드

### 1. 현행 업무 파악

```
Q1. 담당하시는 주요 업무는 무엇인가요?
Q2. 하루/주간 업무 흐름을 설명해 주세요.
Q3. 업무에 사용하는 시스템/도구는 무엇인가요?
Q4. 다른 팀/시스템과 연계되는 업무가 있나요?
```

### 2. 문제점 및 개선점

```
Q5. 현재 업무에서 가장 불편한 점은 무엇인가요?
Q6. 수작업으로 처리해야 하는 업무가 있나요?
Q7. 업무 처리 시 지연이나 오류가 발생하는 구간이 있나요?
Q8. 현 시스템에서 개선이 필요한 부분은 무엇인가요?
```

### 3. 요구사항 수집

```
Q9. 신규 시스템에 꼭 필요한 기능은 무엇인가요?
Q10. 추가로 있으면 좋겠다고 생각하는 기능이 있나요?
Q11. 타 서비스에서 본 좋은 기능이나 레퍼런스가 있나요?
Q12. 웹 전환 시 우려되는 점이 있나요?
```

## 인터뷰 진행 시 주의사항

### Do's (해야 할 것)

- **경청하기**: 말을 끊지 않고 끝까지 듣기
- **구체적으로 묻기**: "불편하다"면 → "어떤 상황에서, 어떻게 불편한지" 추가 질문
- **예시 요청하기**: "예를 들어 설명해 주실 수 있나요?"
- **화면 보며 진행**: 가능하면 실제 화면을 보면서 인터뷰
- **녹음/녹화 동의**: 사전에 녹음 동의 받기 (기록 정확성 위해)

### Don'ts (하지 말아야 할 것)

- **유도 질문 피하기**: "이 기능이 필요하시죠?" (X) → "어떤 기능이 필요하신가요?" (O)
- **기술 용어 사용 자제**: 사용자 눈높이에 맞춰 질문
- **한 번에 여러 질문 피하기**: 질문은 하나씩
- **답변 해석하지 않기**: 들은 그대로 기록

### 협조가 어려운 경우 대응

| 상황 | 대응 방법 |
|------|----------|
| 바쁘다고 함 | 15분만이라도 요청, 핵심 질문만 |
| 모른다고 함 | "평소에 어떻게 하시나요?"로 우회 |
| 기존 시스템 옹호 | 공감 후 "더 좋아지면 하는 점" 질문 |
| 부정적 반응 | 변화의 이점 설명, 의견 존중 표현 |
