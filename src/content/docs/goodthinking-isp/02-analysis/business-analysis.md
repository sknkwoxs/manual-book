# 업무 분석

실무자 워크 쉐도잉을 통해 연동 불가로 인해 발생하는 엑셀 수작업 및 중복 업무 식별

---

## 분석 방법

### 워크 쉐도잉 (Work Shadowing)
실무자의 일상 업무를 관찰하여 실제 업무 흐름과 문제점을 파악

| 대상 | 기간 | 방법 |
|------|------|------|
| CS 담당자 | __일 | 업무 관찰 및 기록 |
| 운영 담당자 | __일 | 업무 관찰 및 기록 |

---

## 현행 업무 흐름도

### 1. 주문 처리 프로세스

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 주문발생  │───▶│ 수동확인  │───▶│ Excel    │───▶│ CS입력   │
│ (각 채널) │    │ (다중창)  │    │ 다운로드  │    │ (수작업) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                      │
                                                      ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 고객응대  │◀───│ 권한부여  │◀───│ CMS수정  │◀───│ 검증     │
│          │    │ (수동)    │    │ (별도접속)│    │ (목시)   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 2. 데이터 취합 프로세스

```
┌──────────────────────────────────────────────────────────┐
│                    데이터 수집 과정                        │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  [자사몰] ──▶ Excel 다운로드 ──┐                          │
│                               │                          │
│  [외부몰] ──▶ 관리자 로그인 ──▶│──▶ 수기 통합 ──▶ CS 입력 │
│              Excel 다운로드 ──┘                          │
│                               │                          │
│  [후원]  ──▶ 별도 시스템 ─────┘                          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 수작업 구간 식별

### 식별된 수작업 항목

| No | 업무 | 현재 방식 | 소요 시간 | 빈도 | 오류 위험 |
|----|------|----------|----------|------|----------|
| 1 | 주문 데이터 다운로드 | 각 채널 수동 접속 | __분 | 일 __회 | 중 |
| 2 | Excel 데이터 취합 | 수동 복사/붙여넣기 | __분 | 일 __회 | 상 |
| 3 | CS 프로그램 입력 | 건별 수동 입력 | __분/건 | 일 __건 | 상 |
| 4 | CMS 권한 부여 | 별도 시스템 수동 처리 | __분/건 | 일 __건 | 중 |
| 5 | 데이터 검증 | 목시 확인 | __분 | 일 __회 | 상 |

### 수작업으로 인한 문제

1. **시간 낭비**
   - 일일 수작업 총 소요 시간: __시간 (추정)
   - 월간 환산: __시간

2. **오류 발생**
   - 입력 오류 발생 건수: 월 __건 (추정)
   - 오류 수정 소요 시간: __시간/건

3. **업무 집중도 저하**
   - 단순 반복 업무로 인한 피로 누적
   - 본질적 CS 업무에 투입 시간 감소

## 병목 구간 분석

### 주요 병목 지점

```
병목 심각도: 🔴 높음 | 🟠 중간 | 🟢 낮음

1. [주문 수집 → CS 입력]  🔴
   - 원인: 시스템 간 연동 불가
   - 영향: 처리 지연 __시간

2. [결제 확인 → 권한 부여]  🔴
   - 원인: CMS와 CS 분리
   - 영향: 고객 이용 지연

3. [데이터 취합]  🟠
   - 원인: 다중 채널 수동 접속
   - 영향: 일 __시간 소요
```

### 병목 해소를 위한 개선 방향

| 병목 | 현재 | 개선 방향 |
|------|------|----------|
| 주문 수집 | 수동 다운로드 | API 자동 연동 |
| 데이터 입력 | 수동 입력 | 자동 입력/동기화 |
| 권한 부여 | 수동 처리 | 결제 연동 자동화 |
