# 취업관리시스템 테스트 가이드

서울시가족센터 취업관리시스템 테스트 가이드입니다.

## 이 매뉴얼의 구성

| 부 | 장 | 내용 |
|:---|:---|:---|
| **개요** (이 페이지) | 해당 없음 | 접속·계정·제공 범위·테스트 현황 요약 |
| **화면별 구성** | 로그인 · 대시보드 · 구인처 · 채용공고 · 구직자 · 상담 · 알선 · 재동의 · 업무일지 · 실적통계 · 시스템관리 (11장) | 화면마다 조작 순서와 역할별 차이 |
| **역할별 구성** | 상담사 · 담당자 · 팀장 · 관리자 · 마스터 (5장) | 하루 일과順으로 쓰는 화면과 주의점 |
| **부록** | 권한 총정리 · 테스트 현황 · 운영 안내 (2장) | 관리자·테스트 총괄용 참고 |

화면별 구성과 역할별 구성은 일부러 겹치게 썼습니다 (MECE 아님). 화면 기준으로 찾든 역할 기준으로 읽든 원하는 답에 도달할 수 있습니다.

## 접속 정보

| 항목 | 내용 |
|:---|:---|
| 개발서버 URL | `__URL 입력__` |
| 테스트 기간 | `__MM/DD ~ MM/DD__` |
| 문의 | `__담당자 / 연락처__` |
| 문의·오류 제보 | QA 시트(`__링크 입력__`)에 자유롭게 적어주세요 |

### 테스트 계정 (비밀번호 공통: `test1234`)

| 계정 | 역할 | 한 줄 |
|:---|:---|:---|
| `staff@test.local` | 취업지원팀 담당자 | 실무 중심, 처음에는 이 계정 권장 |
| `counselor@test.local` | 상담사 | 본인 담당 상담·유선확인 |
| `admin@test.local` | 센터지원팀 관리자 | 계정·감사·복구 |
| `chief@test.local` | 취업지원팀장 | 참고용 (팀장 전용 화면 제외) |
| `master@test.local` | 시스템 마스터 | 전체 조회·파기 실행 |

:::caution
테스트 데이터는 개발용 익명화 데이터이며 초기화될 수 있습니다. 실제 개인정보를 입력하지 마세요.
:::

## 범위에서 제외된 것

- 취업지원팀장 전용 화면 (담당자·관리자의 자료 공유로 대체, DB 읽기 권한은 선행 부여)
- 4종 실적 보고 엑셀 다운로드 (구인상담·구직상담·취업연계·누계실적 로그)
- 업무일지 PDF 전용 저장 고도화 (브라우저 인쇄로 대체)

## 테스트 현황 한눈에 보기

- 로그인·세션·계정잠금, 시스템 관리(계정 목록·수정·비활성화·잠금해제·감사로그)는 내부 검증 완료
- 구인처·공고·구직자·상담·알선·재동의·업무일지·통계 화면은 본 매뉴얼대로 직접 확인해 주세요
- 발견된 문제는 QA 시트에 적어주시면 개발팀이 재현·수정 후 다시 확인 요청드립니다
- 세부 검증 내역과 알려진 제약은 [부록 · 테스트 현황 · 운영 안내](./reference/test-operations/)에 정리되어 있습니다
