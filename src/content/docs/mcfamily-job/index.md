# 취업관리시스템 운영 매뉴얼

서울시가족센터 취업관리시스템 운영 매뉴얼입니다.

## 이 매뉴얼의 구성

| 부 | 장 | 내용 |
|:---|:---|:---|
| **개요** (이 페이지) | 해당 없음 | 접속·계정·구성 요약 |
| **화면별 구성** | 로그인 · 대시보드 · 구인처 · 채용공고 · 구직자 · 상담 · 알선 · 재동의 · 업무일지 · 실적통계 · 시스템관리 (11장) | 화면마다 조작 순서와 역할별 차이 |
| **역할별 구성** | 상담사 · 담당자 · 팀장 · 관리자 · 마스터 (5장) | 하루 일과順으로 쓰는 화면과 주의점 |
| **부록** | 권한 총정리 · 운영 안내 (2장) | 관리자·총괄용 참고 |

화면별 구성과 역할별 구성은 일부러 겹치게 썼습니다 (MECE 아님). 화면 기준으로 찾든 역할 기준으로 읽든 원하는 답에 도달할 수 있습니다.

## 접속 정보

| 접근 조건 | Cloudflare Access 인증 필요. 사무실 IP는 자동 통과, 외부는 `@familyseoul.or.kr` 이메일 OTP |

### 계정 안내

실명으로 발급된 개인 계정으로 로그인합니다. 공용·공유 계정은 사용하지 마세요.

- 신규 계정은 관리자가 **시스템 관리** 메뉴에서 생성·역할 부여합니다 (master 부여는 master만 가능)
- 초기·초기화된 비밀번호는 화면에 1회만 표시되니 전달 시 메모해 두고, 첫 로그인 시 비밀번호 변경이 강제됩니다
- 비밀번호를 잊었거나 5회 실패로 잠겼으면 관리자에게 초기화·잠금 해제를 요청하세요

## 범위에서 제외된 것

- 취업지원팀장 전용 화면 (담당자·관리자의 자료 공유로 대체, DB 읽기 권한은 선행 부여)

## 운영 한눈에 보기

- 계정·잠금·초기화·감사·파기는 [화면 · 시스템 관리](./screens/11-system/) 절차대로 진행합니다
- 화면 조작법은 아래 화면별 구성대로, 역할별 일과는 역할별 구성대로 확인하세요
- 오류 신고 시 관리자가 비밀번호 변경 없이 화면 확인으로 재현합니다 (관리자·마스터만)
