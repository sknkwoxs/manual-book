# 1.4 채용공고 관리

## 이 화면에서 할 수 있는 일 (역할별)

| 행위 | 상담사 | 담당자(staff) | 관리자(admin) | 마스터 |
|:---|:---:|:---:|:---:|:---:|
| 목록 조회 | ○ | ○ | 제한적 | ○ |
| 등록·수정·마감·삭제 | ✕ (등록 페이지 접근 차단) | ○ (독점) | ✕ | ○ |
| 목록 엑셀 다운로드 | ✕ | ○ | ○ | ○ |

## 목록

좌측 메뉴 **채용공고 관리**를 클릭합니다. 헤더에 **총 N건** 뱃지, 우측에 **엑셀 다운로드**(staff/admin/master)와 **공고 등록**(staff) 버튼이 있습니다.

![채용공고 목록](../images/05-offers.png)

- 검색·필터는 표 머리(th)에서 바로 선택합니다: 공고명 검색(구인처명·근무지 포함) + 모집상태·직종·근무지역·모집국가
- 모집국가 2개 초과 시 "외 N" 축약 표시, 회사명은 길면 잘림(110px) 처리됩니다
- 상태 배지: 진행(초록) / 마감(검정)으로 한눈에 구분됩니다

## 등록 (staff)

**공고 등록** 버튼 → `/offers/create`에서 구인처를 선택해 공고를 저장합니다.

![채용공고 등록](../images/06-offer-create.png)

## 상세 · 수정 · 삭제 (staff)

공고 제목을 클릭하면 상세(`/offers/[id]`)가 열립니다. 구인처 상세와 같은 좌(본문) / 우(댓글·변경이력) 2단 구성입니다.

![채용공고 상세](../images/15-offer-detail.png)

- 상태 변경: 모집중 ⇄ 마감, 취소는 종단(되돌릴 수 없음)이며, DB가 강제하므로 화면에서 우회할 수 없습니다
- 마감된 공고에는 신규 알선이 만들어지지 않습니다 (알선 등록 시 공고 목록에서 제외되면 정상)
- **정보 수정**은 `/offers/[id]/edit`에서 합니다. **삭제**는 알선이 참조 중인 공고에서는 차단됩니다
- **댓글**: 공고 단위 메모(지원자 문의, 기업 요청사항, 조건 협의 등)를 남길 수 있습니다. 구직자 댓글과 달리 공고에 귀속되며, 작성자 본인만 수정·삭제할 수 있습니다
