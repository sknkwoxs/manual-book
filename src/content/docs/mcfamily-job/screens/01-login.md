# 1.1 로그인

운영서버(`https://job.familyseoul.or.kr`)로 접속하면 로그인 화면이 나타납니다. 발급받은 개인 계정으로 로그인합니다 (Enter 키도 동일하게 동작). 사무실 IP가 아니면 Cloudflare Access에서 `@familyseoul.or.kr` 이메일 OTP 인증이 먼저 뜹니다.

- 아이디: 발급받은 개인 이메일
- 비밀번호: 본인이 설정한 비밀번호 (초기·초기화 직후에는 첫 로그인 시 변경 화면이 먼저 뜹니다)
- 로그인 성공 시 대시보드(`/`)로 이동하고, 좌측 하단에 이름·역할이 표시됩니다

![로그인 화면](../images/01-login.png) (운영 화면으로 재촬영 예정)

## 알아두면 좋은 로그인 보안 동작

- **실패 메시지 미구분**: 존재하지 않는 계정이든 틀린 비밀번호든 동일하게 "이메일 또는 비밀번호가 올바르지 않습니다"로 표시됩니다. 계정 존재 여부를 유추할 수 없게 하려는 정상 동작입니다.
- **반복 실패 시 계정 잠금**: 비밀번호를 5회 연속 틀리면 계정이 잠기고, 정상 비밀번호로도 로그인이 거부됩니다. 잠금 해제는 관리자에게 요청하세요 ([부록 · 운영 안내](../reference/operations/) 참조).
- **비활성화 계정**: 퇴사·보직 변경으로 비활성화된 계정은 로그인할 수 없습니다.
- **첫 로그인·초기화 후 비밀번호 변경 강제**: 신규 발급·관리자가 초기화한 비밀번호로 로그인하면 다른 화면에 들어가기 전에 비밀번호 변경 화면이 먼저 뜹니다. 바꾸기 전에는 계속 변경 화면만 표시됩니다
- **로그인 화면 도움말**: 제목 옆 `?`를 누르면 비밀번호·잠금·신규발급 안내가 팝업으로 뜹니다
- **로그아웃 후 주의**: 로그아웃한 뒤 브라우저 뒤로가기로 이전 화면이 보일 수 있으나 세션은 파기된 상태라 아무 동작도 되지 않습니다. 공용 PC에서는 로그아웃 후 브라우저를 닫아주세요.

## 역할별 첫 화면

로그인 직후 보이는 대시보드는 역할마다 다릅니다. 자세한 구성은 [화면 · 대시보드](./02-dashboard/)에서 확인하세요.
