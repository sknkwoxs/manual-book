# 3.2 테스트 현황·운영 안내

## 검증 완료 항목 (테스트 시 스킵 가능)

내부 검증에서 통과가 확인된 항목입니다. 시간이 부족하면 스킵하고, 이상 동작을 발견했을 때만 제보해 주세요.

- **로그인·로그아웃**: 5개 역할 로그인, Enter 제출, 역할 라벨 표시, 비로그인 직접 접근 리다이렉트, 비로그인 API 401 차단
- **로그인 보안**: 실패 메시지 미구분(계정 열거 방지), 5회 실패 시 계정 잠금, 비활성화 계정 로그인 거부, 잠금 후 관리자 해제
- **시스템 관리**: 계정 목록·수정·비활성화·잠금해제, 역할 변경 감사 기록, 감사 로그 조회
- **백엔드 자동 검증 28개**: 5역할 인증·익명 차단·데이터 가시성·쓰기 권한·알선 상태 전이·배치 함수 권한

## 알려진 제약 · 미결 사항 (제보 불필요)

이미 파악된 사항이라 별도 제보 없이 개발팀이 대응 중입니다.

| # | 내용 | 상태 |
|:---|:---|:---|
| 1 | 관리자 화면에서 **계정 생성·비밀번호 초기화 실패** (`Admin endpoints require the service_role key`) | 원인 파악됨, 서버 키 설정 후 해소 예정 |
| 2 | 마스터 **파기(하드딜리트) 실행 버튼이 화면에 없음** (기능은 존재) | 실행 화면 추가 예정 |
| 3 | 로그아웃 후 브라우저 뒤로가기 시 이전 화면이 보이는 현상 (세션은 파기됨) | 수정 예정, 공용 PC에서는 브라우저 종료 권장 |
| 4 | 4종 실적 보고 엑셀, 팀장 화면, 업무일지 PDF 고도화 | 제공 범위 밖 (고객 협의 사항) |
| 5 | 초기 비밀번호가 공통(`test1234`)으로 생성됨 | 런칭 전 랜덤 초기비번 + 최초 로그인 시 변경 강제로 전환 결정됨 |

## 운영 안내

### 계정 발급·관리 (관리자)

1. **시스템 관리** 메뉴 → 계정 탭에서 신규 계정을 생성하고 역할을 부여합니다
2. 초기 비밀번호를 전달합니다 (전달 후 첫 로그인 시 변경하도록 안내, 위 5번 개선 전까지는 직접 변경 요청)
3. 퇴사·보직 변경 시 계정을 **비활성화**합니다 (삭제가 아니라 비활성화, 이력 보존)
4. 비밀번호를 잊은 사용자는 관리자가 초기화합니다. 잠긴 계정(5회 실패)은 관리자가 잠금 해제합니다

### 개인정보 재동의·보관·파기 주기

- 구직자 등록 시 기록된 **수집 동의일로부터 6개월**이 지나면 재동의 대상으로 자동 선정됩니다
- 문자 발송(담당자) → 무응답 시 유선 확인(상담사) → 최종 무응답 시 목록에서 숨김(**소프트 삭제**)
- 숨김 처리된 지 **30일 이내**에는 관리자가 정상 상태로 **복구**할 수 있습니다
- 30일이 지나면 마스터가 **완전 삭제(파기)** 합니다. 통계는 비식별 형태로 보존됩니다

### 테스트 데이터 주의

- 개발서버 데이터는 언제든 초기화될 수 있습니다. 입력한 테스트 내용은 사라질 수 있습니다
- 초기화 후에는 테스트 계정도 함께 사라지므로 개발팀이 재생성합니다. 로그인이 안 되면 문의처로 연락해 주세요
- 실제 개인정보(실명·실 연락처)를 입력하지 마세요

### 문의·제보

- 테스트 문의사항: QA 시트 `__링크 입력__`에 자유롭게 적어주세요
- 적어주시면 좋은 내용: 어느 화면·어느 계정에서 무엇을 눌렀더니 어떻게 됐는지 + 스크린샷
- 긴급한 장애(로그인 불가·화면 전체 오류)는 `__담당자 / 연락처__`로 직접 연락해 주세요
