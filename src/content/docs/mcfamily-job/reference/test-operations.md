# 3.2 테스트 현황·운영 안내

## 검증 완료 항목 (테스트 시 스킵 가능)

내부 검증에서 통과가 확인된 항목입니다. 시간이 부족하면 스킵하고, 이상 동작을 발견했을 때만 제보해 주세요.

- **로그인·로그아웃**: 5개 역할 로그인, Enter 제출, 역할 라벨 표시, 비로그인 직접 접근 리다이렉트, 비로그인 API 401 차단
- **로그인 보안**: 실패 메시지 미구분(계정 열거 방지), 5회 실패 시 계정 잠금, 비활성화 계정 로그인 거부, 잠금 후 관리자·마스터 해제, 신규·초기화 계정의 최초 로그인 변경 강제
- **시스템 관리**: 계정 생성(랜덤 초기비번 1회 표시)·수정·비활성화·잠금해제, 역할 변경 감사 기록, 감사 로그 조회·엑셀 내보내기(사유 필수), 데이터 파기 미리보기·실행
- **실적 통계**: 5개 역할 동일 수치 조회, 4종 로그 엑셀 다운로드(상담사는 본인 범위)
- **업무일지**: 상담사 작성·제출 잠금·정정·출력, 하루 1건
- **백엔드 자동 검증 28개**: 5역할 인증·익명 차단·데이터 가시성·쓰기 권한·알선 상태 전이·배치 함수 권한

## 운영 안내

### 계정 발급·관리 (관리자)

1. **시스템 관리** 메뉴 → 계정 탭에서 신규 계정을 생성하고 역할을 부여합니다 (master 부여는 master만 가능)
2. 초기 비밀번호를 비워두면 12자리 랜덤으로 생성되며 화면에 1번만 표시되니 메모해서 전달합니다. 신규·초기화 계정은 첫 로그인 시 비밀번호 변경이 강제되니 미리 안내해 주세요
3. 퇴사·보직 변경 시 계정을 **비활성화**합니다 (삭제가 아니라 비활성화, 이력 보존)
4. 비밀번호를 잊은 사용자는 관리자가 초기화합니다. 잠긴 계정(5회 실패)은 관리자가 잠금 해제합니다. 관리자까지 잠기면 마스터가 해제하고, 전부 막히면 DB에서 직접 해제합니다 (`UPDATE users SET failed_attempts=0 WHERE email='...'`)
5. 본인 비밀번호는 좌측 하단 내 계정(마이페이지 모달)에서 직접 바꿀 수 있습니다

### 개인정보 재동의·보관·파기 주기

- 구직자 등록 시 기록된 **수집 동의일로부터 6개월**이 지나면 재동의 대상으로 자동 선정됩니다
- 문자 보내기·유선 연락 후 결과 기록(상담사 본인 담당·담당자) → 최종 무응답 시 목록에서 숨김(**완전 삭제 대기**)
- 숨김 처리된 지 **30일 이내**에는 담당자(staff)가 정상 상태로 **복구**할 수 있습니다
- 30일이 지나면 관리자·마스터가 시스템 관리의 데이터 파기 탭에서 **완전 삭제(파기)** 합니다 (실행 전 미리보기 확인). 통계는 비식별 형태로 보존됩니다

### 테스트 데이터 주의

- 개발서버 데이터는 언제든 초기화될 수 있습니다. 입력한 테스트 내용은 사라질 수 있습니다
- 초기화 후에는 테스트 계정도 함께 사라지므로 개발팀이 재생성합니다. 로그인이 안 되면 문의처로 연락해 주세요
- 실제 개인정보(실명·실 연락처)를 입력하지 마세요
