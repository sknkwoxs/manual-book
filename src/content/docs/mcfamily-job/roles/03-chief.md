# 2.3 취업지원팀장

팀장 전용 화면은 제외된 역할입니다. 로그인은 가능하고 DB 읽기 권한은 선행 부여되어 있으나, 별도 메뉴는 없습니다.

![팀장 대시보드](../images/22-dashboard-chief.png)

## 이용 방식

- 팀장이 봐야 할 자료(실적·현황·명단)는 **담당자·관리자가 공유·보고하는 방식**으로 대체합니다
- 재동의 현황은 조회 전용 권한으로 설계되어 있으나, 별도 메뉴가 없습니다
- 구인처 등록·수정 페이지도 정책상 조회가 제한될 수 있습니다

## 참고

- 팀장 화면 설계 시에는 마스킹 전용 뷰 경유로 PII 직접 열람 없이 조회하는 방향이 결정되어 있습니다
- 테스트 시에는 chief 계정으로 로그인되는지와 노출 범위를 가볍게 확인하는 수준이면 충분합니다
